# 教科書型の文章の量と順序（スロットに文を入れる前の目安）

教科書 122 ページの書き起こしの形の測定（文・段落・見出し・強調・事例・注）から。**元の文は入れていない。例文は自作**。詳しい数値・本ごとの差・根拠は `${CLAUDE_PLUGIN_ROOT}/skills/reportkiller/references/textbook-prose.md`（これが本体）。ここは紙面の入力 JSON を書くときの 1 枚。

| スロット | 量の目安（測定） | 書き方 |
|---|---|---|
| `body`（本文） | 1 段落＝約 200 字・3 文（150〜260 字・2〜5 文）。1 文は中央値 55〜68 字・p90 125 字以下・読点 2〜3 | 段落の頭の接続語は 4 つに 1 つまで。文末は「と呼ぶ・と解される・といえる」の終止形が主で「である。」は 13% 程度。長短を混ぜる（40 字以下を 5 文に 1 つ） |
| 定義語の太字 | 1 段落に 0〜2 語・9 字以下 | 具体の場面 → 「このような〜を〜と呼ぶ」→ 名前だけ太字 |
| `h2`（節） | 8 字前後（上限 20）・名詞止め | 「〜について」「〜とは」で終えない |
| `h3`（項） | 5 字前後（上限 8〜24） | 直下の階層（節→項）なら本文なしで続いてよい |
| `box`（事例） | 約 120 字・3 文以内・A/B/X/Y・事実だけ | 節の頭に集める。結論・評価は本文へ |
| `aside`（補足） | 75〜120 字・1〜2 文（脚注型の本は 170 字まで） | 接続語なしで始める。出典は確認済みだけ |
| `fig` の図題 | 12〜34 字・番号＋名詞句 | 動詞で終えない。図の中の語は 4〜8 字 |
| `point`（要点） | 3〜5 項目・1 項目 27 字まで・主語＋述語 | 見出しか太字の語と一致させる |
| `overview`（章頭） | 9 行ほどの導入（270 字まで） | 論点を並べる。結論を先に書かない |

順序：**事例（節の頭）→ 総説（定義・分類）→ 要件（項・目）→ 例外・学説**。1 ページに見出し 1・本文 600〜900 字。

自作の例（定義の 3 歩）：**「Aが倉庫の鍵を預かったまま転居し、持ち主Bが取り戻せなくなる場合のように、預かった物を返せない状態が続くことがある。このような状態を、債務の滞留と呼ぶ。」**

書いたあと：`node ${CLAUDE_PLUGIN_ROOT}/skills/reportkiller/scripts/textbook_check.js 本文.md`（本文を Markdown にして渡す）。
