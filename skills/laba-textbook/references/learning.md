# Laba の学習：目録 → フォーマット JSON → 規則（と、新しい本の受け取り方）

Laba は**画像も本文も持たない**。次の 4 つだけから学ぶ（数値・構造・言語化した規則。公開してよい形）。

| 段 | 置き場 | 中身 |
|---|---|---|
| ① 目録 | `formats/catalog.tsv` | 本の種類（題名は書かない）・ファミリー・ページの種類・部品の一覧・確度 |
| ② フォーマット JSON | `formats/fam-f1.json`・`fam-f2.json`・`fam-f3.json` | 紙の比率と幅・字・送り・行数・余白・傍注の列・柱・変種の差分・マスターごとのスロット（役割・種類・必須・文字数の目安） |
| ③ 規則 | `references/rules-short.md`（20 行）・`rules.md`（詳細）・`figure-spec.md`・`output-format.md` | いつどの部品・図の型を使うか／文章から図の記述を作る手順／スロットと文だけの出力 |
| ④ 測定の手順 | （この公開リポジトリには入れない） | 画像から寸法・罫・色を同じ手順で取り出す道具と測定値は、非公開の置き場にある |

## 1. 読む順と量（費用を抑える）

1. 毎回：`rules-short.md`（20 行）と `page-slots.md`（スロットの要約）。
2. 図を作るとき：`figure-spec.md` の 2 章（型別の欄）と 4 章（G1〜G7）。
3. 規則の根拠・例外を確かめるとき：`rules.md` の該当の章だけ。
4. **読まない**：`formats/*.json` の全文を AI に渡さない（`textbook_page.py slots` が要約を出す）。`rules.md` 全文を毎回読まない。

## 2. フォーマットの付け替えと変種

- ファミリー F1（法学教科書・横 1 段・傍注）・F2（UNIT 型・脚注・上の柱）・F3（入門書・字が小さく 39 行・外側の注欄）。変種（b1・b2・b4・b5）は字詰め・傍注列・図表の語・句読点の差分。
- **スロット名は同じ役割で全フォーマット共通**（`body`・`h2`・`aside`・`box`・`fig`…）。だから、同じ入力で `format`・`variant` を変えるだけで、文が欠けずに付け替えられる。
- `status` が `provisional` の変種は、測定が 1〜2 ページ・または本の判別が仮。見た目が合っているかを確かめきれていないと報告する。

## 3. 規則を直す流れ（学習の更新）

- 規則の食い違い（測定と合わない・利用者の採点で落とされた）を見つけたら、その規則の印を［推］→［測］（再測定で確かめた）／［利用者］（利用者の採点で決まった）に改める。**優先順位：利用者の指示・採点＞測定＞推**。
- 更新は規則番号つきで記録する（例：「R4 CASE 枠の上限を 2 から 3 に：見開き 1 面に 3 件の例があったため」）。規則の本文を黙って書き換えない。

## 4. 新しい本（画像）を受け取ったとき

画像・本文は**公開リポジトリに入れない**（作業用の一時領域に置き、結果だけ数値で残す）。個人情報は伏せる。本の題名・出版社は特定せず、「型」で書く。

1. 受け取る：画像をリポジトリの外に置き、番号・時刻・サイズの一覧を作る。
2. 判別する：撮影順の連続・字詰め・行数・部品の語彙で本を分ける（既存の本と混ざっていないか確かめる）。
3. 形を分ける：単ページ／見開き／切り抜き。**紙の縦横比は見開きの画像から**（見開きが無ければ［不明］とし、近いファミリーの比率を仮に使う）。
4. 測る：全ページを同じ手順で測る（行数・行送り・本文の外接・余白・罫・色・ノンブルの位置）。本文の列の範囲（傍注・注欄を避ける）は本ごとに決める。
5. 目録に 1 行足す（`formats/catalog.tsv`）。
6. ファミリーを決める：字の大きさ ±3%・送り÷字 ±3%・行数 ±1・ノンブルの型が同じ・見出しと囲みの部品の重なり 60% 以上を満たせば既存ファミリーの**差分（変種）**。満たさなければ新しいファミリー（`fam-fN`）。
7. 部品を拾う：既存の部品に当てはまらないものは新しい部品として id と描き方を足す（描き手の実装は GNOTO 側）。値は**画像から測った値だけ**。測れないものは［不明］。
8. フォーマット JSON を書く：値は**その本の測定の中央値**（1 枚の値は使わない）。スロット名は既存と**そろえる**。測定の半分でフォーマットを作り、残りの半分で検証する（過学習を防ぐ）。
9. 規則を足す：使い方の規則は［推］から始め、頻度を数えて［測］に直す。10 枚未満の本は頻度の規則を作らない。
10. 報告：走らせなかった検査・不明・確認したいこと（判型・pt・書体・字詰めの現物の 1 か所）を書く。

## 5. 雑誌・新聞に広げるとき（書き込む雛形）

教科書との違い：色（カラー）・段（2〜6 段・段間・跨ぎ）・書字方向（縦書き）・見出し（記事ごとに独立・リード・キャプション）・画像（写真・広告は占有領域だけ測る。中身は記録しない）・ページの型（表紙・目次・広告・特集）。フォーマットの `base` に `cols`・`gutter`・`writing` を足し、`palette` を持たせ、スロットに `headline`・`lead`・`caption`・`photo`・`byline` を足す。`catalog.tsv` は雑誌 `M1…`（ファミリー `G1…`）・新聞 `N1…`（`H1…`）の行を足す。縦書きの測り方（行送りの周期を縦に取る）は横書き前提の測定手順に足す必要がある［未実装］。

## 6. 学習したこと・していないこと

- した：5 冊・約 100 枚の教科書の画像から、寸法・部品・規則を言語化した（測定の手順と値は非公開の置き場）。
- していない：Laba の実際の出力に規則を当てた前後比較（分かりやすさが上がったかの評価は、利用者の採点が基準で［不明］）。使い方の頻度の統計。フォント（書体）の確定。docx への写し。
