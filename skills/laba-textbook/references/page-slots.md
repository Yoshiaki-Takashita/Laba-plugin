# スロットの要約（page-slots）

Laba が書く前に読む。フォーマットの全文（`formats/*.json`）は読まない。最新は `python3 ${CLAUDE_PLUGIN_ROOT}/skills/laba-textbook/scripts/textbook_page.py slots --format fam-f1 --variant b1` で出る（この表はその写し）。

- スロット＝ページの中の「役割の入れ物」。位置・大きさ・書体は GNOTO がフォーマットから決める。Laba は、スロット名と文だけを書く。
- kind：`text`＝1 段落／`md`＝最小のマークダウン（`#`〜`###` 見出し・`- ` 箇条・`1. ` 番号・空行で段落・`**太字**`）／`notes`＝注の配列（`items[{ref,no,text}]`。`ref` は本文の印 `[^キー]`）／`fig`＝図の id。
- マスター（ページの種類）：`chapter`（章扉）・`body`（本文ページ）。GNOTO のひな形は、body に `fig` があれば「本文＋図」、`box` があれば「本文＋囲み」になる（**1 ページに図と囲みを両方置くと、囲みは本文の流れの中に入る**）。
