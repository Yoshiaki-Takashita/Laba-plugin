# 教科書の組みの規則（20 行の短縮版）

毎回これだけ読む。根拠・例外は `rules.md`、スロットは `page-slots.md`、図は `figure-spec.md`。

```
文章を役割に分け、役割ごとにスロットを決める。座標・色・書体は書かない。
本文(body)＝1 段落 3〜7 行・定義語は太字。定義を枠に入れない。
事例＝box(CASE)に 3〜8 行・A/B/C の記号で・論証は本文で。
補足＝aside に 60 字まで・本文に [^キー] を置く。それより長ければ本文か Column。
発展の読み物＝box(Column)・章に 2〜5 件・必須内容を入れない。
章頭に overview(5〜9 行)・節末に point(3〜5 項目・1 項目 27 字まで・主語＋述語)。
見出しは名詞句・節 20 字・項 24 字まで・4 段まで・兄弟のいない見出しを作らない。
図は条件に当たるときだけ：関係(3 人以上)→relation／分岐→flow／木→tree／日付 3 つ以上→timeline／比較→table(2 軸なら matrix)／包含→concept。
図は 1 ページ 1〜2 つ・flow は箱 5〜9・tree は 3 階層・timeline は 3〜8・図の前後の本文で一度言及する。
囲みは入れ子にしない・1 ページに 2 つまで。番号・頁・柱は書かない。出典は確認済みだけを書く。
```

補足（短縮版で足りない所）：
- 役割への振り分け：本文／事例（box）／定義（本文中の太字）／補足（aside）／発展（box・Column）／要点（point）／図（fig）。迷ったら本文。1 段落＝1 役割。
- 章扉ページ（master=chapter）は `title`（必須）と `overview`（任意）だけ。本文ページ（master=body）は `h2`・`h3`・`body`（必須）・`aside`・`box`・`fig`・`point`。
- 本文 1 ページの目安は `textbook_page.py slots --format … --variant …` で出る字数（字詰め×行数）。超えても GNOTO が次のページへ流す。足りないときは足りないと報告する（字数合わせの水増しをしない）。
- 句読点は変種に合わせる（b1・b2＝「，．」／b4＝「、。」）。変種が仮（provisional）のときは、見た目を確かめきれていないと報告する。
- やってはいけないこと：座標・大きさ・色・書体の指定／節・項・図・注の番号／教科書の文章・図の中の語の書き写し／確認していない出典。
