# P0 依頼の形（`topic.json`）

最初の回に 1 回だけ、まとめて聞く。聞けないときは既定で進め、報告に「既定で決めた」と書く。

| 聞くこと | 選択肢 | 既定 |
|---|---|---|
| 題の種類 | `word`（単語 1 つ）・`field`（分野名）・`sourced`（資料つき） | 資料が渡されていれば `sourced`、1〜2 語なら `word`、分野名なら `field` |
| 読者の段 | `hs`（高校生）・`ug`（学部生）・`grad`（大学院生） | `ug` |
| 分量 | 1 節（約 1,200〜1,600 字）・1 章（3〜6 節）・本（章立てだけ先に） | 資料つき＝1 節、単語＝1 章、分野＝章立て＋第 1 章 |
| 言語 | `ja`（この版は日本語だけ） | `ja` |
| 紙面にするか | する（laba-textbook へ渡す）・しない | しない（文章だけ） |

- 段の数値：`hs` は文の中央値 45〜55 字（推。測定は大学の教科書だけ）、`ug`・`grad` は 55〜68 字（測）。値は `writer-brief.md` と `scripts/targets.json`。
- 英語・他言語の教科書の数値は無い（不明）。頼まれたら、日本語の数値を使わず、reportkiller の `prose-en.md` に従うと伝える。

## `topic.json` の形

```json
{"seed": "発注点方式", "kind": "sourced", "level": "ug", "lang": "ja",
 "size": "section", "source": "work/source.txt", "page": false}
```
`size` は `section`・`chapter`・`book`。`source` は資料が無ければ `null`。

## 題の種類で変わること

- `sourced`：範囲は資料の範囲（`outline.md` 1）。資料にない事実を足さない。資料が薄い（700 字未満）ときは、本文が目標の字数に届かないことがあると先に伝え、**字数を水増ししない**。
- `word`・`field`：範囲を自分で決める（`scope.md`：標準の章立てを確認先つきで・`map.json`）。主張は台帳の ID つきでだけ書く（`sources.md`：V0 を載せない・見つからない＝存在しないではない・法学はコネクタ）。ウェブもコネクタも使えない環境では、確かめられることが無いので、章立て（未確認と明記）だけを渡し、本文は書かないか、利用者に資料を求める。
