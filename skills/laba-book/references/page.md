# P6 紙面（章 → GNOTO の紙面ノート .gnoto）

本文（P4）と図（P5）が済んだ章を、GNOTO で開ける紙面ノートにする。**親（この入口）が行う**。道具が組む（座標・色・書体は書かない）。

## 1. 1 行で

```
python3 ${CLAUDE_PLUGIN_ROOT}/skills/laba-book/scripts/book_state.py page work/ch<n> --out out/book-ch<n>.gnoto [--format fam-f1 --variant b1] [--plan work/ch<n>/plan.json]
```
- 読むもの：`work/ch<n>/outline.json`（章の題）・`chapter.md`（無ければ構成の節の順に `s*.md`）・`figs.json`。台帳の印 `[R01]` は外す（紙面に出典は出さない）。
- 書くもの：紙面の指示 **v:2（読む順の塊）**の `.gnoto`。章扉（「第 n 章　題」）＋本文のページ。誤りがあれば書かない。
- 既定の本の型は `fam-f1` の `b1`（測定済み・傍注の列あり）。ほかの型は `textbook_page.py formats`。

## 2. 道具がすること（形は laba-textbook `references/output-format.md` の 7）

| 本文の印 | 紙面の塊 |
|---|---|
| `#` 節・`##` 項・`###` 目 | 見出しの格 `h2`・`h3`・`h4`（b1 の節は輪郭数字。番号が無ければ節の順の数を頭に付ける） |
| 段落 | `p`（字下げ 1 字） |
| `:::box` | 囲み（b1＝事例の枠 CASE） |
| `:::aside` | 傍注（直前の段落の行に。傍注の列の無い本は脚注の帯） |
| `:::fig id=…` | 図（`figs.json` の記述をそのまま `page2.figs` に。大きさは描き手の SVG から・題は本の札〈b1＝CHART〉） |
| `:::point` | 枠なしの囲みの行（「・」を頭に。GNOTO に要点の枠の部品が無い） |

- **ページの区切りは道具が決める**（GNOTO はページをまたいで文を流さない）。GNOTO の行の数え方の写し（字詰め・見出しの行・囲みと図の高さ）で 1 ページの行を見積もり、入らない段落は文の切れ目で次のページへ分ける（続きは字下げの段落になる）。入らない図は次のページの頭へ送り、後の段落で今のページを埋める。
- 検査（`textbook_page.py check` と同じ）：GNOTO の読み込み（`pgSanPage2` の lite v:2）の写しで落ちる・変わる欄が 0／全部の pid がどれか 1 つの塊に置かれる（未配置 0）／傍注の参照が同じページ／図の記述の検査／見積りでどのページも 1 ページの行以内。

## 3. 報告に書く

- 本の型と変種・ページ数・ページごとの見積りの行（`plan.json`）・段落を分けた数・送った図。
- **GNOTO で開いて見たか**。チャット・この道具だけでは開けない＝「見た目は確かめていない（見積りは写し）」と書く。開ける環境（GNOTO の開発側の検証の道具）があれば、未配置・あふれ・字の重なり・図の位置を見る。

## 4. してはいけないこと

- 座標・色・書体・字の大きさを書き足す（GNOTO が本の型から決める）。
- 見積りを通すために本文を削る・言い換える（分けるのはページの区切りだけ）。
- 見た目を確かめていないのに「紙面を確かめた」と書く。
