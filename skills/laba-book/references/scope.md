# P1 範囲：単語・分野から章立てを立てる（`map.json`。資料なしの題）

資料が無い題（`word`・`field`）では、扱う範囲を自分で決める。決め方の芯は二つ：**その分野で標準とされる章立てに合わせる**（自分の思いつきで並べない）と、**章立ての根拠を確認先つきで残す**（後で人が確かめられる）。資料つきの題（`sourced`）はこの文書を使わず、`outline.md` 1 の 1 に従う。

## 1. 手順

1. **分野を決める**：`field` はその分野名のまま。`word` は、その語がふつう教えられる分野と、その分野の章立ての中の位置（どの章の中で出てくるか）を決める。分野が 2 つ以上ありうる語（例：同じ語が経済学と会計学で別の意味）は、`topic.json` の段と依頼の文から 1 つを選び、選ばなかった分野を `excluded` に書く。
2. **標準の章立てを確かめる**：その分野の標準的な章立てを、**種類の違う 2 つ以上の確認先**で見る。確認先の型は下の 2。見たものは出典の台帳（`sources.md`）に行を作り、その ID を `map.json` の `standard.check` に書く。章立て（目次・シラバスの項目の並び）だけを見たなら、その行の使い方の欄に【構成】と書く（中身の根拠には使わない）。
3. **概念を挙げる**：書く章の概念を 5〜15 個挙げ、**前提の向き**（A を知らないと B が分からない）を `pre` に書く。前提は同じ章か前の章の概念だけ。1 節に新しい概念は 2〜4 個まで。
4. **外すものを決める**：隣の分野・発展の話題・段（`hs`・`ug`・`grad`）に合わない話題を `excluded` に理由つきで書く（1 つ以上）。
5. **検査**：`python3 ${CLAUDE_PLUGIN_ROOT}/skills/laba-book/scripts/book_state.py map work/map.json --ledger work/ledger.tsv` が誤り 0 になるまで直す。その後で `outline.md` 2〜3 の規則で、書く章の `outline.json` を作る（節の `terms` は地図の概念から取る）。

確認先が 1 つも見つからない・開けない環境では、章立ては自分の知識で立ててよいが、`standard.check` を空にして `standard.note` に「確認先なし（未確認）」と書き、報告の冒頭に出す。**見つからないことは「標準の章立てが無い」ことではない**。

## 2. 確認先の型（分野ごと。章立てと中身の両方に使う）

| 分野 | 章立ての確認先（構成） | 中身の確認先（主張の根拠） |
|---|---|---|
| 高校までの教科 | 学習指導要領・その解説（文部科学省）の項目の並び | 同じ解説の本文・検定教科書の出版社の公開資料 |
| 大学の分野一般 | 大学の公開シラバスの授業計画（2 校以上）・学会の教育の指針（例：分野別の参照基準）・定番の教科書の目次（出版社の書籍ページ） | 学会・公的機関の用語集や解説・査読論文（DOI）・百科事典の署名つき項目 |
| 法学 | 体系書・教科書の目次・法学部のシラバス | **条文は laba のコネクタ**（`law_get_article`。無ければ e-Gov 法令検索を手で開く）・判例は `case_verify_citation`／`case_get`（無ければ裁判所の判例検索）。手順は `skills/laba/references/connector.md` |
| 理工・医療 | シラバス・学会の教育の指針・規格の目次 | 規格（JIS・ISO の書誌と公開部分）・学会の用語集・査読論文・公的機関の解説（理科年表・統計） |
| 語学 | 学習指導要領・CEFR などの枠組みの記述・シラバス | 辞書・文法書の書誌と公開部分・国の機関の資料（文化審議会の答申など） |
| 歴史 | 学習指導要領・シラバス・定番の通史の目次 | 史料集・公的機関（国立公文書館・国立国会図書館）の公開資料・査読論文 |

- 統計・年・数は、それを出した機関の公開資料（原典）で確かめる。孫引き（まとめサイト・ブログ）にしない。
- 検索結果に出た URL をたどる。記憶で URL を組み立てない（`citation-ledger.md` 3）。

## 3. `map.json` の形

```json
{"seed": "比較優位", "kind": "word", "level": "ug",
 "field": "国際経済学",
 "standard": {"check": ["R01", "R02"], "note": "シラバス 2 校と教科書の目次 1 冊で、貿易の理論の章の中で扱われることを見た"},
 "chapters": [
  {"no": 1, "title": "貿易の理論", "concepts": ["c1", "c2", "c3", "c4", "c5"], "check": ["R01"]}
 ],
 "concepts": [
  {"id": "c1", "name": "機会費用", "pre": [], "check": ["R03"]},
  {"id": "c2", "name": "絶対優位", "pre": ["c1"], "check": ["R03"]},
  {"id": "c3", "name": "比較優位", "pre": ["c1", "c2"], "check": ["R03"]},
  {"id": "c4", "name": "特化", "pre": ["c3"], "check": ["R04"]},
  {"id": "c5", "name": "交易条件", "pre": ["c4"], "todo": ["学会の用語集の該当の項"]}
 ],
 "excluded": [{"name": "新貿易理論", "why": "発展の話題（段 ug の第 1 章では扱わない）"}],
 "write": {"chapter": 1}}
```
- `field` の題は、`chapters` に標準の章立て全体（5〜15 章）を書き、`write.chapter` に今回書く章を書く。`word` の題は、語を扱う章を 1 つ以上書く。
- 各章・各概念の `check` は台帳の ID（V1〜V3。章立ては【構成】の行でよい）。確かめられなかったものは `check` を空にし、`todo` に確認先の候補（例：`"e-Gov 民法 166 条"`）を書く。`todo` のある概念は、確かめるまで本文で定義しない。
- 番号・座標・紙面の指定は書かない。
