# 建築図の共通仕様（作図の約束）

背景：レポートやポートフォリオの建築図（平面・断面・立面・展開図・階層別の図・アクソメなど）が
「Opus の実力にしてはチープ」。製図の約束事と細部まで作り込んだ、本格的な建築図を生成できる道具を作る。
比較の元：作図の見本（断面に見えがかり・材料・開口・レベル表記が無い、
平面に開口・寸法・方位が無い、線の太さが1段、図が版面からはみ出す）。

根拠の研究（研究ノート。同梱しない）：FIG-ARCHITECTURE（建築の優秀作 163 件の実測）、
FIG-PRINCIPLES（図の一次資料）、FIG-STUDENT-PORTFOLIOS。記憶でなく製図の規格（JIS A 0150 建築製図通則・
JIS Z 8114／Z 8316・ISO 128・ISO 7519）を一次資料で確かめて使う。確かめられないものは「判断」と明記。

## 1. 出力の形
- SVG（ベクタ）。座標の単位は「紙の上の mm」。縮尺は図ごとに指定（1:20／1:50／1:100／1:200／1:500）。
- 生成は Python 3 標準ライブラリだけ（Python 3）。外部の作図ライブラリに頼らない。
- PNG の確認：`convert -density 600 in.svg out.png`（ImageMagick）か、ヘッドレス Chromium
  （自分の環境の Chromium と playwright-core）。
  PNG は必ず Read で見て、細部まで目で点検する。
- 書体：和文・欧文とも 1 書体族（サンセリフ）。SVG では font-family="'Noto Sans JP','IPAGothic','Helvetica Neue',Arial,sans-serif"。
  文字の大きさは紙の上で 3 段以内（例：注記 2.0mm・室名 2.5mm・図題 3.5mm）。

## 2. 線の体系（紙の上の太さ・mm。ISO 128 の系列）
| 用途 | 太さ | 線種 |
|---|---|---|
| 切断面の輪郭（壁・床・屋根の切り口） | 0.50〜0.70 | 実線（切断面は塗り＝ポシェか材料ハッチ） |
| 見えがかり（切断面の奥に見える輪郭） | 0.25 | 実線 |
| 遠い見えがかり・家具・設備 | 0.13〜0.18 | 実線 |
| 隠れ線・上部の輪郭（吹抜・庇・梁） | 0.18 | 破線 |
| 通り芯・中心線 | 0.13 | 一点鎖線 |
| 寸法線・引出線 | 0.13 | 実線＋端末記号（矢印か斜線・黒丸を図の中で統一） |
| 地盤線 | 0.70 | 実線＋地盤のハッチ |
- 線の太さの比は、切断面：見えがかり＝おおむね 2〜3 倍以上（FIG-ARCHITECTURE の実測：細と太の比 3〜5 倍）。
- 色は黒 #1A1A1A を基本。灰 #8C9493 は文脈（周辺の建物・既存部分）にだけ。強調 #943522 は1図に1つの意味だけ
  （例：提案部分・論点の壁）、面積は図の 3〜6%。それ以外の色は使わない。

## 3. 必ず描くもの（図の種類ごとの最低限。担当は自分の図でさらに作り込む）
- 平面図：切断高さ FL+1,000〜1,500 の壁のポシェ（構造と間仕切りを太さか塗りで区別）、開口（ドアの開きの弧、引戸、窓の枠と
  ガラスの線、掃き出し）、階段（踏面の線・上り下りの矢印・切断線）、上部の輪郭（破線）、家具・設備（細線）、室名、
  通り芯と符号（X1, X2…／Y1, Y2…の丸）、寸法（全体・通り芯間・開口）、方位記号、スケールバー、縮尺、断面の位置の記号。
- 断面図：切断面（ポシェ・材料）と見えがかりの区別、地盤（GL）と地盤のハッチ、床・天井・屋根の厚み、開口の切断と見えがかり、
  階段の踏面・蹴上、レベル記号（GL・1FL・2FL・軒高・最高高さ）、階高と寸法、隣地・道路との関係、人のスケール（線で描く人物）。
- 立面図・展開図：外形と開口、仕上げの目地（必要な所だけ）、地盤線。展開図は室ごとに壁 A〜D を展開し、キープラン（どの壁か）を付ける。
- アクソメ・分解アクソメ：正確な投影（等角か、平面を 30/60・45/45 で立ち上げるプラノメトリック）、隠れ線の処理、
  分解の案内線（破線）、層ごとのラベル。
- 共通：図題（図の下。「図n　主題（縮尺）。出典」）、スケールバー（実寸の目盛）、方位（平面・配置）、版面からはみ出さない構図。

## 4. 共通の題材（全員が同じ建物を描く＝図どうしの整合を確かめる）
見本の住戸を、設計条件として固定する（寸法は mm）。
- 敷地：路地（幅 2,700。南側）に面した間口 5,400 × 奥行 9,000 の敷地。路地の境界から 650 後退して外壁。北・東・西は隣地（木造 2 階）。
- 建物：木造 3 階建て（在来軸組を想定）。外壁の芯で 5,400（X1〜X3、X1-X2 2,700・X2-X3 2,700）× 8,100（Y1〜Y4、2,700 ずつ）。
  外壁厚 150（耐火の外壁：仕上げ込み）、間仕切り 100。
- 階高：1F 3,000（土間：FL=GL+150）、2F 2,800、3F 2,700。屋上（陸屋根・パラペット 1,100）。最高高さ GL+9,000 程度。
- 平面：1F＝土間（作業場・店）と WC、階段は東の界壁沿いの直階段（幅 800、蹴上 ≒200、踏面 ≒220）。2F＝居間・食堂・台所。
  3F＝寝室 2 と浴室。路地側（南）は 1〜3F とも大きな開口（耐火の窓）。北側は小さな窓。
- 断面の位置：建物の中央（X 方向に切る A-A'）と、階段を通る B-B'。
- 足りない条件は、各担当が「判断」として決め、各自の README に書く。

## 5. 置き場（衝突しないよう、自分のフォルダだけを触る）
自分のフォルダに：生成のコード（*.py）、examples/（SVG と確認用 PNG）、README.md（使い方・描いた要素・
根拠の規格・判断したこと・自己点検の結果）。共通の部品は後で統合担当が core にまとめるので、今は各自のフォルダで完結させる。
他のフォルダは触らない。

## 6. 自己点検（渡す前に必ず）
600dpi の PNG を Read で見て：線の太さの段が意図どおりか、切断と見えがかりが一目で分かるか、文字が重ならず語の途中で切れていないか、
寸法が正しい（設計条件と一致）か、版面からはみ出していないか、AI らしい飾り（角丸・影・グラデーション・アイコン・多色）が無いか。
寸法と設計条件の一致は、コードで数値を検算する。

## 7. AIらしさを消す研究の要点（2026-10-23 追記）
根拠：研究ノート FIG-STUDENT-PORTFOLIOS（海外の学部生の図 400 枚）・FIG-PRINCIPLES（一次資料）・FIG-ARCHITECTURE、
と伏せた評価（採点者 2 人）で見つかった図の癖。
1. **具体で濃くする**：人の優秀な図にあって AI の図に無いのは「具体」。主張に関係する数値の注記（寸法・高さ・面積・距離）、
   意味のある参照線（GL・後退線・隣地境界・延焼の線）、名前の付いた範囲、出典と「筆者作成」の断り。飾りでなく情報で濃くする。
2. **道具の既定を残さない**：既定の太さ・既定の色・図の中に図題と同じ題を重ねる・既定の背景色。値はすべて意図して決める。
3. **評価で見つかった癖を避ける**：要素を記号（A〜E など）だけで示して図題に頼る／流れの図なのに矢印を省いて表のようにする／
   流れと対応など別種の関係を一枚に混ぜる（混ぜるなら線種で分け、凡例でなく直書き）／始点・終点だけ形式が違い階層が崩れる／
   図題が断片的な文。ラベルは図だけで意味が取れる語にし、図題は「何を示すか＋読み方＋縮尺・出典」の完全な文にする。
4. **白黒で強調が残るか**：強調 #943522 と灰 #8C9493 は明度差のある組。元の #C2543A と #6F7877 は白黒で同じになるので使わない。
