# arch-masters：ライトとル・コルビュジエ研究（索引）

目的：近代建築の原点を見直し、建築のレポート・ポートフォリオの図（`scripts/archstudio`）に両者の作品と図面の約束を使えるようにする。図の複製はしない。

| 担当 | 範囲 | 成果 | 状態 |
|---|---|---|---|
| 時期別 1〜4 | 両者の作品研究（時期別） | 各担当のファイル（担当が追記） | 不明（本担当は未確認） |
| 横断 | 図面表現の約束と数値化・比較 | [drawing-conventions.md](drawing-conventions.md) | v0.1 |
| 横断 | 全作品目録（catalog.json） | 配布版には入れていない | 元は Wikipedia の作品表の転記（V2。632 件）。ファイルが 256 KiB を超え、転載の条件も別なので外した。作品の確認は `rules.json` の `works` と `deep/` を使う |

確認段階：V0 記憶のみ／V1 二次資料・本文未照合／V2 本文照合／V3 一次資料で実測。
目録への追加は時期別担当の成果で行い、`verification` を上げる。

注：`rules.json` の `sources`・`raw_rules` にある `data/arch-masters/…json#…` は、規則の元になった研究の機械可読版を指す識別子で、配布版には入っていない（同名の `.md` を `deep/` と本フォルダに置いた）。
