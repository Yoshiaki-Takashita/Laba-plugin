# フランク・ロイド・ライト：初期〜プレーリー期（1887–1915頃）

作品ごとのデータ（25 件）：同名の機械可読版（同梱しない）。図は載せない。数字と規則だけを置き、出典と確認段階を付ける。
HABS（米国歴史的建造物調査）は連邦政府の記録でパブリックドメイン。

- **V2**：LOC の HABS 記録で確かめた。説明ページ（data pages）の本文か、図面を画像として読んだもの。

- **V0**：一般知識。今回は確かめていない。
- **不明**：推測で埋めない。

## HABS から読めた細部（V2）
- **グリッド**：Robie の主階平面（図面 3 枚目）では、柱と方立の間隔が 4'-0" の繰り返しで寸法記入されている（南の掃き出し窓の列・北の壁）。ほかの作品はグリッドの記載がなく、不明。
- **天井高**：Martin は「すべての天井が 7½ ft」。Boynton は 1 階の各部屋に、天井の 1'-10" 下を一周する見切り材（1"×5"）を回し、開口の高さをその線で決める。食堂の天井は 3 段（朝食の張り出し・鉛ガラス入りの下がり天井・高窓の上端）。
- **入口**：Martin の玄関の開口は高さ 6'-4" と低く、狭い前室から右に折れて居間に入る。Robie は地上階の北西角、煙突の向かいから入る。Unity は長辺の中央から入り、側廊の下を通って奥で半階上がる。Boynton の前室はホールより 3 段低い。
- **見切りの帯**：Robie は戸の上端の高さに幅 4½" の帯を一周させ、すべての戸と窓の上枠にする。幅木は 9"。Unity は 1½"×3/8" と 2½"×5/8" の帯。Winslow は連続する上端の見切り。
- **軒**：Robie は鋼の溝形材で片持ちにし、幅 2 ft 近い銅の樋を回す。Boynton は軒天の外周 19" を木の帯にする。
- **家具**：
  - Boynton の食堂は当時のまま：食卓 2 台と椅子一式、隅の柱に明かりを組み込んだ花台、窓の下のガラス戸付き本棚。
  - Bradley：西に作り付けの食器棚、東に作り付けの台。食卓の上の梁の間にアートグラスの照明。
  - Martin の食堂一式（椅子 10 脚・食卓・食器棚）は Heath 邸へ移されている。製作はおもに Niedecken-Walbridge 社。
  - Robie：主階の照明は木枠の球形灯と格子の奥の埋込み灯。北の壁の作り付けビュッフェは撤去。
  - 自邸：寝室の両端に作り付けの箪笥と、その両脇の収納。
- **素材**：Martin の煉瓦は横目地を深く、縦目地を浅くし、外の角はすべて直角に組んだ一対の柱。Robie はローマン煉瓦 2"×12" と灰色の石。Boynton のローマン煉瓦は 12"×4"×1½"。

## 生成規則（設計ソフト向け）
出典つきの値は［出典］、仮定は［仮定］と書く。

1. `unit` = 4'-0"（1219 mm）。窓の方立と柱を unit の間隔で並べる［Robie の HABS 図面］。ほかの作品へ一般化できるかは不明。
2. `core`：暖炉と階段の塊を、平面の中央付近に置く［Robie・Boynton・Bradley・Winslow の HABS 本文］。Robie 型では、塊の上部を開けて両側の部屋を見通せるようにし、両脇を通れるようにする。
3. `wings`：型を選ぶ。十字（Martin・Bradley・Willits）、細長い直線に小さな横軸（Boynton・Robie）、軸上の対称（Winslow・Unity）、棟の分散（Coonley）。翼の比の参考：Dana の東端の奥行は 8'-4½" : 17'-8" : 13'-7" : 17'-8" : 8'-3½" で、中央の軸をはさんで対称［HABS 図面］。
4. `entry`：高さ 6'-4" 程度の低く狭い前室から、90° 曲がって主室に入る［Martin］。主室の床は入口より 3 段から半階高くする［Boynton・Unity］。
5. `section`：
   - 天井 7'-6"［Martin］。見切りの帯は天井から 1'-10" 下［Boynton］。
   - 戸の上端の帯を部屋ごとに一周させる［Robie］。
   - 天井は 2〜3 段にし、いちばん低い段を食卓や窓際に置く［Boynton］。
   - 主階の床の高さ：地面から約 4 ft［自邸］。地下を地上に上げ、低い組積の台座にする［Martin。ライト本人の言葉の引用］。
6. `openings`：開き窓を帯状に連ねるか、掃き出し窓を対にして列にする［Robie・Boynton・Martin］。窓の上端は戸の上端の帯にそろえる［Robie］。
7. `eaves`：寄棟の軒の出は大きくし、片持ちは鋼材で支える［Robie］。具体的な出の寸法は不明。
8. `furniture`：
   - 食堂の食卓は四隅の柱に明かりを入れ、天井の下がり壁の中にもガラスの照明を入れる［Boynton］。
   - 作り付けの食器棚は壁の短辺側に置く［Bradley］。
   - 暖炉の脇に作り付けの長椅子か本棚を置き、放熱器はその下に隠す［Bradley］。
   - 窓の下に低い本棚を置く［Boynton］。
9. `materials`：基壇・暖炉・角の柱は組積にする。上部はスタッコに木の帯（Bradley・Boynton）か、煉瓦（Robie・Martin）。
10. 検査：core が重心から 1 unit 以上ずれていないか。戸の上端の帯が途切れていないか。入口から主室へ直進できてしまわないか。

## 走らせなかった確認とその理由
- **HABS の図面の多く（Robie 25 枚、Martin 27 枚、Bradley 25 枚、Coonley 17 枚、Dana 15 枚）は、1〜2 枚しか読んでいない**。原寸の TIFF は 1 億画素を超え、1 枚ずつ切り出して読む必要がある。家具の配置・断面の寸法・グリッドは、残りの図面からまだ読める。
- **NRHP 推薦書**：Robie は検索結果の抜粋だけ。Willits（80001380）ほかは開いていない。
- **未読**：FLW Trust と FLW Foundation の各作品ページは一部の確認だけ。CMU の資料、Storrer・Hildebrand・Wasmuth・Koning–Eizenberg の本文も読んでいない。
- **HABS の記録が見つからなかった作品**：Willits・Heurtley・Thomas・Cheney・Evans・Hickox・Fricke・Husser・Gale・Larkin・Midway。このため寸法は不明のまま。
- 図面から読んだ数字のうち、Robie の階高（7'-6" ほか）と Winslow の幅の一部は 1024 px の画像から読んだもので、読み違えのおそれがある。
