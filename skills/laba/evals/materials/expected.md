# 試験用の資料の合格条件

機械検査の値は、`scripts/inventory.py` をそのまま走らせた値（見出しは目で補正する前）。スクリプトを直したら、値を取り直す。

## resume-A（レジュメ型）

期待されるノート
- です・ますの解説。章の頭に「前提」（意思表示の構造、意思の不存在と瑕疵ある意思表示）。
- Q1〜Q5 の全部に太字の「答え」。
- 設例は、請求→抗弁→再抗弁の型で論じ、結論を言い切る（Aは、善意のCに対して、無効を対抗できない。Cに登記は要らない、とするのが判例）。主張の位置は、請求の立て方に即して決める。
- 図：虚偽表示の当事者関係（A・B・C）と、94条2項の類推適用の3要素。表：心裡留保と虚偽表示の比較（効果・第三者の要件）。
- 判例は、資料が「判例」とだけ書いている。補うなら、確認して、補ったと報告する。確認できなければ「判例は」にとどめる。

必ず見つけるべき資料の誤記
- 末尾の（注）「錯誤（95条）。効果は無効。」→ 現行法では、錯誤の効果は取消しである（95条1項）。本文は正しい形で書き、報告に挙げる。

合格条件
1. 5つの問いの全部に答えがある。
2. 設例に、太字の「結論」がある。
3. 上の誤記を報告している（黙って直していない、そのまま写していない）。
4. 96条3項の第三者（善意無過失）と、94条2項の第三者（善意）の違いを、表か文で示している。
5. 条文（93条1項・2項、94条1項・2項）の要約が、現行の条文と合っている。
6. 資料にない判例の理由を、判例の理由として書いていない。

## resume-B（設例中心型）

期待される結論（条文は現行の民法。試験のときに照らすこと）
- 設問1：認められない。弁済期（2021年4月1日）から5年で、2026年4月1日の経過により時効が完成する（166条1項1号。Gは契約の時から弁済期を知っている）。提訴はその後であり、Sの援用により債権は消滅する。
- 設問2：認められる。2025年10月1日の手紙は権利の承認にあたり、時効は更新され、その時から新たに進行する（152条1項）。2026年5月1日の時点で時効は完成していない。
- 設問3：援用することができない（判例）。時効の完成後に債務を承認した者は、完成を知らなかったときでも、信義則上、援用することが許されない。146条の放棄ではない点も書く。
- 設問4：認められる。2026年3月1日の催告により、その時から6か月を経過するまでは時効は完成しない（150条1項）。同年8月1日の提訴は6か月以内であり、裁判上の請求により完成が猶予される（147条1項）。

合格条件
1. 冒頭に「前提：請求・抗弁・再抗弁」の表がある。
2. 見出しに【請求】【抗弁】【再抗弁】がある。時効の完成・援用が抗弁、更新・完成猶予・援用の制限が再抗弁に置かれている。
3. 4つの設問の全部に、1文で言い切った「結論」があり、上の結論と一致する。
4. 時間軸の図（2021年4月1日、2026年4月1日、各設問の日付）がある。
5. 結論一覧の表がある。
6. 起算日・満了日の計算が正しい。
7. 設問3で、判例の書誌を書くなら、裁判所の判例検索で確かめている。確かめていないなら「判例は」にとどめている。

## textbook-C（教科書型）

機械検査で出るはずの値：判例3件（平成9・2・14、平成2・1・22、平成19・7・6）、条文は388条・389条1項。資料の体は、である調、読点「，」。

期待されるノート
- 本文は、である調・読点「，」。`style_check.py` の WARN が0。
- 見出し 8-3-1〜8-3-4 が1対1で対応。
- 判例3件が、資料と同じ書誌で載っている。判例の理由は、資料の説明と、判決文で確かめたものを分けている（確かめていないなら「判決文は確認していない」）。
- 図：①土地だけ／建物だけに抵当権がある場合の比較、②共同抵当と再築の価値配分、③一番抵当権・二番抵当権の時間軸、のうち2枚以上。
- ざっくり理解：法定地上権の意義の前。
- 論点カード：3〜5枚（資料が短いので、少なくてよい）。
- 一致の検査：生の値と除外後の値の両方を報告。地の文の流用がない。

合格条件
1. `coverage_check.py` の欠落が0。
2. `style_check.py` の WARN が0。
3. `reason_source_check.py` の所見が0。
4. `match_check.py` の除外後の最長が30字程度まで。
5. 図が2枚以上、`fig_lint.py` で error 0。図の要素に本文の根拠がある。
6. 資料の「もっとも，…という批判もある」（確度）が、ノートでも保たれている。
7. 389条1項の要約で、限定（抵当権の設定後に抵当地に建物が築造されたとき）を落としていない。
