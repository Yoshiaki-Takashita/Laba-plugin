# 採点・検査の結果から、次に何を直すか

`scripts/pipeline.py` のレポートの「次に直す点」は、この表による。16指標のそれぞれについて、「どの値が、どの線を下回ったら、何を直すか」を1行ずつ決めてある。指標ごとの詳しい手順は `../metrics/` の各ファイル。

## 目次
1. 使い方　2. 16指標の決定表　3. 指標に属さない所見　4. 優先度の付け方　5. 引っ張り合う指標　6. 回す回数と止めどき　7. 疑似コード

## 1. 使い方

1. `pipeline.py` を走らせ、`report.md` の「次に直す点」を見る。
2. 優先度1〜2は全部直す。優先度3は、点の低いものから2〜3個まで。優先度4は、優先度1〜3が無くなってから。
3. 直したら、全部の検査を走らせ直す（一つを直すと、別の指標が動く。5節）。
4. 機械の所見が誤検知だと判断したら、理由を控える（網羅は `--coverage-ignore`、ほかは報告の「機械の誤検知」の欄）。黙って無視しない。

## 4. 優先度の付け方

| 優先度 | 意味 | 当たるもの |
|---|---|---|
| 1 | 誤りにつながる（必ず直す） | 点検者の誤りの指摘、網羅の欠落、書誌の食い違い、理由の出所の所見、条文の誤り、図の error |
| 2 | 確かめる必要がある | 確度、条文の一覧の照合、食い違いの候補、定義の照合、未確認の判例、分量1.3倍超 |
| 3 | 質を上げる | ⑥⑦⑧⑩⑪⑭⑯、⑫の所見 |
| 4 | 足すとよい（9.5 に届くための追加） | 出所表・索引・答案での使い方の欄・短答の命題が無い |
| 5 | 手続 | 独立点検、最後の版の点検 |

同じ優先度の中では、点の低い指標から直す。機械の値と点検者の採点が食い違うときは、点検者の採点を優先する（機械は形しか見ない）。

## 5. 引っ張り合う指標

一つを直すと、別の指標が動く。直した後に必ず見る指標を挙げる。

| 直したもの | 動きやすい指標 | 何が起きるか |
|---|---|---|
| ⑯ 文体を資料に寄せた | ⑩ 独自性 | 一致が増える。両方が条件に入る所で止める |
| ⑩ 一致を下げた | ⑯ 文体、⑤ 定義 | 文が浮く。術語・定義を崩していないかを見る |
| ⑪ 分量を削った | ⑥ 論証密度、⑬ 網羅、④ 確度 | 理由の文・例外・留保を削っていないかを見る |
| ⑥ 理由を足した | ⑪ 分量、⑮ 誤り | 足した理由が資料にあるかを確かめる。無ければ（補足） |
| ⑦ 例を足した | ⑮ 誤り、⑪ 分量 | 足した例の帰結を確かめる |
| ⑧ 図・ざっくり理解を足した | ⑪ 分量、④ 確度、⑮ 誤り | 図が本文と逆に読めないか。ざっくり理解で留保を落としていないか |
| ⑫ 巻末の表を足した | ④ 確度、① 条文、② 書誌 | カード・短答の条文・書誌・確度が本文と同じか |
| ③ 理由の出所を分けた | ⑪ 分量、⑥ 論証密度 | 表に移した理由が、本文から消えていないか |
| 体裁を直した | ⑬ 網羅 | 文が抜けていないか |

## 6. 回す回数と止めどき
- 「資料を上回る」の判定が出て、重大・中の誤りが0になったら、渡せる。そこから先（9.5 に届く条件）は、利用者が求めるときに回す。
- 3回直しても同じ指標が上がらないなら、その指標の測り方が合っていない可能性がある（機械の誤検知）。点検者の判断を優先する。
- 検査の定義を変えたら（標識の語を足す、除外の規則を変える）、前の版も同じ検査で測り直してから、前後を比べる。
- 直すたびに、別の所が悪くなることがある（5節）。直した後は、全部の検査を走らせ直す。

## 7. 疑似コード

```
def next_fixes(report):
    fixes = [f for f in report.fixes if f.priority <= 2]
    low = sorted([f for f in report.fixes if f.priority == 3], key=lambda f: f.score)[:3]
    if not fixes and not low:
        low = [f for f in report.fixes if f.priority == 4]      # 9.5 に届くための追加
    return fixes + low

while True:
    report = pipeline(note); review = independent_review(note)
    if review.verdict == "資料を上回る" and review.major == 0 and review.mid == 0 and not want_9_5: break
    if want_9_5 and not report.gap_to_9_5 and review.all_indicators >= 9.5: break
    if rounds >= 4: report_to_user(remaining=report.fixes, gap=report.gap_to_9_5); break
    apply(next_fixes(report) + review.must_fix); rounds += 1
```
