# 判断の決定表

書くときに迷う判断を、決定表と疑似コードにした。上から順に当て、最初に当たった行に従う。当たらないときは、最後の行（既定）。

| ファイル | 判断 | 使う段階 |
|---|---|---|
| `source-type.md` | 資料の型（教科書／レジュメ／設例／判例評釈／条文解説） | ①の後 |
| `figure-type.md` | 難所の性質から、図の型（25型）を選ぶ | ⑦ |
| `table-or-prose.md` | 表にするか、文で書くか | ⑤ |
| `case-placement.md` | 判例を本文に書くか、表に書くか。理由の出所の書き方 | ⑤ |
| `zakkuri-placement.md` | 「ざっくり理解」を置くか、どこに置くか | ⑥ |
| `hosoku-tag.md` | 足した文に「（補足）」を付けるか | ⑤〜⑦ |
| `next-fix.md` | 採点・検査の結果から、次に何を直すか（16指標の決定表。指標ごとの手順は `../metrics/`） | ⑪の後 |

決定表は、これまでの採点で実際に差が出た判断だけを載せている。表にない判断は、`techniques.md` の技法と、資料の書き方に従う。
