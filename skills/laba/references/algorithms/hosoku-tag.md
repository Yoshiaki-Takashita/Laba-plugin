# 足した文に「（補足）」を付けるか

## 決定表（文・表のセル・図の注記・ざっくり理解の1文ごとに当てる）

| № | その文は | 札 | 例 |
|---|---|---|---|
| 1 | 資料の文の言い換えで、意味が同じ | 付けない | 資料の長い文を2文に分けた |
| 2 | 資料の例を、記号を替えて描き直した | 付けない | 資料「債権者が主債務者と保証人を…」→「XがY1（主債務者）とY2（保証人）を…」 |
| 3 | 資料にない具体例 | 付ける | 「（補足）たとえば，Aが…という場合，」 |
| 4 | 資料にない理由・評価・射程の判断 | 付ける | 「（補足）この区別は，…という点に実益がある。」 |
| 5 | 条文・判決文を確かめて、資料の表現に語を補った | 付けない（報告に書く）。資料と違う内容になるなら付ける | 条文の「同一の控訴裁判所に」を補った |
| 6 | 改正後の条文番号など、資料の後の変化 | 付ける | 「（補足）現行の252条5項に当たる。」 |
| 7 | 節をまたぐ対比・相互参照（内容は資料にあるものどうし） | 付けない | 「これは39条の場合と逆の扱いである。」 |
| 8 | 作成者が設例に出した結論で、資料が結論を示していないもの | 「ノートとしての結論」と書く | 結論の段 |
| 9 | 判例の理由のうち、資料の説明であって判決文にないもの | ［資料］または「資料の説明」の列 | `case-placement.md` |
| 10 | ざっくり理解の中の平易な言い換え | 付けない。ただし 3・4 に当たる文には付ける | — |

## 疑似コード
```
def needs_hosoku(sentence, source):
    m = source.find_matching_passage(sentence)
    if m and same_meaning(sentence, m): return False          # 1, 2, 7
    if sentence.is_conclusion_on_open_question: return "ノートとしての結論"
    if sentence.is_case_reason and not in_judgment(sentence): return "［資料］"
    if sentence.adds_example or sentence.adds_reason or sentence.adds_evaluation: return True
    if sentence.updates_statute_number: return True
    return False
```

## 付け方
- 文頭に「（補足）」。段落の全部が補足なら、段落の頭に1回。
- 表のセルは、セルの冒頭。図の注記は、注記の頭。
- 補足は、資料の1段落につき1〜2文まで。補足だらけになるなら、範囲外に出ている。
- 「（補足）」を付けても、誤りは誤りである。補足の内容も、条文・判例で確かめる。

## 間違えやすい所
- 言い換えのつもりで、理由を足している（4 に当たるのに、1 として扱う）。言い換えの文に、資料にない「〜からである」「〜という立場である」があれば、4。
- 表のセル・図の注記に付け忘れる。
- 「と説明されることもある」と書いて、出所をぼかす（札を付けるか、出所を書く）。
