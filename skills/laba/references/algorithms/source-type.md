# 資料の型の判定

## 入力
- `style_profile.py` の値：平均文長（L）、句点のない行の率（N）、段落あたりの文数（P）、箇条書きの行数（B）
- 目で見た特徴：設問（Q・設問・問）の数、事例（Case・設例）の数、判決文の引用の量、条文の引用の量

## 決定表（上から順に）

| № | 条件 | 型 | 本文の体 | 重点 |
|---|---|---|---|---|
| 1 | 利用者が体・重点を指定した | 指定に従う | 指定 | 指定 |
| 2 | 1件の判決の事実・判旨・評釈が中心（「本件」「本判決」が多い） | 判例評釈型 | 資料に合わせる | 事案の図、審級ごとの判断、判旨の射程。このスキルより判例研究の手順が合うなら、そちらを使う |
| 3 | 条文の逐条の説明が中心（条番号が見出し。「本条は」が多い） | 条文解説型 | 資料に合わせる | 条文ごとに［趣旨→要件→効果→関連条文→判例］。条文の照合を厚く |
| 4 | 事例と設問が紙面の半分以上 | 設例中心型 | です・ます（設例の検討は論証の型） | 請求→抗弁→再抗弁、結論、結論一覧 |
| 5 | L ≥ 45 かつ N < 25% かつ P ≥ 1.8 | 教科書型 | 資料と同じ | 文体の模倣、難所の図、判例4段 |
| 6 | 箇条書き・体言止め・矢印（→、⇒）が中心（N ≥ 25% または B が多い） | レジュメ型 | です・ますの解説 | 前提の加筆、行間を埋める、問いへの答え |
| 7 | 資料がない（題目だけ） | 資料なし | です・ますの解説 | 判例・論点の一覧を先に作る |
| 8 | どれにも当たらない | レジュメ型として扱う | です・ます | — |

## 疑似コード
```
def source_type(profile, seen, user):
    if user.specified: return user.type
    if seen.single_case_commentary: return "判例評釈"
    if seen.article_by_article: return "条文解説"
    if seen.exercise_share >= 0.5: return "設例中心"
    if profile.mean_len >= 45 and profile.noperiod_pct < 25 and profile.para_sents >= 1.8: return "教科書"
    if profile.noperiod_pct >= 25 or seen.bullets_dominant: return "レジュメ"
    if not seen.has_source: return "資料なし"
    return "レジュメ"
```

## 混ざっているとき
- 解説＋演習事例：解説の部分は 5 か 6、事例の部分は 4。
- レジュメ＋判決文の長い引用：本文は 6。判決文は、資料からの引用として短い一節だけを引き、残りは言い換える。
- 教科書＋コラム：コラムは「発展：○○」として本文と同じ体で書く。

## 型を決めたら
- 教科書型 → `style-imitation.md` を読み、`style_profile.py` を走らせる。
- レジュメ型・設例中心型・資料なし → 文体は既定値（`style-imitation.md` 9）。
- 判例評釈型・条文解説型 → 見出しの組み方だけが違う。他は同じ手順。
