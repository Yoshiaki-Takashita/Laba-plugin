# 「ざっくり理解」を置くか、どこに置くか

## 決定表

| № | 条件 | 置くか | 型（`zakkuri.md`、`examples/good-zakkuri.md`） |
|---|---|---|---|
| 1 | 表紙の直後 | 必ず置く（「この回の全体像」。半頁以内） | 見本A（全体像） |
| 2 | 書き出した難所のうち、制度の存在理由が分かりにくいもの（なぜこの制度があるのか） | 置く。その節の冒頭 | 場面→何が困る→そこで制度→ひとこと |
| 3 | 難所のうち、似た二つの区別 | 置く。区別が出てくる節の冒頭。比較図があれば、図の直前 | 見本B（比較） |
| 4 | 難所のうち、手続の流れ・時間 | 置く。流れ図・時間軸があれば、図の直前 | 見本C（流れ） |
| 5 | 難所だが、図か表だけで足りる | 置かない | — |
| 6 | 資料が平易に書いている節 | 置かない | — |
| 7 | 定義・分類だけの節 | 置かない（整理軸の表で足りる） | — |
| 8 | 発展・コラム | 置かない（本文の読者向け） | — |

## 数の目安
- 全体像1つ＋難所に2〜4つ。資料20頁で合計3〜5。
- ざっくり理解の分量は、全体の5〜8%。10%を超えたら、置きすぎか、長すぎる。

## 置いたあとの確認
- 直後の本文と、同じ設例の説明を繰り返していないか（本文は「前述の設例において」で受ける）。
- 参照する図が2頁以内にあるか。
- 頁をまたいでいないか。
- 段の中の文末が、です・ますで揃っているか。
- 資料にない断定をしていないか（確度の語、限定語、「正確には→本文」）。
- 理由の文が1つ以上あるか（論証密度を下げないため）。

## 疑似コード
```
def place_zakkuri(section, hard_spots):
    if section.is_cover_following: return "全体像"
    hs = hard_spots.get(section)
    if hs is None or section.is_column or section.is_definition_only: return None
    if hs.covered_by_figure_or_table_alone: return None
    if hs.kind == "制度の存在理由": return "場面型"
    if hs.kind == "似た二つの区別": return "比較型"
    if hs.kind == "流れ・時間": return "流れ型"
    return None
```
