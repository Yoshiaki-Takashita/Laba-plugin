# 表にするか、文で書くか

## 決定表（上から順に）

| № | 内容の性質 | 書き方 |
|---|---|---|
| 1 | 3つ以上の項目を、2つ以上の同じ観点で比べる（類型×要件・効果、契約の種類×成立・対価・終了） | 表 |
| 2 | 条文の列挙が5項目以上（取得できる場合、例外の号） | 表（号／場面／なぜ） |
| 3 | 判例が同じ小節に3件以上 | 表（`case-placement.md`） |
| 4 | 要件が3つ以上あり、それぞれに趣旨・利益を書く | 表（要件／内容／誰のどんな利益） |
| 5 | 設例の結論が3つ以上、場合分けが2つ以上 | 表（結論一覧） |
| 6 | 二つの概念の区別（典型例・基準・理由・場面・限界） | 区別表。資料が1文で対比しているだけなら、文でよい |
| 7 | 論証（主張→理由→例→限定）、制度の経緯（問題→対処→限界→制度） | 文。表にすると、理由のつながりが切れる |
| 8 | 学説の対立で、各説の理由と批判が絡む | 文（両説を1段落ずつ）。結論と理由を並べるだけなら表でよい |
| 9 | 2項目だけの対比 | 文（「前者は…のに対し、後者は…」） |
| 10 | 上のどれでもない | 文 |

## 疑似コード
```
def table_or_prose(x):
    if x.items >= 3 and x.shared_aspects >= 2: return "表"
    if x.is_statute_list and x.items >= 5: return "表"
    if x.is_precedents and x.items >= 3: return "表"
    if x.is_requirements and x.items >= 3 and x.has_rationale: return "表"
    if x.is_conclusions and (x.items >= 3 or x.branches >= 2): return "表"
    if x.is_argument or x.is_history: return "文"
    return "文"
```

## 表を作るときの規則
- 同じ内容を、本文と表の両方に書かない。表にしたら、本文は導入の1文（「…は表3のとおり分かれる」ではなく、内容を1文で言い、文末に「（表3）」）。
- セルは短く（1〜2文）。セルが3文を超えるなら、その内容は文で書くべきものである。
- 「同左」「同上」「—」で埋めない。該当なしなら「該当する判例なし」「資料に記載なし」と書く。
- 資料にない内容のセルには「（補足）」。
- 列は5つまで。それを超えるなら、表を分ける。
- 表の数の目安：資料20頁で8〜14。これを大きく超えるなら、表にしなくてよいものが混ざっている。

## 分量との関係
分量が資料の1.15倍を超えたら、まず次を疑う。
1. 判例の二重記載（本文と表）。
2. 表のセルが長文になっている。
3. まとめ・言い直しの繰り返し。
4. 範囲外の加筆。
