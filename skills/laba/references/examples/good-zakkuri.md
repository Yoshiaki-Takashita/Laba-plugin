# 「ざっくり理解」の見本

`zakkuri.md` の5・6に、法定地上権と同時審判の申出の見本がある。ここには、型の違う見本を3つ置く。どれもこのスキルのために書いたもの。

## 見本A：全体像（表紙の直後に置く型）

**この回の全体像（ざっくり）**

お金を貸した人（債権者）は、借りた人（債務者）が財産を減らしてしまうと、返してもらえなくなります。この回は、それを防ぐために債権者が使える二つの手段を扱います。

- **債権者代位権**：債務者が自分の権利を使わずに放っているとき、債権者が代わりに使う。
- **詐害行為取消権**：債務者が財産をわざと減らしたとき、その行為を取り消して財産を戻す。

どちらも「債務者の財産に、債権者が口を出す」制度です。本来、自分の財産をどうするかは債務者の自由なので、口を出せるのは、債務者にお金が足りない（無資力の）ときに、原則として限られます（例外は本文）。この「債務者の自由」と「債権者の保護」の釣り合いが、全体を通した軸です。

## 見本B：似た二つの区別（比較の型）

**ざっくり理解：取消しと撤回はどう違うのか**

どちらも、いったんした処分の効力を失わせます。違いは「いつの理由か」です。

- **取消し**：処分をした時点で、すでに間違っていた。だから、最初にさかのぼって無かったことにする。
- **撤回**：処分をした時点では正しかった。その後に事情が変わった。だから、これから先に向かって効力を失わせる。

たとえば、運転免許を与えたあとで、申請のときの書類が偽造だったと分かれば取消しです。免許を与えたあとで、重大な違反を繰り返したなら撤回です。法律の条文では、撤回のことも「取消し」と書いてあることが多いので、条文の言葉ではなく中身で見分けます。

**ひとことでまとめると**　最初から間違っていたなら取消し、あとから事情が変わったなら撤回です。（さかのぼる範囲の制限や、相手方の信頼の保護は→本文）

## 見本C：手続の流れ（時間の型）

**ざっくり理解：逮捕されてから起訴されるまで**

警察に逮捕されると、そこから時間の制限つきで手続が進みます。

1. 警察は、逮捕から48時間以内に、事件を検察官に送る。
2. 検察官は、受け取ってから24時間以内（逮捕から72時間以内）に、勾留を請求するか、釈放する。
3. 裁判官が勾留を認めると、原則10日間。やむを得ないときは、さらに10日まで延長できる。
4. 検察官は、この期間のうちに、起訴するかどうかを決める。

**なぜ時間が細かく決まっているのか**　体を拘束されることは、それだけで大きな不利益だからです。捜査の必要と、拘束される人の自由との釣り合いを、時間で区切って取っています。

**ひとことでまとめると**　逮捕から起訴までは、通常は最長で23日間です。（逮捕の種類ごとの要件、勾留の要件、事件ごとに数えることは→本文）
