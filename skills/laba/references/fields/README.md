# 法分野ごとの参照ファイル

構成の段階（④）と図の段階（⑦）で、資料の分野のファイルを1つ読む。複数の分野にまたがる資料（例：担保と民事執行）は、両方を読む。

| ファイル | 分野 |
|---|---|
| `kenpo.md` | 憲法 |
| `minpo-sosoku-bukken.md` | 民法（総則・物権・担保物権） |
| `minpo-saiken.md` | 民法（債権総論・契約・不法行為など） |
| `minpo-shinzoku-sozoku.md` | 民法（親族・相続） |
| `shoho-kaisha.md` | 商法・会社法 |
| `minso.md` | 民事訴訟法（末尾に、民事執行・民事保全の入口） |
| `keiho.md` | 刑法 |
| `keiso.md` | 刑事訴訟法 |
| `gyosei.md` | 行政法 |
| `rodo-chizai-tosan.md` | 労働法・知的財産法・倒産法（要点だけ） |

各ファイルの構成は同じ：①整理軸の定番　②論証・設例の型　③図が効く難所と推奨する型　④条文・判例を引くときの注意　⑤混同しやすい概念の組　⑥その分野の資料の文体。

## 使い方の注意
- ここに書いてあるのは「どう整理し、どこに気をつけるか」の手がかりであって、知識の出典ではない。ノートに書く内容は、資料と、確認した条文・判例による。
- 条文番号は、よく使うものだけを挙げている。改正で動くので、書く前に現行の条文を確かめる。
- 判例は、事件の通称と年月日までしか挙げていない。書誌（登載誌・巻号頁）は、ここから写さず、`case-verification.md` の手順で確かめて書く。年月日も確かめる。
- 資料の整理軸がここと違うときは、資料に従う。
- 術語の表記は資料に合わせる。同じ概念に複数の表記があるとき（例：主観的予備的併合／主体的予備的併合）は、資料の表記で書き、初出で別の表記を括弧で添える。ここに挙げた表記を、資料の表記より優先しない。
- 改正の一覧は、2026年11月の時点で確かめたもの。成立・公布まで確かめ、施行日を確かめていないものは「施行の有無を確かめる」と書いてある。ノートを書くときは、その時点の現行条文（e-Gov）で確かめ直す（`statute-verification.md`）。
- 判例の言い回し（判決文の語）と、学説による言い換えは分けて書く。ここに「判例の言い回し」として挙げた語も、引用するときは判決文で確かめる。
