# 民事訴訟法

## ① 整理軸の定番
- 手続の流れ：訴えの提起→審理（口頭弁論・争点整理・証拠調べ）→判決→上訴→確定→（執行）。いま扱っている制度が、この流れのどこにあるかを先に示す。
- 三つの基本原則：処分権主義（何について・どの範囲で審判を求めるかは当事者が決める）、弁論主義（事実と証拠の提出は当事者の責任）、職権進行主義（手続の進行は裁判所）。個々の規律がどの原則の現れか、どの原則の例外かを書く。
- 訴訟要件と本案：適法性の問題か、請求に理由があるかの問題か。
- 訴えの三類型：給付・確認・形成。確認の利益、形成の訴えの法定性は、類型から説明する。
- 判決の効力：既判力の時的限界（基準時）・客観的範囲（主文、例外としての相殺）・主観的範囲（当事者、承継人など）。
- 多数当事者：訴訟共同の必要（全員が当事者にならないと不適法か）と、合一確定の必要（判決の内容を揃える必要があるか）の二つで、通常共同訴訟・固有必要的共同訴訟・類似必要的共同訴訟を整理する。
- 複雑訴訟：客体の複数（請求の併合、訴えの変更、反訴）と主体の複数（共同訴訟、参加、承継）。
- 証拠法：
  - 証明の対象：争いのある主要事実。自白された事実と顕著な事実は証明を要しない（179条）。
  - 証明責任：ある事実が真偽不明のとき、どちらの当事者が不利益を受けるか。分配は、条文の構造（権利の発生・障害・消滅・阻止）による、とするのが一般。主張責任の分配とそろう（`yoken-jijitsu.md`）。
  - 自白：成立（口頭弁論または弁論準備手続での、相手方の主張と一致する、自己に不利益な事実の陳述）→効果（証明不要、裁判所への拘束、撤回の制限）→撤回が許される場合。主要事実に限るか（間接事実・補助事実の自白）、権利自白は別に論じる。
  - 自由心証主義（247条）と、その限界（証明責任による裁判、経験則違反）。
  - 証拠共通：一方の当事者が申し出た証拠は、相手方に有利な事実の認定にも使える（当事者間の証拠共通）。共同訴訟人の間の証拠共通は別の話で、通常共同訴訟でも認められる、とするのが一般。主張共通と区別する。
  - 証拠調べ：書証（文書の成立の真正、文書提出命令〔220条以下〕）、人証、鑑定、検証。
- 訴えの利益の各論：確認の利益（対象の選択、方法の選択、即時確定の利益）、将来の給付の訴え。一部請求、相殺の抗弁と重複起訴。
- 当事者：当事者の確定、法人でない社団、任意的訴訟担当。上訴：上訴の利益、不利益変更の禁止。

## ② 論証・設例の型
- 「この訴えは適法か」：訴訟要件を順に（当事者能力・当事者適格、訴えの利益、重複起訴の禁止、管轄など、問題になるものだけ）。
- 「裁判所はこの事実を認定できるか」：弁論主義の三つの内容（主張されていない事実は基礎にできない／自白された事実はそのまま基礎にする／証拠は当事者が申し出たものによる）のどれの問題か→主要事実か間接事実か→当てはめ。
- 「後訴でこの主張は許されるか」：前訴判決の既判力が後訴に及ぶ関係か（訴訟物が同一・先決・矛盾）→基準時の前の事由か後の事由か→主観的範囲。
- 「一人がした行為の効力は」：共同訴訟の類型を決める→39条（独立）か40条（合一確定のための規律）か→有利な行為か不利な行為か。
- 「この事実について証明は要るか」：主要事実か→相手方が認めているか（自白の成立）→撤回されたなら、撤回の要件。
- 「真偽不明のとき、どちらが負けるか」：その事実が、どの条文の、発生・障害・消滅・阻止のどれにあたるか→証明責任の所在→当てはめ。
- 要件事実の振り分け（請求原因・抗弁・再抗弁）は `yoken-jijitsu.md`。

## ③ 図が効く難所
| 難所 | 型 |
|---|---|
| 共同訴訟の類型（二つの必要の組合せ） | 座標図 |
| 同時審判の申出の対象（法律上両立しないと、事実上両立しない） | 比較図（証明責任の所在を並べる） |
| 共同所有と固有必要的共同訴訟（誰が誰に、何を求めるか） | 判例マトリクス |
| 共同訴訟での主張と証拠（証拠は共通になるが、主張はならない） | 動きの図 |
| 既判力の時的限界（基準時の前後） | 時間軸 |
| 一人の上訴で何が移審し、誰が上訴人になるか | 流れ図 |
| 補助参加・独立当事者参加・訴訟承継の当事者の配置 | 当事者関係図（2枚まで） |

| 証明責任の分配（発生・障害・消滅・阻止と、誰が言うか） | 表 |
| 自白の成立と撤回 | 流れ図 |

## ④ 条文・判例の注意
- 現行法は平成8年制定（平成10年施行）。それ以前の判例は旧法の条文番号で書かれている。対応を確かめる。
- 令和4年改正（手続のIT化）は、現行の条文に入っている（電子判決書、電磁的訴訟記録、電子情報処理組織による申立て、法定審理期間訴訟手続など）。条文番号・用語が動いているので、現行の条文で確かめる。民事執行・民事保全などのデジタル化（令和5年法律第53号）は、施行されていない部分がありうる。施行の有無を確かめる。
- 規則（民事訴訟規則）の条文は「規○条」と書く資料が多い。法と規則を混ぜない。
- 人事訴訟法、会社法、行政事件訴訟法など、特別法が対世効や当事者適格を定めていることがある。判決効の範囲は、その条文で確かめる。
- よく引かれる条文：38条（共同訴訟の要件）、39条（共同訴訟人独立）、40条（必要的共同訴訟）、41条（同時審判の申出）、42条以下（補助参加）、47条（独立当事者参加）、114条・115条（既判力）、142条（重複起訴の禁止）、143条（訴えの変更）、146条（反訴）、152条（弁論の併合・分離）、179条（自白）、246条（申立事項と判決事項）。
- 判例は、事案（誰が誰に何を求めたか）と結論を必ず対にして書く。手続法の判例は、事案を離れると射程を誤りやすい。

## ⑤ 混同しやすい概念
- 訴訟共同の必要／合一確定の必要
- 共同訴訟人間の主張共通（一般には否定）／証拠共通（肯定）。原告と被告の間の主張共通・証拠共通とは別の話
- 法律上併存し得ない／事実上併存し得ない（同時審判の申出）
- 弁論の分離／一部判決
- 既判力／反射効／争点効／参加的効力
- 訴えの取下げ／請求の放棄／上訴の取下げ／上訴権の放棄
- 主要事実／間接事実／補助事実
- 主張責任／証明責任、本証／反証、証明／疎明
- 自白／権利自白／擬制自白
- 当事者間の証拠共通／共同訴訟人の間の証拠共通
- 当事者能力／訴訟能力／当事者適格
- 主観的予備的併合（主体的予備的併合とも表記される。判例は不適法とする〔最判昭和43・3・8〕）／同時審判の申出。表記は資料に合わせ、初出で別の表記を括弧で添える
- 固有必要的共同訴訟／類似必要的共同訴訟（上訴・取下げの扱いが違う）
## 付：民事執行・民事保全の入口
担保物権や債権回収の資料で、執行・保全の語が出てくるときの手がかり。くわしい規律は資料と条文による。条文は「民執○条」「民保○条」と書き、民事訴訟法の条文と混ぜない。
- 全体の位置：権利の確定（判決手続）→権利の実現（執行手続）。判決が出る前に財産や現状を押さえておくのが保全。
- 強制執行：債務名義（確定判決、仮執行宣言付きの判決、執行証書など）＋執行文＋送達。金銭の執行は、差押え→換価→満足（配当）。対象（不動産・動産・債権）ごとに手続が違う。金銭以外の執行（明渡し、作為・不作為）は、直接強制・代替執行・間接強制。
- 担保権の実行：債務名義は要らない。担保不動産競売と担保不動産収益執行。
- 不動産の売却で権利がどうなるか：売却により消える権利と、買受人が引き受ける権利（民執59条）。抵当権と利用権の資料は、ここと民法の規定（明渡しの猶予など）を対にして書く。
- 執行を争う方法：請求異議の訴え（債務名義の請求権を争う）、第三者異議の訴え（目的物が債務者の財産でないと争う）、執行抗告・執行異議（手続の違法）。どれが何を争うものかを表にする。
- 保全：仮差押え（金銭債権の執行を保全する）、係争物に関する仮処分（現状を固定する。占有移転禁止、処分禁止）、仮の地位を定める仮処分。要件は、被保全権利と保全の必要性。疎明で足りる。
- 図：手続の流れ（流れ図）、配当での順位（価値配分）、差押えと処分・相殺の前後（時間軸）。
- 混同しやすい組：債務名義／執行文、強制執行／担保権の実行、請求異議／第三者異議、仮差押え／仮処分、証明／疎明。
