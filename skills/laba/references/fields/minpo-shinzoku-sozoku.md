# 民法（親族・相続）

## ① 整理軸の定番
- 親族：身分関係の発生・変更・消滅（婚姻・離婚、親子〔実子・養子〕、親権、後見、扶養）。各制度は、要件（実質的要件と届出）→無効・取消し→効果、の順。
- 身分行為の特徴：当事者の意思の尊重、届出（創設的届出と報告的届出）、財産法の規定（意思表示・代理）がそのままは当てはまらないこと。
- 親子：嫡出の推定→否認→認知→養子縁組。法律上の親子関係を、誰が、いつまで、どの手続で争えるか。
- 親権：身上監護と財産管理。利益相反行為（外形で判断するとされる）と、代理権の濫用。
- 相続：開始→相続人（順位、代襲、欠格・廃除）→相続分（法定・指定、特別受益・寄与分）→遺産の範囲→承認・放棄→遺産共有→遺産分割→遺言→遺留分→配偶者の居住の保護。
- 相続と第三者：相続による権利の承継と対抗要件（法定相続分を超える部分）。
- 離婚：離婚原因（有責配偶者からの請求を含む）と、離婚の効果（財産分与、親権者の指定、養育費、親子交流）。効果は令和6年改正で大きく変わっている（④）。
- 夫婦の財産関係：日常の家事に関する債務の連帯責任（761条）と、その範囲を超えた行為の相手方の保護。
- 遺言：方式→撤回→解釈→遺言執行者。相続回復請求権。

## ② 論証・設例の型
- 「誰が相続人で、相続分はいくらか」：相続人の確定→法定相続分→特別受益・寄与分による修正→具体的相続分。計算は表で示し、合計が1になることを確かめる。
- 「この遺産はどう帰属するか」：遺産に含まれるか（可分債権、預貯金、金銭の扱いは判例で違う）→遺産分割の対象か→分割前の処分。
- 「この行為は有効か」（親権者の行為）：利益相反行為にあたるか（特別代理人）→あたらなくても代理権の濫用にならないか。
- 「遺留分を侵害されたか」：遺留分の算定の基礎となる財産→遺留分の額→侵害額→請求の相手方。
- 身分関係の訴訟は、人事訴訟法が当事者適格・判決の対世効を定める。民事訴訟の型（`minso.md`）と合わせて見る。

## ③ 図が効く難所
| 難所 | 型 |
|---|---|
| 相続人と相続分 | 親族関係図（家系図の形）＋計算の表 |
| 特別受益・寄与分の計算 | 価値配分 |
| 遺留分の計算 | 価値配分 |
| 嫡出推定と否認・認知の期間 | 時間軸 |
| 相続開始から遺産分割までの遺産の帰属 | 時間軸・流れ図 |
| 相続と登記（遺産分割・相続放棄・遺贈と第三者） | 時間軸・表 |
| 親権者の行為（利益相反と代理権の濫用） | 比較図 |

親族関係図は、夫婦を横線、親子を縦線で結ぶ。死亡した者には印と死亡の日付を付け、相続分は各人の下に書く。

## ④ 条文・判例の注意
- 改正が多い。平成30年の相続法改正（配偶者居住権、遺留分侵害額請求、預貯金の払戻し、相続による権利の承継と対抗要件など）、令和3年改正（特別受益・寄与分を主張できる期間の制限〔904条の3。相続開始から10年を過ぎた後の遺産分割には、原則として特別受益・寄与分の規定を適用しない。遺産分割そのものに期限ができたのではない〕、共有、相続登記）、令和4年改正（嫡出推定、否認、懲戒権の削除など）。施行日と、相続の開始・行為の時がどちらかを確かめる。
- 令和6年改正（令和6年法律第33号。令和6年5月24日公布、令和8年4月1日施行）。父母の離婚後の子の養育に関する見直しで、親権・監護、養育費、親子交流、養子縁組、財産分与などの規定が変わった（離婚後に父母の双方を親権者と定めることができる、親権の行使方法、法定養育費、財産分与の請求期間の伸長など）。離婚・親権・養育費・財産分与の資料は、この改正の前のものか後のものかを最初に確かめる。改正前の資料で書くときは、現行の条文と照らし、変わった点を注記する。条文番号は現行の条文で確かめる（819条、824条の2、766条の3、768条など）。
- 令和8年改正（令和8年法律第45号。令和8年6月24日公布）。遺言の制度の見直し（電子データ等で作成し法務局で保管する保管証書遺言の創設、押印の任意化など）と、成年後見の見直し。施行は、押印の任意化などが公布から1年、保管証書遺言の創設などが3年、成年後見が2年6月を、それぞれ超えない範囲内で政令で定める日。遺言の方式を書くときは、施行の有無を確かめる。施行前は現行の条文で書く。
- 改正前の判例の用語（遺留分減殺請求など）は、現行法の用語との対応を書く。
- 家事事件手続法・人事訴訟法・戸籍法と一体で動く。調停・審判・訴訟のどれで争うかを書く。
- 相続分の計算は、分数を通分して検算する。計算の誤りは重大な誤りになる。

## ⑤ 混同しやすい概念
- 婚姻の無効／取消し、協議離婚の無効／取消し
- 嫡出否認／親子関係不存在確認／認知無効
- 代襲相続／再代襲／数次相続
- 相続放棄／相続分の放棄／遺産分割での事実上の放棄
- 遺贈／死因贈与／「相続させる」旨の遺言（特定財産承継遺言）
- 特別受益／寄与分／特別の寄与
- 遺留分／遺留分侵害額請求（金銭債権）
- 利益相反行為／代理権の濫用
- 遺産共有／通常の共有（分割の手続が違う）

## ⑥ 文体
教科書は、である調で、家族関係の事例（A男・B女、子C・D）が多い。設例の人物は、資料の呼び方のまま使う。
