# レジュメの文体

判例研究のレジュメは、発表で読み上げ、指導教員が紙で読む文書である。論文ほど硬くせず、教科書の説明文の調子で書く。数値は、完成したレジュメの実測に合わせてある。

## 1. 数値

| 項目 | 目安 |
|---|---|
| 1文の長さ | 平均約50字、中央値約48字 |
| 節ごとの差 | 前提知識は短め（約42字）、事案はやや長め（約60字） |
| 長い文 | 100字を超える文は、引用以外では作らない |
| 段落 | 2〜3文。前提知識は約80字、事案・学説・考察は約130字 |
| 文末 | 「〜した」「〜する」「〜である」「〜ない」で約9割 |
| 結論の文 | 「〜ことになる」「〜のである」をたまに使う |
| 推量 | 「〜と思われる」「〜と考えられる」を続けない。事実からの推論は「〜とみられる」「〜と読める」 |
| 問いかけ | 「〜かは疑問である」「〜ではないか」（考察で） |

本体の `scripts/style_check.py` は、資料の文体に合わせるための道具である。判例研究では手本の資料がないので、上の表を目安にし、`scripts/density.py` で1文の長さと重複だけを確かめる。

## 2. 書き方

- である調。定義→条文番号→具体例1つ→「本件では〜」の順。
- 専門用語は、初出で一言説明する。
- 判例集や解説の名前を主語にした言い回し（「百選によれば」「調査官解説によれば」）を連発しない。内容を平易な言葉で書き、出所は段落の終わりに括弧で付ける。
- 判例集の体裁をそのまま持ち込んだ言い方（「判決要旨一」「判示事項二」）や、説明なしの外来の術語（「レイシオ・デシデンダイ」「オビタ・ディクタム」）を使わない。「判決の結論を支える理由の部分」「結論に必要のない説示」のように、内容を書く。
- 「ポイント」のような枠や見出しは使わない。要点は本文に混ぜる。
- 作業の記録（検索したこと、読めなかったこと、字数）は本文に書かない。報告に書く。

## 3. 発表原稿として読む段落

利用者が、発表でそのまま読むために「です・ます」に直した段落は、そのままにする。

- その段落を、次の版で である調に戻さない。語句も直さない（誤りを見つけたら、直さずに報告する）。
- 利用者が付けた太字・下線は消さない。新しく太字を足さない。
- どの段落が利用者の手が入った段落かは、版の差分で確かめる（`09-revision.md`）。

## 4. 引用の表記

- 判決文は原文の表記のまま（漢数字、読点）。地の文は算用数字。
- 判例名は「最判平成○年○月○日民集○巻○号○頁」。繰り返すときは「本判決」「昭和○年判決」。
- 条文は「○条○項」。法令名は初出だけ。

## 5. AI らしさを消す

次のものは、読み手に機械が作ったと思わせる。使わない。

- 色の帯、縦線、色つきの枠、塗りつぶした表の見出し行（Word）。
- すべての節を同じ長さ・同じ型の箇条書きにすること。
- 三つ並べること自体が目的の「三つの意義」「三つの課題」（意義が二つなら二つと書く）。
- 「重要なのは〜である」「〜が鍵となる」のような、中身のない強調。
- 金額や数字だけを大きくした見せ方。

## 6. Word の体裁（判例研究レジュメ）

判例研究のレジュメは、講義ノートとは体裁が違う。完成版として認められたレジュメの実測に合わせてある。`scripts/hanrei/resume_build.py` の既定（`--style hanrei`）がこの体裁で作る。

| 項目 | 判例研究レジュメ（`--style hanrei`） | 講義ノート（`../docx-format.md`、`--style note`） |
|---|---|---|
| 余白 | 上下 25.4mm、左右 27.5mm | 上下 27mm、左右 25mm |
| 本文 | 明朝 10.5pt、**字下げなし**、段落の後ろ 6pt、行送り 1.42 | 明朝 10.5pt、1字下げ、段落の後ろ 4pt |
| 章（１．前提知識） | ゴシック太字 14pt、下に黒の罫線、章ごとに改頁 | 14pt、下に罫線 |
| 節（1　…。通し番号） | ゴシック太字 **13.5pt** | 11.5pt |
| 小見出し（(1) …） | ゴシック太字 **11pt** | 10.5pt |
| 時系列の小見出し（① …） | ゴシック太字 10.5pt | — |
| 表 | **黒い細罫線の格子**（0.5pt。縦の罫線もある）。見出し行は太字のゴシックだけで、塗りつぶし・白字にしない。文字 9.5pt | 上下の横罫だけ（縦の罫線なし） |
| 条文・判旨の引用 | **左に 1.5pt の黒い罫線を引いた段落**（左 24pt・右 12pt 下げる） | 引用の段落はない |
| 専門用語の注 | 小さい灰色の字（9pt） | （補足）として本文に |
| 参考判例・文献 | **8pt**、行間を詰める、1頁以内 | — |
| 色 | 黒だけ（見出し・表・頁番号も）。色の帯・縦線・色つきの枠は使わない | 黒だけ |
| フッター | 右下に「頁 / 総頁」 | 同じ |

- 表は「並べて見ると分かるもの」だけ（`03-structure.md` の5）。
- 「ポイント」「要確認」などの枠は使わない。
- 講義ノートの付録として判例研究を付けるときだけ、`--style note` でノートと同じ体裁にする。
- 利用者が前に仕上げたレジュメ（キット）があるときは、それを測って寸法を合わせる（`README.md` の「キットの再利用」）。
- 2回目以降の直しは、作り直さずに文書を直接編集する（`09-revision.md`）。
