# 各審級の書き方

三つの審級を、同じ型で書く。読み手が、どの審級が何を理由に結論を変えたかを追えるようにする。

## 1. 1審級の型

見出しは「第一審【請求棄却】」のように、結論を【 】で付ける。中身は4つ。

1. **裁判所・日付**：「○○地方裁判所　平成○年○月○日判決」。下級審の日付が確かめられなければ、裁判所名だけにする。
2. **当事者の主張**：その審級で新しく出た主張だけ。前の審級と同じ主張は繰り返さない。
3. **判断**：原文の引用。最高裁の判旨は全文を載せる。下級審は、最高裁の判決文が要約した範囲で書き、出所を断る。
4. **解説**：この審級が何を重くみたかを1〜2文で。

## 2. 前の審級からの変化

差分の表にしない。1段落で言い切る。

> 第一審から変わったのは、①法律構成を補ったこと、②法人格という形式ではなく使用の実態を重くみたことの2点である。

変化が結論を左右した点を先に書く。変わらなかった点（事実認定など）は、変わらなかったと一言で済ませる。

## 3. 上告審（中心）

| 項目 | 書くこと |
|---|---|
| 上告理由 | 上告人が、原判決のどこを誤りとしたか。解説に基づくなら出所を断る |
| 判旨 | 原文。段落ごとに区切り、漢数字など表記は原文のまま |
| 判旨の構造 | 表（段階／内容）。一般論・要件・例外・本件への当てはめ・結論の順に並べる |
| 控訴審からの変化 | 1段落 |
| 差戻審で考慮される事情 | 破棄差戻しのとき。判決が指示した点と、解説が挙げる点を分ける |
| 注目したい事実 | 考察につなぐ事実を1つ予告する（`07-original-point.md`） |
| その後 | 差戻審・再上告審の結末。確かめられたときだけ |

判旨の構造の表は、判決の文を短く切って並べるだけにする。言い換えるときは「」を外す。判決が理由を述べていない段には、理由を補わない。

## 4. 三審の比較

表1つ（論点／第一審／控訴審／最高裁）。行は、結論、法律構成、判断の基準、鍵になる評価の4〜5行まで。表の後に、争点が一つに絞られることを1文で書く。

## 5. 原文と解説を分ける

- 判決が述べた理由と、解説（調査官解説・評釈）が付けた説明を、同じ段落に混ぜない。
- 「本判決は…と判示した」（原文）と「調査官解説によれば…」（解説）を、主語で書き分ける。
- 判決が「特段の理由を付すことなく」結論だけ示した点は、そう書く。

## 6. スライドとの対応

審級1つにつき、スライドは1〜2枚（主張の枠／判断の枠（強調色）／下に1行の要点）。判旨の構造・その後の流れ・三審の比較は、それぞれ1枚（`../slides/02-layouts.md` の instance、holding_structure、instance_flow、compare_table）。
