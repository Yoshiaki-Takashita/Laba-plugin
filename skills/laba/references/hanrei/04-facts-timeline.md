# 事実の概要：当事者・相関図・時系列

事実は、判決文の「原審の適法に確定した事実関係」にあるものだけを書く。日付・金額は全部入れる。推論は「〜とみられる」と書き分ける。

## 1. 当事者の表

| 記号 | 立場 | 備考 |
|---|---|---|
| X | 原告・控訴人・被上告人 | 本件土地の所有者。当時未成年 |

- 立場の欄には、審級ごとの呼び名（原告・控訴人・被上告人）を並べる。
- 備考は、争点に効く属性だけ（年齢、親族関係、職業、会社との関係）。
- 表は元の形のまま保つ。利用者が見やすいと言った表を、次の版で別の形に変えない。

## 2. 相関図（レジュメ用の画像）

- 親族関係と取引関係のように、性質の違う関係は左右に分ける。
- 人物は白地・黒枠の箱（記号＋小さく役割）。争点になる権利関係だけ強調色、世話・事実上の関係は点線。
- 日付・金額は、判決が確定した事実だけを入れる。
- 図の文法（色、線の太さ、ラベル、検査）は本体の `../figures/` に従う。図題は「図　当事者の相関図（判決の確定した事実による）」。
- スライドの sokan を先に書いたときは、`scripts/hanrei/sokan_png.py 構成.json 図.png` で、同じ当事者・関係からレジュメ用の図を作れる（figgen の当事者関係図。groups を左右の囲み、emphasis の関係だけ強調色）。出力をレジュメの `facts.figure.path` に書く。記号と関係が、スライドとレジュメで食い違わなくなる。
- スライドでは、この図を貼らずに図形で描き直す（型は sokan。`../slides/03-diagram-on-slide.md` の 4-2）。スライドでは、相関図を当事者の枚と時系列の**前**に置く。

## 3. 時系列

- 段ごとに小見出しを付ける：「① 昭和○年○月〜　〔出来事の名前〕」。丸数字は、スライドの時系列の段と同じ番号にする。
- 1段は1〜3段落。1段に出来事を詰め込まない（新しい関係が2つ以上出るなら段を分ける）。
- 範囲は、提訴まで。訴訟の経過は各審級の節で書く。
- 各段の最後に、その段で新しく生まれた法律関係を1文で言う（だれとだれの間に、何が）。スライドでは、これが強調色の矢印になる。

## 4. 金額と日付の扱い

- 金額を大きな字で強調しない。金額そのものより、「だれが何を負担したか」という法的な地位を表にする（X の法的地位の表）。
- 極度額の変更、借入れの追加など、数字が変わる出来事は、変わる前後を1文で並べる。
- 元号は判決文の表記に合わせる。西暦を併記するかは、利用者の資料に合わせる。

## 5. 争点

時系列の後に、条文から争点へ流れる形でまとめる：「○条により…できるか → ○条に当たるか → 当たらないとして、…の法理で効果を否定できるか」。三審の判断を分けた点が、一つに絞られるように書く。レジュメでは「条文・法理／問い／本件での答え」の表（`facts.issue_table`）と1〜2段落、スライドでは同じ順の箱を横に並べる（型は issues。最後の箱だけ強調の枠）。この小見出し「(3) 本件の争点」の枚を、スライドで飛ばさない。

## 6. 確認

- 時系列の各文に、事実の番号（`01-research.md` 6 の F01…）が付くか。付かない文は削る。
- 記号の対応表と、本文の記号が一致しているか。
- 相関図・当事者表・時系列・スライドの4か所で、同じ人物が同じ記号・同じ役割で書かれているか。
