# 引用の格付け：読んだものだけを書く

読者（指導教員、演習の参加者）は引用元を知っている。読んでいない文献を読んだように書くと、最初に見抜かれるのはここである。書く前に、文献ごとに格付けを決める。

## 1. 格付けの表

判例研究の A・B・C と、学術レポートで使う確認段階 V0〜V3 は、同じものの別の呼び方である。

| 格付け | 確認段階 | 意味 | 本文でできること |
|---|---|---|---|
| **A** | V3 全文を読んだ | 判決の原文、利用者が貼った解説、自分で開いて読めた資料 | 「」の引用、頁つきの参照、著者名を出した要約。すべてできる |
| **B** | V1 二次資料で知った | 講義資料・教科書・判例集の解説が紹介している学説・判例 | 「」を付けない。原著者の名前を出さず「…とする見解がある」。段落の終わりに「（〔二次資料〕の整理による）」。参考文献には二次資料の側を載せる |
| **C** | V2 書誌だけ確かめた | 題名・号・頁は確かめたが、中身は読めていない | 本文に入れない。参考文献に書誌だけ載せてよい（学部の演習の場合）。渡すときに「読めていない」と報告する |
| **X** | V0 記憶だけ | 確かめていない | 書かない。台帳からも外す |

## 2. 書く前の判定（毎回）

1. この文の内容は、どの資料で読んだか。資料の ID を言えるか。言えなければ書かない。
2. その資料は A か。A でなければ、「」・頁・著者名を外す。
3. 言い換えに「」を付けていないか。「」は、原文と一字一句同じときだけ。表記（漢数字、読点の字形）も原文のまま。
4. 事実か、推論か。推論なら「〜とみられる」「〜と読める」と書く。

## 3. 「」と頁

- 判決文からの引用は、原文の表記のまま。省略は「……」、補いは〔 〕。
- 頁を書けるのは A だけ。利用者が貼った資料から頁を写したときは、その一覧を渡すときに報告する（利用者が原本で照合できるように）。
- 同じ文献の頁が、箇所によって食い違っていないかを `ledger.py` で確かめる。

## 4. 指導教員の文献

読者がその文献の著者本人でありうる場合、扱いをいちばん厳しくする。

- A（原文を読んだ）でなければ、本文に入れない。二次資料経由の紹介（B）でも入れない。
- 書誌を確かめられたら、参考文献に載せ、台帳に【指導教員】【要入手】の印を付ける。
- 渡すときに、「この文献は読めていない。図書館で確かめてから足すとよい」と伝える。
- 教員の見解を推測して書かない。教員の名前を、確かめていない見解に結びつけない。

## 5. 台帳

1文献1行。タブ区切りのファイルにする（`scripts/hanrei/samples/ledger_sample.tsv` が見本）。

```
id    書誌    確認に使った資料    格付け    使い方
R01   最判…（判決原文）    裁判所の判例検索（全文）    A    事実・判旨【中心】【一次】
R02   講義資料（○○の項）    利用者が貼った資料    B    前提知識【二次】
R03   □□「…」雑誌○号    出版社の目次ページ    C    本文に入れない【要入手】
```

- 本文の下書きでは、文献を〔R01〕のように ID で指す。検査が済んだら、仕上げで ID を外す（`resume_build.py --strip-ids`）。
- 検査：`python3 scripts/hanrei/ledger.py 本文.txt --ledger 台帳.tsv`。格付けのない行、A でない文献への「」・頁、C・X を本文で使った箇所、指導教員の未読文献、B の「（〜の整理による）」の抜け、台帳にない ID を出す。
- 台帳は、成果物とは別に渡す。

## 6. 渡すときの報告（必ず）

- B に当たる箇所の一覧（どの段落が、どの二次資料に基づくか）。
- C の文献の一覧（読めていない。読めば足せる内容の見込み）。
- 貼られた資料から写した頁数の一覧。
- 【要入手】の文献。重要なもの（調査官解説、主要な評釈）が読めていないときは、報告の冒頭に書く。

## 7. 書き換えの例

格付けに合わない文を、どう直すか。文献名・著者名は例のための仮のものである。

| 元の文 | 格付けと問題 | 直した文 |
|---|---|---|
| 甲野教授は「特段の事情は賃借人が立証すべきである」と述べる（甲野・○○法 123 頁）。 | B（講義資料の紹介で知っただけ）。「」・著者名・頁は使えない | 特段の事情は賃借人の側が主張・立証すべきであるとする見解がある（講義資料の整理による）。 |
| 調査官解説によれば、本判決は従来の判例を変更したものではない。 | C（書誌だけ確かめた。中身は読んでいない） | 本文から外す。参考文献に書誌だけ載せ、渡すときに「読めていない」と報告する |
| 判決は「実態に変化がない」と判示した。 | A（判決原文）だが、「」の中が原文と違う（原文は「実態に変わりがない」） | 判決は「実態に変わりがない」と判示した。（原文をもう一度開いて、一字ずつ照らす） |
| 最高裁は、背信性がないので解除できないとした。 | A。ただし、判決の言葉ではなく自分の要約なのに、判旨のように読める | 最高裁は、背信的行為と認めるに足りない特段の事情があるとして、解除の効力を否定した。（判決の用語で書く。「」は付けない） |
| Y は、X に無断で会社を設立した。 | 判決にない事実（判決が認定したのは、承諾なく使わせたことだけ） | Y は店の経営を Z 社に移し、Z 社は X の承諾をとらずに本件建物の一部を使うようになった。 |
| 学説の多数は本判決に賛成している。 | X（どの資料でも読んでいない。記憶） | 書かない。賛否の分布を書くなら、それを述べた資料（A）を示す |
| 指導教員の論文によれば、本判決の射程は狭い。 | 【指導教員】の文献で、A でない | 本文から外す。台帳に【指導教員】【要入手】を付け、報告の冒頭で伝える |
| 評釈は、本判決を「妥当」と評価する（○頁）。 | A（利用者が貼った評釈）。ただし頁は、貼られた資料から写したもの | そのまま書いてよい。写した頁の一覧に入れ、利用者が原本で照合できるようにする |

直すときの順番は、いつも同じである。(1) どの資料で読んだかを言う。(2) その資料の格付けを台帳で見る。(3) A でなければ「」・頁・著者名を外し、B なら「…とする見解がある（〜の整理による）」に、C・X なら本文から外す。(4) A なら、原文を開いて一字ずつ照らす。

## 8. 迷いやすい場合

| 場合 | 格付け | 理由 |
|---|---|---|
| 判決の原文を、裁判所の判例検索で全文読んだ | A | 一次資料を自分で読んだ |
| 判例集の解説を、利用者が全文貼ってくれた | A | 自分で読めた。頁は写したものとして報告する |
| 利用者が貼った解説の中で引かれている別の論文 | B | 読んだのは解説であって、その論文ではない |
| 検索結果の抜粋（数行）で内容が分かった | B か C | 全文を読んでいない。抜粋に書かれた範囲だけを、著者名を出さずに書くか、本文に入れない |
| 判決の要旨（裁判所のサイトの「裁判要旨」）だけ読んだ | A（要旨について）。理由の部分は読んでいない | 要旨は判決の理由そのものではない。理由を引くなら全文を読む |
| 教科書に載っている判例の紹介 | 判例の存在と結論は B。判決の理由は、原文を読むまで書かない | 教科書の説明と、判決が述べた理由を分ける（`../techniques.md`） |
| 前に読んだ記憶がある | X | 今、開いて読めなければ、書かない |

## 9. 本体の規則との関係

講義ノートでは、資料にない説明に「（補足）」を付ける（`../added-text-safety.md`）。判例研究では、これに当たるのが格付けである。A の資料に基づく文は資料の内容、自分の考察は「考察」の節に置き、B・C は上の扱いにする。判例の理由を、判決が述べたものと解説が付けたものに分けて書く規則（`../techniques.md`）は、判例研究でもそのまま守る。
