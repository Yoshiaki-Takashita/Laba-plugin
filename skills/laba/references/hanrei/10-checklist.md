# 確認表（判例研究）

渡す前に、上から順に確かめる。機械で確かめられるものは道具の名前を付けた。

## 調査

- [ ] 判決の全文を開いて読んだ。主文を全文で確かめた。
- [ ] 判例集の巻号頁・事件番号・事件名を、裁判所の判例検索の詳細ページで確かめた。
- [ ] 事実の控えに番号があり、レジュメの事実の文がどれも番号に対応する。
- [ ] 記号の対応表を作り、日付・金額の表記を原文と照らした。
- [ ] 個別意見の有無を確かめた。

## 引用

- [ ] 台帳の全行に格付け（A・B・C・X）がある。X は本文にない。（`ledger.py`）
- [ ] 「」の引用は A の資料だけで、原文と一字一句同じである。
- [ ] 頁は A の資料だけに付いている。貼られた資料から写した頁の一覧を作った。
- [ ] B の内容には「（〜の整理による）」があり、原著者の名前を出していない。
- [ ] 指導教員の文献は、原文を読んだものだけが本文にある。
- [ ] 参考文献は、本文で使ったものと一致する。

## 構成と中身

- [ ] 5章の構成で、節に通し番号がある。
- [ ] 前提知識の各節が、「本件では」で本件につながっている。
- [ ] 時系列の丸数字が、スライドの段と同じである。
- [ ] 各審級に、裁判所・主張・判断・解説がある。変化は1段落で書いた。
- [ ] 判旨は原文で、判決が述べた理由と解説の説明を分けた。
- [ ] 学説は対立軸が二つ以内で、各説の本件への当てはめがある。
- [ ] 考察 (1) は、判決文の事実から出た自分の論点である。解説の意義のなぞりではない。
- [ ] 判決にない事実を足していない。推論は推論と分かる。

## 文体と体裁

- [ ] 1文の平均が50字前後、100字を超える文は引用だけ。（`density.py`）
- [ ] 未確認の印・作業の記録が残っていない。（`ledger.py` の marker-left）
- [ ] 利用者の手が入った段落を変えていない。
- [ ] Word は黒一色、表は黒い細罫線の格子（見出し行を塗らない）、引用は左罫線の段落、参考文献は 8pt、本文は字下げなし、フッターに頁番号（`resume_build.py` の既定の体裁。`08-style.md` の6）。全頁を画像で見た。
- [ ] 仮の文字（「（…を書く）」「【要確認】」）が残っていない。（`resume_build.py` を `--draft` なしで通した）
- [ ] 表紙の所属・報告者・発表日が入っている。空なら、仮の文字であることを報告に書いた。

## スライド

- [ ] 見出しがレジュメの番号・題と1対1である。小見出し（「(3) 本件の争点」「考察 (2)」）の枚が抜けていない。当事者の記号、時系列の段の数、日付・金額がレジュメと同じである。（`scripts/hanrei/sync_check.py` の error 0。`deck_lint.py` の heading-order）
- [ ] スライドにだけある内容がない。限定の言い方（「〜とは読めない」「原則として」）を言い切りに変えていない。（`sync_check.py` の content-not-in-resume・hedge-dropped を1件ずつ見た。語の重なりで調べる近似なので、考察と射程の枚は目でも照らす）
- [ ] 相関図が、当事者・時系列の前にある。図形で描き、争いの中心の関係だけが強調の色である。
- [ ] 図は図形で描いた。図を画像で貼っていない。（`deck_lint.py` の picture）
- [ ] 時系列は1段ずつ積み、新しい関係だけ強調色である。
- [ ] はみ出し・重なり・色の外れ・語の途中の改行・仮の文字が0。（`deck_lint.py` を `--draft` なしで掛けて error 0。「描画後の検査：済み」と出ていること）
- [ ] 1枚の文字数が、平均 150〜230 字の間にある（完成版は平均 189 字）。下が空いた枚・枠の中が空いた枚がない。（`deck_lint.py` の sparse・frame-empty、`build_deck.js` の「確かめる所」）
- [ ] 全枚を画像にして、語の途中の改行・余白の多すぎる枚・図の片寄りを直した。
- [ ] PowerPoint の実機では確かめていないことを、報告に書いた（確かめたのは LibreOffice の描画）。
- [ ] 発表時間に対して枚数が合っている（進行表 `--outline`）。

## 独立の点検

- [ ] 本文を書いていない点検者に、法的な正確さ（条文、判例の事案・結論・理由、「」の照合）を見てもらった。（指示文は `../reviewer-prompts/`）
- [ ] 点検者の「記憶による」指摘は、原典で確かめてから直した。
- [ ] 独立の点検ができなかったときは、報告に「未実施」と書いた。

## 渡すとき

- [ ] レジュメ、スライド、台帳を渡した。
- [ ] 報告に、B・C の箇所、写した頁、読めていない重要文献、仮置きを書いた。
- [ ] 前の版を残した。
