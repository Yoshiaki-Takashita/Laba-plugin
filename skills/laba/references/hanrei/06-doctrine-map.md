# 学説：対立軸を二つに絞る

学説を並べるだけの節にしない。本件の結論を左右する対立だけを取り上げ、各説が本件でどういう結論になるかまで書く。

## 1. 対立軸の選び方

1. 判旨の中で、結論を分ける判断が何か所あるかを数える（例：ある条文に当たるか／当たらないとして別の法理で救えるか）。
2. それぞれの判断について、反対の立場が実際にあるかを、読めた資料（A・B）で確かめる。
3. 二つまでに絞る。三つ目以降は「その他の見解」として1段落にまとめるか、落とす。

対立軸の候補は、たいてい次のどれかである。

| 型 | 例 |
|---|---|
| 判断の基準（形式か実質か） | 行為の外形で決めるか、動機・結果まで見るか |
| 処理の段階（どの要件で受け止めるか） | 要件に当たらないとするか、当たるとしたうえで例外で救うか |
| 保護の範囲（だれをどこまで守るか） | 本人の保護を広げるか、相手方の信頼を優先するか |
| 効果（無効か、取消しか、対抗できないだけか） | 改正の前後で変わった場合を含む |

## 2. 1軸の書き方

1. **対立の構図**：何について、どの立場とどの立場が分かれるかを2文で。
2. **両説を1段落ずつ**：主張、理由、本判決との関係。読めていない学説の主張者名は出さない（「…とする見解がある」）。
3. **本件への当てはめ**：各説に立つと、本件の結論がどうなるか。ここがなければ、学説の節を置く意味がない。
4. 表は1軸につき1つまで（判断の対象／長所／短所／立場）。二つ目の軸は文章で書く。

## 3. 書かないもの

- 各審級がどの説に立つかを並べる位置づけ表（審級の節と重複する）。
- 読めていない論文の要約。存在だけに触れる文（「〜の論文がある」）も書かない。
- 説の名前だけの列挙。

## 4. 出所の書き方

- 二次資料で知った学説は、段落の終わりに「（〔講義資料・判例集の解説〕の整理による）」。
- 利用者が貼った解説から引くときは、解説者の名前と頁を書ける（貼られた資料に頁があるとき）。
- 指導教員の見解は、原文を読んだときだけ（`02-citation-grade.md` 4）。

## 5. スライドとの対応

1軸1枚。左右に両説の枠を置き、本判決の側を強調色の枠にする。下に1行で「違いがどこに現れるか」（`../slides/02-layouts.md` の doctrine_lr）。反対する立場は別の1枚（opposition）。
