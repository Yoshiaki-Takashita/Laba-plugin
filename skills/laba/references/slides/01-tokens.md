# 寸法・書体・色の数値

数値は `scripts/slides/lib/tokens.js` にあり、ここと対応している。変えるときは両方を直す。寸法はインチ、文字は pt。

## 1. 元にした実測

完成版として認められた発表資料（48枚）を、python-pptx で測った（2回目の測り直し。数え方は `deck_lint.py` と同じ）。

| 項目 | 実測 |
|---|---|
| スライド | 16:9（10 × 5.625） |
| 1枚の文字数 | 平均 189字、中央値 181字、最小 76字、最大 304字（見出し・大項目名・頁番号を除く） |
| 太字の割合 | 95%（太字でないのは条文の本文と注） |
| 文字サイズ（字数の多い順） | 17pt、16pt、15.5pt、15pt、18pt、16.5pt、14.5pt。この7段で本文の約9割。12pt（役割）、10.5pt・9pt（図の中の注・条文の注）が少し。表は 13.5pt が最多、次に 15pt・13pt |
| 文字の色 | 黒 73%、強調 12%、基調 7%、灰 6%、濃色 1% |
| 線の太さ | 2.25pt（枠。71個）が最多、2.5pt と 4pt（矢印）、1.5〜1.75pt（区切り線・表・相関図の箱）、1pt |
| 枠の内側の余白 | 左右 0.2、上下 0.1〜0.12 |
| 段落の後ろの空き | 3〜12pt（5pt が最多、次に 6・8・10pt）。行数の少ない枠ほど広い |
| 本文の領域の使い方 | 枠・文字の下端は、ほとんどの枚で 4.9〜5.15。下が空くのは最大でも領域の 29% |
| 表 | 10個、どれも幅 9.2（本文の領域いっぱい）。罫線に黒（#000000）が残る表がある |
| ピクト | 黒い単色の画像 58個（0.6×0.6 が43、0.8×0.8 が8、0.7×0.7 が6、1.1×1.1 が1） |
| 太い矢印（4pt） | 1枚に3〜4本の枚が3枚ある（ほかは2本まで） |
| 見出しの長さ | 最長で全角 24 字分 |

この実測に合わせて直した値（前 → 後）。前の値は、1回目の実測の読み違いか、根拠のない推測だった。

| 項目 | 前 | 後 | 理由 |
|---|---|---|---|
| 1行の字数から引く余裕 | 全角 0.3 字 | 全角 0.6 字 | 書体が置き換わると行が延び、表示側でもう一度折れた |
| 和文と英数字の境の空き | 見込まない | 0.25 字 | LibreOffice が自動で空ける。「Y1には…Y2には」の行で折れた |
| 改行の位置 | 文節で切れなければ禁則だけ守って切る | 語・条文番号・判例の表記の途中では切らない。切れなければ作成を止める | 「41条1項・2／項」「特段の／事情」が出た |
| 余った高さの配り方 | 枠を最大 45% 広げる | 段落の間を 6→12pt、次に枠を最大 35%（0.6 インチまで） | 2行の枠が大きく広がり、中が空いた |
| 1枚の文字数の下限 | なし | 75字未満の枚・平均 150字未満の資料は知らせる | 見本の平均が 125字で、完成版（189字）より薄かった |
| 時系列の帯の高さ | 段ごとに行数で決める | いちばん行の多い段に全段をそろえる | 段によって図の位置が動いた |
| ピクトの種類 | 13 | 18（背広の人、保証協会などの機関、位置の印つきの土地、木槌、天秤を追加） | 完成版は当事者の属性でピクトを使い分けている |
| 整理軸の軸の文字 | 14pt | 15pt | 本文の下限（15pt）を下回っていた |
| 正誤の印 | ○は基調の色、×は強調の色 | どちらも黒（形で区別） | 色だけで意味を分けない |
| 図形 | 1枚あたり平均14個 | （数えない） | 目安にならない |

## 3. 書体と文字サイズ

書体は Yu Gothic の1種類（見出しも本文も）。無い環境では、同じ幅のゴシック体に置き換わる。

| 用途 | サイズ | 太字 |
|---|---|---|
| 表紙の題 | 40 | ○ |
| 表紙のテーマ | 26（長ければ 22） | ○ |
| 表紙の報告者 | 22 | ○ |
| 表紙の判決情報・日付 | 16 | ○ |
| 見出し | 20 | ○ |
| 大項目名 | 11 | ○（灰） |
| 本文・枠の中・要点 | 18 → 17 → 16 → 15（収まる最大） | ○ |
| 条文の本文 | 15 → 14.5（下限） | × |
| 表 | 15.5 → 15 → 14 → 13 | ○ |
| 当事者の記号 | 30（当事者スライドは、2列のとき 34） | ○ |
| 相関図の箱 | 記号 17、説明 10.5（灰） | ○ |
| 当事者の立場（当事者スライド） | 15.5〜17（基調の色） | ○ |
| 役割（記号の下） | 12 | ○（灰） |
| 矢印のラベル（新しい関係） | 15 | ○（強調） |
| 矢印のラベル（前からの関係） | 12 | ○ |
| 帯の見出し／箇条 | 17／15 | ○ |
| 参考文献 | 11〜16（件数が少なければ大きく） | × |
| 図の中の小さい注・相関図の線のラベル | 10.5 | ○ |
| 枚の隅の注（専門用語の説明） | 9（灰） | × |
| 頁番号 | 10 | ×（灰） |

- 下限（役割ごと。完成版 48 枚の実測で決め、`build_deck.js` と `deck_lint.py` の font-small で同じ値を使う）

| 役割 | 下限 | 完成版の実測 | 下回ったとき |
|---|---|---|---|
| 本文・枠の中・条文（黒、25字以上の箱で、幅 4.5 インチ以上か 60 字以上） | 14.5 | 最小 14.5（条文 3 枚と → の1行）。ほかは 15 以上 | 作成を止める（error）。textfit は 14.5 より小さくして収めない。要約するか2枚に分ける |
| 表 | 13 | 最小 13（13.5 が最多） | 15 を下回るときは、先に列の幅を中身に合わせて配り直して試す（作成時に知らせる）。それでも 13 未満なら error |
| 図の中の短い注（幅 4.5 インチ未満で 60 字未満の箱） | 10 | 10〜10.5（相関図） | error |
| 灰色の注・頁番号 | 9 | 9 | font-floor（error） |

  本文が 15 を下回る枚は、作成時に「確かめる所」に出す（止めない）。
- 行送りは文字サイズの 1.32 倍（固定値で指定する。環境で行の高さが変わらないようにするため）。
- 段落の間は 6pt。枚に余りがあれば 12pt まで広げる。
- 1行の字数：枠の内側の幅 ÷ 文字サイズ から、全角 0.6 字を引く。和文と英数字の境は 0.25 字と数える（`05-text-fitting.md`）。

## 5. 色（配色は2つ）

| 役割 | teal（発表用の既定） | mono（印刷・ノートの図とそろえる） |
|---|---|---|
| 文字 ink | 1A1A1A | 1A1A1A |
| 基調 base（枠線・条文名・表の罫線） | 2F6F6C | 1A1A1A |
| 濃色 dark（表紙の題） | 17403F | 1A1A1A |
| 強調 accent | C2543A | 943522 |
| 帯 band | E3EDEB | EDEFEF |
| 灰 gray（補足・頁番号） | 8A9493 | 8C9493 |
| 区切り線 rule | D0D6D5 | C9CECD |
| 表の見出し行 | 基調の塗り＋白の字 | 帯の色の塗り＋黒の字 |

- teal は、認められた発表資料の色。発表ではこちらを使う。
- mono は、講義ノートの図（黒・灰・強調1色）と同じ色。ノートから起こした復習用のスライドや、白黒で配る資料に使う。
- この表にない色は使わない（`deck_lint.py` の off-palette）。黒（#000000）だけは、表の既定の罫線などに残ることがあるので許す（完成版にもある）。
- 利用者の完成版（キット）の色・書体に合わせるときは、`scripts/hanrei/kit_measure.py` で測り、`build_deck.js --kit` で渡す。

## 6. 文字の装飾の記法（構成の JSON の中）

| 記法 | 意味 |
|---|---|
| `{r:語}` | 強調の色（要点の語） |
| `{b:語}` | 基調の色（条文名・判例名・枠の小見出し） |
| `{g:語}` | 灰（補足） |
| `{n:語}` | 太字にしない |

強調は語に付ける。1枚に強調の色が多すぎると、どれも目立たなくなる（目安：1枚の文字の2割まで。4割を超えると `deck_lint.py` の accent-heavy。完成版は全体で 12%、多い枚で 35%）。

## 7. 密度と時間

| 項目 | 値 |
|---|---|
| 1枚の文字数の目標 | 190字前後（資料全体の平均で 150〜230 字） |
| 少ない | 75字未満の枚（完成版の最小は 76字）、平均 150字未満の資料 |
| 注意 | 330字を超える |
| 分ける | 420字を超える |
| 発表原稿の速さ | 1分に300字 |
| 1枚の時間 | 15〜90秒 |
