# 関係図を図形で描く

図の型（`../figures/02-types/` の25型）と、図に共通する文法（`../figures/01-grammar.md`）は、本体の `../figures/` にある。ここでは、スライドの上で関係図を描くときの決まりだけを書く。

## 1. 部品

| 部品 | 形 | 大きさ |
|---|---|---|
| 当事者 | 黒いピクト（図形の組合せ）＋右に大きな記号＋下に小さく役割 | ピクト 0.6、記号 30pt、役割 12pt 灰 |
| 当事者（相関図） | 白地＋黒の細い枠の箱に、記号（名）と小さい灰色の説明 | 記号 17pt、説明 10.5pt、枠 1.5pt（強調・基調の箱は 2.25pt） |
| 結びつき（親子・夫婦・所有） | 矢じりのない黒の線（`arrow: false`） | 線 2.5pt、ラベル 12pt |
| 事実上の関係（世話など） | 点線（`dash: true`） | 同上 |
| 関係 | 黒の矢印。上か横にラベル | 線 2.5pt、ラベル 12pt |
| その段で新しく出た関係 | 強調の色の矢印とラベル | 線 4pt、ラベル 15pt |
| 図の中の短い注記 | 強調の色の文字（「Yは使途を知っていた」など） | 15pt |
| 下部の帯 | その段の出来事（見出し＋「・」の箇条） | 17pt／15pt |

ピクトの種類（`kind`）は18種。当事者の属性が絵で分かるように使い分ける（全員を person にしない）。

| 使う場面 | kind |
|---|---|
| 人 | person（人）、woman（女性・母）、child（子・未成年者）、suit（背広の人。会社の代表者・叔父など）、group（複数人） |
| 組織 | company（会社）、bank（銀行・金融機関）、landmark（保証協会・公的な機関）、court（裁判所）、agency（官庁） |
| 物 | land（土地）、landpin（土地。位置の印つき。本件土地）、house（建物）、document（書面・契約書）、money（金銭）、goods（物） |
| 抽象 | gavel（裁判・判決）、scale（衡量・比較） |

どれも四角・円・三角の組合せで描く。丸で囲まない。色を付けない。完成版として認められた発表資料は、黒い単色のピクト画像（0.6〜0.8 インチ）を使っている。画像のピクトを使うなら、黒の単色・丸なし・1.3 インチ以下にする（`deck_lint.py` はこの大きさまで許す）。図そのものを画像で貼ることはしない。

## 2. 書き方（構成の JSON）

```json
"diagram": {
  "actors": [
    { "id": "X", "kind": "person", "symbol": "X", "role": "賃貸人", "col": 0, "row": 0 },
    { "id": "Y", "kind": "person", "symbol": "Y", "role": "賃借人", "col": 1, "row": 0 },
    { "id": "T", "kind": "house", "symbol": "", "role": "本件建物", "col": 0, "row": 1 }
  ],
  "relations": [
    { "from": "X", "to": "Y", "label": "賃貸借", "both": true },
    { "from": "X", "to": "T", "label": "所有" }
  ]
}
```

- 当事者は格子（`col`・`row`）に置く。座標は書かない。格子の大きさは、全部の当事者から決まる。
- 関係は `from` → `to` の矢印。`both: true` で両向き、`arrow: false` で矢じりのない線（親子・夫婦・所有のような結びつき。向きのない関係に矢印を使わない）、`dash: true` で点線（事実上の関係）、`emphasis: true` で強調の色（時系列の段では、`emphasis: false` を付けると、その段で出ても黒のままにできる。所有や親子のような背景の関係に使う）、`color: "base"` で基調の色、`small: true` でラベルを 10.5pt に。
- `col`・`row` は小数で書ける（`"col": 1.5`）。線が当事者の上を通るとき、ラベルが置けないときに、半分ずらす。
- 図の中の注記は `"notes": [{ "text": "…", "col": 2, "row": 1, "step": 3, "dx": 0.2, "dy": -0.1 }]`。置く場所は格子のます（`col`・`row`。当事者のいないます）で指定し、`dx`・`dy`（インチ）で微調整する。当事者・線・ラベルに重なると、作成時に止まる。長い説明は注記にせず、下部の帯か右の枠に書く。
- ラベルは、矢印や当事者に重ならない位置に自動で置かれる（線の上か横。置けなければ2行に分け、それでも置けなければ作成時に止まる）。語の途中で折れる分け方はしない。
- 線が、ほかの当事者（ピクト・記号・役割の文字）の上を通る配置は、作成時に止まる。当事者の位置を変える。

## 3. 配置の決まり

- **原告側を左、被告側を右**に置く。物（土地・建物）は、持ち主の下に置く。
- **同じ種類の関係は同じ向き**にする（お金の流れは横、所有は縦、など）。
- **矢印を交差させない**。交差するなら、当事者の位置を入れ替える。
- 1枚の図に、当事者は6人まで、関係は7本まで。超えるなら、関係の種類で2枚に分ける（親族関係と取引関係、など）。
- ラベルは短く（全角8字まで。超えると作成時に知らせる）。日付や金額は、ラベルではなく下部の帯に書く。必要なら「根抵当権／3000万円」のように2行にする。
- **最初の段から、図が左右に広がるように置く**。時系列で、最初の段に出る当事者を左の列にだけ置くと、1枚目の図が左に片寄る（作成時に知らせる）。最初から出る当事者を両端か中央寄りに置き、後から出る当事者をその間か下に置く。
- 当事者の間は、ラベルが入る幅をとる。3列を 6 インチに詰めると、強調のラベル（15pt）が入らない。3列なら図は全幅（9.5 インチ）、右に解説の枠を置くなら2列まで。

## 4. 強調の色の使い方

- 強調の色は、**その枚で言いたい関係1〜2本だけ**に使う。
- 時系列では、その段で新しく出た関係が強調の色になる（`04-step-reveal.md`）。
- 関係図（時系列でない1枚）では、どれも黒で描き、右の枠で言いたいことを書く。争点になる関係だけを強調したいときは、その関係に `"emphasis": true` を付ける（1枚に2本まで）。

## 4-2. 相関図（sokan）

判例研究では、時系列の前に、当事者の全体の地図を1枚で見せる（`02-layouts.md` の 33）。

- 図形で描く（画像にしない）。当事者は、白地＋黒の細い枠の箱。箱の中に記号（名）と、小さい灰色の説明。
- 関係の種類が2つあれば、左右に分ける（左に親族関係、右に取引関係。間に縦線、上に小さい題）。両方に関わる当事者は、縦線の近くに置く。
- 結びつき（親子・夫婦・所有）は矢じりのない線、世話などの事実上の関係は点線、取引（貸付・保証・設定）は矢印。
- **争いの中心になる関係1本だけ**を、強調の色の太い矢印にする。その当事者の箱も強調の色の枠にしてよい。原告や本件の目的物は、基調の色の枠にしてよい。ほかは黒。
- 日付・金額は、判決の確定した事実だけを、ラベルの2行目か箱の説明に小さく書く。
- 図の右下に、争いの中心を1行で書く（帯の色の地）。
- この後に、当事者（parties）→ 時系列（timeline。段ごと）→ まとめの表、の順で続ける。時系列の最後の段の図と、相関図の関係が食い違わないようにする。

```json
{ "type": "sokan", "heading": "3. 事実の概要　当事者の相関図",
  "groups": [{ "title": "賃貸借の関係", "cols": 2 }, { "title": "会社の関係", "cols": 2 }],
  "diagram": { "cols": 4,
    "actors": [ { "id": "X", "symbol": "X", "sub": ["賃貸人"], "col": 0, "row": 0, "color": "base" },
                { "id": "Z", "symbol": "Z社", "sub": ["Yが設立した会社"], "col": 2.6, "row": 0, "color": "accent" } ],
    "relations": [ { "from": "X", "to": "Y", "label": "賃貸借", "arrow": false },
                   { "from": "Z", "to": "T", "label": "使用（承諾なし）", "emphasis": true } ] },
  "caption": ["争いの中心：Z社による使用は、Xの承諾のない転貸か"] }
```

## 5. 画像にしない理由

講義ノートやレジュメの図（画像）を、スライドに貼らない。スライドでは図形で描き直す。

- 貼った図は、文字が小さい（ノートの図は紙の幅 150mm に合わせてある）。
- 直せない。積めない。
- スライドの色・線・書体と揃わない。

`deck_lint.py` は、大きな画像（1.3 インチ超）が貼られたスライドを error にする。小さい単色のピクト画像は許す（`--no-pictos` でピクト画像も error にできる）。写真など、図形で描けないものを載せるときだけ `--allow-pictures` を付ける。

## 6. ノートの図の型との対応（25型すべて）

ノートの図（`../figures/02-types/` の25型）をスライドにするときは、貼らずに、次の型で描き直す。`note_to_deck.py` は、図題の語から型を選んで雛形を出す。

| # | ノートの図の型 | スライドの型 | 描き直すときの要点 |
|---|---|---|---|
| 01 | 当事者関係図 | relation | 当事者は6人まで。物（土地・建物）も置く |
| 02 | 三者間・多数当事者 | relation（2枚に分ける）、sokan | 関係の種類で左右に分ける |
| 03 | 時系列の積み上げ | timeline（段ごと） | 段ごとに1枚。位置を動かさない |
| 04 | 権利移転の連鎖 | instance_flow、relation | 左から右へ箱を並べる。移転の原因を箱の2行目に |
| 05 | 対抗関係 | relation | 二重の移転を2本の矢印、対抗の線を点線に。優先する側を強調 |
| 06 | 審級の流れ | instance_flow | 結論が変わった段を強調の枠に |
| 07 | 要件効果の木 | points、blocks（効果の枠＋要件の箇条） | 効果を上の強調の枠、要件を ①②③ の箇条に |
| 08 | 請求・抗弁・再抗弁 | yoken | 段を右へずらして積む |
| 09 | 主張立証責任の分配 | compare_table、doctrine_lr | 相手ごと・場面ごとを列に。真偽不明のときの帰結を最後の行に |
| 10 | 判例の変遷 | time_axis、timeline_table | 時期を軸に、その時期の規律を出来事の下に |
| 11 | 学説の対立地図 | doctrine_lr（2説）、compare_table（3説） | 分かれる問いを行に。本判決の側を強調 |
| 12 | 条文の構造 | statute、compare_table | 本文・ただし書・各号を行に分ける |
| 13 | 数直線 | time_axis | 期間・順位を軸の上の両矢印で |
| 14 | 組織図 | blocks（flow を上下に2段）、relation | 選任・監督・報告を線の種類で分ける |
| 15 | 手続のスイムレーン | compare_table（列＝主体、行＝段階）、instance_flow | 主体を列にした表に直す |
| 16 | 決定木 | branch | 問いは3つまで。はい／いいえで答えられる問いに |
| 17 | 包含図 | axis、compare_table | 広い概念と狭い概念を、表の行か2×2に直す（入れ子の四角は描かない） |
| 18 | 時間軸 | time_axis（期間）、timeline（出来事の順） | 期間の長さを見せるか、順序を見せるかで選ぶ |
| 19 | 座標図 | axis | 「ない」組合せも枠を置く |
| 20 | 比較図 | compare_table、doctrine_lr | 同じ問いを同じ行に。違いの出る行だけ強調 |
| 21 | 判例マトリクス | case_matrix | 1セルは日付と結論だけ |
| 22 | 流れ図 | instance_flow、issues（順に進む）、branch（分かれる） | 箱は4個まで |
| 23 | 動きの図 | relation（及ばない関係を点線に）＋右の枠 | 及ぶ・及ばないを線の種類で |
| 24 | 価値配分 | compare_table（数値の表） | 帯の図は描かず、数値の表に直す |
| 25 | 複合図 | 2枚に分ける | 同じ型を2枚続け、違う所だけ強調 |

## 7. 確認

- 全枚を画像にして、ラベルと矢印・ピクトの重なりを見る（`deck_lint.py` の overlap でも出る）。
- 太い矢印（強調の関係）は1枚（1段）に2本までが目安。5本以上あると、`deck_lint.py` が new-arrows の警告を出す。段を分けるか、強調を外す。
- 同じ当事者が、どの枚でも同じ位置・同じ記号・同じ役割で出ているか。
- 図に描いた関係が、どれも本文（レジュメ・ノート）に根拠を持つか。本文にない関係を描かない。
