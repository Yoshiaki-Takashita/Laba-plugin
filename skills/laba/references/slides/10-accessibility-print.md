# 配布・印刷・白黒

スライドは、映すだけでなく、刷って配り、後で読み返される。どの使い方でも読めるようにしておく。

## 1. 白黒で刷っても読める

- 意味を、色だけで伝えない。強調の色の語は太字でもあり、強調の枠は枠の位置（下・右）でも分かるようにしてある。
- 新しく出た関係は、色だけでなく線が太く（4pt）、ラベルが大きい（15pt）。白黒でも区別できる。
- 白黒で配ると決まっているなら、mono の配色で作る（`--theme mono`）。表の見出し行が、塗りつぶしではなく薄い帯になる。
- 確かめ方：PDF を灰色にして画像にし、強調の語・強調の枠・新しい矢印が見分けられるかを見る。

## 2. 配布用の PDF

- 1頁に1枚（映す用と同じ）か、1頁に2枚（上下）。1頁に4枚以上にすると、15pt の文字が読めなくなる。
- 時系列の段ごとの枚は、配布用では最後の段とまとめの表だけにしてよい（配布用の構成を別に作る）。
- 発表原稿（ノート欄）を配るかどうかは、利用者に聞く。既定では配らない。

## 3. 文字の大きさと教室

- 本文 15pt 以上は、後ろの席から読める下限である。小さな部屋・画面共有なら 14pt まで許せるが、既定は変えない。
- 役割・注記（12pt 以下）は、読めなくても話が追える内容だけにする。

## 4. 色覚

- 基調（青緑）と強調（赤茶）は、明るさが違うので、色の区別が付きにくくても濃淡で見分けられる。mono の配色は、黒と赤茶（強調）だけなので、区別の負担が小さい。
- 赤と緑を、対立する意味（正しい・誤り）に使わない。正誤の確認（tf_check）は、○と×を同じ色（黒）で描き、形で区別する。枠の色も変えない（誤りの文を強調の色の枠にしない）。

## 5. 読み上げ・検索

- 図を図形と文字で描いているので、スライドの文字はすべて検索・コピーできる。
- 見出しは、どの枚にも付ける（表紙・目次を除く）。番号で場所が分かる。
- 記号（X・Y・A）には、必ず役割を添える（図の中では下に、当事者の枚では説明に）。

## 6. 持ち運び

- 書体は Yu Gothic を指定している。無い環境では、同じ幅のゴシック体に置き換わる。改行は作るときに入れてあり、和文と英数字の境の空きと、全角 0.6 字分の余裕を見込んであるので、置き換わっても語の途中で折れにくい。`deck_lint.py` は、描画した後の行を読んで、指定していない改行がないかを確かめる（書体が置き換わっていれば、その旨を出す）。PowerPoint の実機での表示は、渡す前に利用者に見てもらう。
- 行送りは固定値なので、環境が違っても枠からはみ出しにくい。
- 動画・音・アニメーションは使わない。時系列の「積み上げ」は、枚を分けて作ってあるので、PDF にしても同じように見せられる。

## 7. 渡すときに伝えること

- 配色（teal か mono）と、その理由。
- 表紙の仮の文字（報告者・発表日・所属）。
- 画像にして全枚を見たこと、検査の結果（error・warn の件数、描画後の検査をしたか）。
- PowerPoint の実機では確かめていないこと（確かめたのは LibreOffice の描画。書体が置き換わっていれば、そのことも）。
- 配布用の PDF を別に作るかどうかの確認。
