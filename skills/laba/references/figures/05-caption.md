# 05　図題と注

図題は、図を見る前に「何を見ればよいか」を教える文である。図の下の注は、図に入りきらなかった留保を一つか二つ、文で添える所である。どちらも、名詞を並べるだけにしない。

## 1　図題の形

```
図N　この図で分かること：〔メッセージの一文〕。〔読み方の一文〕。強調は〔強調の意味〕。
```

| 部分 | 中身 | 例 |
|---|---|---|
| 番号 | 本文に出てくる順の通し番号。「図1」から | 図3 |
| この図で分かること | 仕様の `message` と同じ内容の一文。主語と述語がある。主題（「〜について」）ではなく主張 | 登記を先に備えた第二譲受人が、先に契約した第一譲受人に優先する。 |
| 読み方 | どこからどこへ読むか。線や帯の意味。一文 | 実線の矢印は譲渡、破線は対抗できる関係を表す。 |
| 強調の意味 | えんじの枠・線が何を指すか | 強調は、優先する譲受人とそこへの譲渡。 |

- 三つの文はどれも述語で終える。「筆者作成。」「三つの類型。」のような断片を置かない。
- 図題は図の**下**に置く（表の題は上）。番号と図題は本文と同じ書体、本文より一段小さい字。
- 図の中に図題を入れない。図の中にあるのはラベルと注だけ。
- 長さは二行から三行（80〜140 字）。三行を超えるなら、読み方を本文に移す。

## 2　メッセージの書き方

| よくない | よい | 何が違うか |
|---|---|---|
| 二重譲渡の関係 | 登記を先に備えた譲受人が優先する。 | 主題ではなく、結論を言っている |
| 共同正犯・教唆犯・幇助犯の比較 | 自ら実行したか、重要な役割を果たしたかの順に問うと、三つの類型のどれに当たるかが決まる。 | 比べて何が分かるかを言っている |
| 法定地上権の要件 | 法定地上権が成立するかは、抵当権設定時に建物があったかで決まる。 | 決め手を言っている |
| 訴訟要件の流れ | 取消訴訟は、四つの訴訟要件をすべて満たして初めて本案の審理に進み、一つでも欠けると却下される。 | 進む先と外れた先を言っている |

メッセージが書けないときは、図が要らないか、二つの図が混ざっている。

## 3　読み方の決まり文句

型ごとに、読み方の文はほぼ決まる。迷ったらここから取る。

| 型 | 読み方の文 |
|---|---|
| 当事者関係・多数当事者 | 矢印は、請求する人から請求される人へ向かう。破線は争いのある関係を表す。 |
| 権利移転の連鎖 | 左から右へ、権利が移った順に読む。 |
| 対抗関係 | 実線の矢印は譲渡、破線は対抗できる関係を表す。 |
| 審級の流れ | 左から右へ、第一審から上告審へ読む。 |
| 要件効果の木 | 下に並ぶ要件がすべてそろうと、上の効果が生じる。 |
| 積み上げ（攻撃防御） | 上から下へ、左の原告の主張と右の被告の主張を交互に読む。 |
| 比較・証明責任・学説 | 左右の列を、同じ段どうしで見比べる。 |
| 判例の変遷・時間軸 | 左から右へ時間が進む。軸の下の帯は、その間の状態を表す。 |
| 条文の構造 | 左の区分ごとに、中の場面から右の効果へ読む。 |
| 数直線 | 軸の上の括りは期間を表し、長さは年数に比例する。 |
| 組織図 | 上から下へ、選ぶ側から選ばれる側へ読む。 |
| スイムレーン | 横の帯は行為の主体を表し、左から右へ手続が進む。 |
| 決定木・流れ図 | 上（左）の問いから順に答え、枝をたどると結論に行き着く。 |
| 包含図 | 外の枠の概念が、中の枠の概念を含む。 |
| 座標図 | 横は〔観点1〕、縦は〔観点2〕で、四つの欄がその組合せを表す。 |
| 判例マトリクス | 行は〔訴えの向き〕、列は〔求める内容〕で、欄にその組合せの結論を置く。 |
| 動きの図 | 届く矢印は及ぶこと、止め線で切れた線は及ばないことを表す。 |
| 価値配分 | 帯の区切りは取り分を表し、括りはそれを把握する者を表す。 |
| 複合図 | 上下の図を、同じ位置どうしで見比べる。 |

## 4　確かさの層を図題で断る

図に、資料にない内容（書き手の補足、説明のための数値、仮の比率）が入るときは、図題か注で必ず断る。図の中だけで見分けさせない。

| 入れたもの | 図での見え方 | 図題・注での断り方 |
|---|---|---|
| 条文・判例・設例にあること | 実線・黒 | 断らない（根拠条文は線の横か注に書く） |
| 争いのある関係・仮定・学説の一つ | 破線 | 「破線は争いのある関係を表す。」 |
| 資料にない、書き手の補足 | ラベルに「（補足）」 | 「『（補足）』と付けた語は、資料にない補いである。」 |
| 説明のための数値・比率 | そのまま | 「年数は説明のための例である。」「帯の割合は説明のための仮の比率である。」 |
| 確かめていない審級・書誌 | 破線の箱 | 「破線の箱は、資料で確かめていない段である。」 |

「何がまだ分からないか」は、図ごとの注に毎回書かず、節の終わりの一か所にまとめる。図の注が留保だらけになると、図のメッセージが読めなくなる。

## 5　注（`notes`）

- 図の下、図題の上に置く。二つまで。三つ目が要るなら本文に書く。
- 主語のある完全な文にする。「背信的悪意者は除く。」ではなく「第二譲受人が背信的悪意者に当たるときは、第一譲受人は登記がなくても対抗できる。」
- 注に書くのは、(1) メッセージの例外、(2) 根拠の条文・主張立証の分担、(3) 図に入れた数値が例であること、のどれか。
- 新しい論点を注で持ち出さない。本文にない論点は、注にも書かない。
- 注の字は図のラベルと同じ大きさ。小さくしない。

## 6　本文での触れ方

- 図の前に、図を指す文を置く。「この関係を図3で確かめる。」「二つの型の違いは、図1の四段目に出る。」
- 図の後に、図から読み取ってほしいことを一文で受ける。「図3のとおり、分かれ目は登記の先後である。」
- 「下図」「上の図」と書かない。番号で指す（紙面が動くと指す先が変わる）。
- 図の語と本文の語をそろえる。図で「第二譲受人」なら本文も「第二譲受人」。

## 7　スライドでの図題

スライドでは、図題の「この図で分かること」をスライドの見出し（一枚一メッセージ）に上げ、図の下には読み方と強調の意味だけを一行にまとめる。段ごとに出す図では、下の帯にその段の事実を書く（`../slides/03-diagram-on-slide.md`、`../slides/04-step-reveal.md`）。

## 8　点検

| 項目 | どこで見るか |
|---|---|
| 図題が「図N　この図で分かること：」で始まる | `cli.js` の warn、`fig_lint.py` W08 |
| 「強調は」の文がある | `cli.js` の warn |
| 図題の文がどれも述語で終わる | 人が読む |
| 注が二つ以内で、主語がある | 人が読む |
| 資料にない内容の断りがある | `trace.py` の「なし」と突き合わせる |
| 本文に「図N」があり、図より前にある | `trace.py` T02 |
