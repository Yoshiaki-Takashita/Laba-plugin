# 06　図と本文の照合（追跡可能性）

図に書いた語・数字・条文番号・言い切りは、本文のどこかに根拠がなければならない。図にしかない内容は、読み手が確かめようがなく、誤りが紛れ込んでも気づけない。過去の誤りの多くは、図を本文と別に作ったことから生じた（限定語の脱落、勝ち負けの逆転、矢印の元の取り違え）。

## 1　三つの決まり

1. **語は本文から取る。** 仕様（JSON）のラベルは、本文の文から写す。図のために言い換えない。
2. **図にしかない内容を作らない。** 補うなら「（補足）」と付け、図題か注で断り、本文にも一文を足す（`05-caption.md` 4節）。
3. **照合してから出す。** 機械（`trace.py`）で所見を洗い出し、点検役が読み上げの表（`../reviewer-prompts/figure-check.md`）で全部の関係を一本ずつ読む。機械の結果は所見の一覧であって、合否ではない。
5. **所見を消すために語を削らない。** `trace.py` の所見を理由に、本文や図から要件・限定語・条文番号を外してはならない。所見が誤りだと読んだら、図を変えずに「所見を退ける理由」を書く（2節「所見を退ける」）。
4. **本文を先に書く。** 図を先に作って本文を合わせると、図の誤りが本文に写り、照合が何も見つけなくなる。本文（少なくとも、図が示す関係を述べる段落）を書いてから、仕様を書く。

## 2　機械の照合：`scripts/figgen/trace.py`（所見を出す補助）

**`trace.py` は、点検役が読むべき所見を出す補助であって、図と本文の一致を保証する検査ではない。** 出力の「所見なし（機械で見られる範囲で）」は、機械が読めた範囲で所見が出なかったという意味でしかない。独立採点（第4回）では、新しい種類の注入誤りの約半分が所見なしで通り、木の兄弟の入替えのように誤りでも所見が出ない場合があった。だから次の三つを守る。

- 所見なしを、正確さの根拠として報告しない（「trace 通過」「一致」と書かない。書くなら「trace：所見なし（機械で見られる範囲で）、照合できなかった要素 n 件は読み上げ済み」）。
- 出力が毎回出す「照合できなかった要素」と「機械で見ない種類」は、点検役が読み上げの表で必ず読む。0 件のときも、読み上げ（全部の関係）は省かない。
- 所見が出たら、まず本文を読み直す。図が誤りなら図を直す。本文に説明が足りないなら本文に書き足す。所見が誤り（偽陽性）なら、図を変えずに退ける理由を書く。

```
python3 scripts/figgen/trace.py spec.json --body 本文.md --fig 3
python3 scripts/figgen/trace.py specs/*.json --body 本文.md --out trace.json --strict
python3 scripts/figgen/trace.py 図.svg --body 本文.md        # 仕様がない図（SVG の文字を読む。語の照合だけ）
python3 scripts/figgen/trace.py spec.json --body 本文.md --relations 関係の表.md   # 関係の表とも突き合わせる
python3 scripts/figgen/trace.py spec.json --body 本文.md --dismiss 退ける所見.md   # 偽陽性と読んだ所見を、理由つきで退ける
```

ラベルごとに、次のどれかが付く。語が本文に出てくるかだけを見ており、意味が合うかは見ない。

| 判定 | 意味 | すること |
|---|---|---|
| 語あり | ラベルの全体が本文に出てくる | 何もしない（意味が合うかは読み上げで見る） |
| 語あり（語ごと） | 語に分けると全部が本文に出てくる（言い回しだけが違う） | 本文と同じ言い回しに直せるなら直す |
| 一部の語 | 語の六割以上が本文に出てくる。足りない語が並ぶ | 足りない語を本文に書く。ラベルから外すのは、その語が誤りだと読んだときだけ |
| なし | 本文に語が見つからない | 本文に説明を書き足すか、「（補足）」を付けて断る。図から消すのは、その語が誤りだと読んだときだけ |

問いへの答えの語（流れ図の通過の語「でない」「した」「用いない」、木の枝の「ある」「ない」）は、仮名と問いの語だけの短い語として、漢字の部分だけを本文で探す（答えの語は本文にそのまま出てこないのが普通だから）。ラベルの「|」は手で入れた改行で、行ごとに照合するが、ラベル全体が本文にあれば行の切れ目に左右されず「語あり」とする。

ほかに、次の指摘が出る。

| 番号 | 中身 | 重さ |
|---|---|---|
| T01 | 図の数字・条文番号が本文にない（「388条」「3か月」） | 必ず直す |
| T02 | 本文に「図N」への参照がない、または図題より後ろにしか出てこない | 必ず直す |
| T03 | 図の番号が、本文で昇順に出てこない | 必ず直す |
| T04 | 図の言い切り（勝つ・負ける・成立する・できない・及ぶ・及ばない 等）が、本文では逆の形でしか出てこない | 候補。人が読んで決める |
| T05 | 本文で対になっている限定語（「数人による」「善意の」「設定時の」等）が、図のラベルで落ちている | 候補。人が読んで決める |
| T06 | 関係の組合せが本文と逆・取り違え：矢印の向きが本文の文と逆／勝ち負け・成否の語が、本文では別の当事者・別の類型について書かれている／効果の語（「減軽する」など）が、本文では別の類型のもの | 必ず直す（error） |
| T07 | 関係の組合せが本文にない：矢印の両端と述語、または「誰について」と「どうなる」を、合わせて述べる段落がない | 必ず直す（error）。本文に書くか、図から外す |
| T08 | 機械で決められない関係の一覧（要読み比べ） | 人が、一本ずつ声に出して本文と読み比べる（3節） |

`--strict` を付けると、退けていない「なし」・T01・T06・T07 が一つでもあれば終了コード 1（要確認）になる。終了コード 0 は「所見なし（機械で見られる範囲で）」であって、納品してよいという意味ではない。

図ごとのまとめの行と、毎回出る二つの一覧：

| 出力 | 意味 |
|---|---|
| 所見なし（機械で見られる範囲で）／要確認（所見 n 件） | 機械の所見の有無。合否ではない |
| 関係ごとの状態 | 所見なし／逆の疑い（T06）／組合せなし（T07）／要読み比べ（T08）／照合できず |
| 照合できなかった要素 | 要読み比べ・照合できずの関係の一覧（`--quiet` では件数、`--out` の `unchecked_elements` に全部）。止め線、語が本文にない段、隣の文にしか条文がない要素など |
| 機械で見ない種類 | 型ごとに、機械が見ない（見ても止まらない）誤りの種類（要件と効果の取り違え、本文にある別の条文、範囲の枠の余分な要素、小枝の帰属、時間軸の帯、止め線、包含図のすり替え、木の兄弟の入替え など） |

### 語の照合と、関係の照合

語の照合（語あり・語あり（語ごと）・一部の語・なし）は、ラベルの語が本文のどこかにあるかを見るだけである。語が全部本文にあっても、勝ち負けを入れ替えた図、対抗の矢印を逆にした図、教唆犯の欄に幇助犯の効果を書いた図は「追跡率 100%」になる。**追跡率は、正確さの保証ではない。**

関係の照合（T06〜T08）は、仕様（JSON）から「誰について・誰から誰へ・どうなる」の組を取り出し、本文の同じ文・同じ段落で、その組合せが述べられているかを見る。

| 型 | 取り出す関係 | 読み方 |
|---|---|---|
| 当事者関係図・連鎖図 | 矢印（`edges`・`links`・`relations`） | 「〔元〕が〔先〕に〔線の横の語〕」。`relations` は `head` の側が先 |
| 同上 | 箱の二行目（`sub`） | 「〔箱の名前〕は〔二行目〕」。二行目がその者の言い換え（「債務者の全ての債権者」）なら、関係でなく別名として使う |
| 同上 | 範囲の枠（`groups`） | 枠の語（「判決の効力が及ぶ」）を述べる本文の文で名前が挙がる者と、枠の中の者が同じか |
| 比較図 | 列×段のセル。列を割ったとき（`split`）は、割った見出し×段のセル。セルの例外（`except`）も | 「〔列〕では、〔段〕は〔セル〕」。条文・例外を持つセルは「段の帰属」（別の段の話題として書かれていないか）も見る |
| 流れ図 | 段→出口、出口→二行目、段→二行目、終点→二行目、**段＋枝の語→行き先**（出口・次の段・小枝） | 「〔段〕に〔枝の語〕なら〔行き先〕」 |
| 木 | 節→二行目、**問い＋枝の語→子**（葉なら結論） | 「〔問い〕に〔枝の語〕なら〔子〕」 |
| 座標図 | **軸の値の組→セルの名前**、セルの名前→各行 | 「〔横軸の値〕で〔縦軸の値〕なら〔セル〕」 |
| スイムレーン | 段→帯（主体）、**段の順**、段→条文 | 「〔帯〕が〔段〕をする」。受け身の段（「…を受ける」）は帯の照合をしない |
| 時間軸 | 出来事の順（逆なら T08）、**帯→始まり・終わりの出来事** | 「〔出来事〕から〔出来事〕まで〔帯〕」 |
| 数直線 | **区間→両端の目盛り** | 同上 |
| マトリクス・包含図・価値配分 | 行→セル、**外の概念⊃内の概念**（逆に書いた文があれば T06）、持ち手→部分 | — |
| 積み上げ図・審級・条文の構造図・動きの図 | 段→効果、裁判所→結論、部分→効果、項目→理由 | 同上 |
| すべての型 | **条文番号→その要素の語**（矢印の `sub`、箱・セル・段の「（N条）」） | 本文でその条文番号を挙げる文が、その要素の述語を述べているか。述べず、その述語を述べる文が別の条文を挙げていれば T06 |

判定のしかた：

- 「誰について」は、その語が本文で出た位置で決める。同じ文の手前にある名前（主題の助詞「は・が・では・との関係では」の付いたものを優先）→同じ節の後ろの名前（「被告になるのは受益者であり」）→前の文からの持ち越し、の順。「甲にも乙にも」「教唆犯・幇助犯は」「債務者及び…」は並列として両方に数える。
- 肯定・否定は、語の直後（「対抗でき**ない**」）と、その語を含む節の終わり（「変更は許され**ない**」）で見る。義務の「…でなければならない」は否定に数えない。名詞として出ているだけの語（「違憲かどうか」）は、肯定とも否定とも数えない。名詞＋動詞の組（「違法性を阻却する」）は、本文の同じ節で動詞の形が図と同じかを見る。
- 矢印は三段で見る。①「〔元〕は…〔先〕に（対し）、〔述語〕」の形の文（受け身の述語の文は除く）。②相手の名前と述語が同じ文に出るのに、述語の形がいつも逆なら「肯定・否定が逆」。③述語を本文で言う主語（は・が・も の付いた名前）が〔先〕だけなら「向きが逆の疑い」。〔元〕が主語なら、相手を確かめられないので T08。
- 矢印の語が端点の名前に含まれていても（「監査役」の「監査」）、照合から外さない。外すのは、端点・ほかの箱・見出しの名前と**同じ**語だけ。語が残らない矢印は T08 に回す（黙って外さない）。
- 枝の語・軸の値で、本文の各文を最もよく合う枝に割り当て、その文が行き先を述べるかを見る。問いを述べる文（「前か後か、である」「…かどうか」）は割り当てない。行き先が次の問いなら、次の文まで見る。
- 段の見出しが否定（「及ばないもの」「成立しない場合」）の段は、セルの肯定・否定を見出しに掛かるものとして、帰属だけを見る。条文番号だけの二行目（木の根の「709条」）は、帰属ではなく条文の照合で見る。
- どの相手にも共通の語（三列とも「本人が責任を負う」）は、取り違えの判定に使わない。木・流れ図の行き先も、兄弟の行き先と共通の語（「身分」「者」）ではなく、兄弟にない語（「通常の刑」「共犯」）で決める。根拠の文が兄弟の枝の条件も同じ文で述べているときは、どちらの枝の行き先か区別できないので「要読み比べ」にする。
- 連体修飾：「国又は公共団体の公権力の行使に当たる公務員が」の「公権力の行使」は、後ろの「公務員」を修飾する語で、手前の「国」の属性ではない（語のすぐ後ろが、助詞「は・が・も」や読点を挟まずに名前へつながるときは、その名前について言われているとする）。
- 受け身の本文（「差押命令は…送達される」）では、文の主語は行為者ではないので、帯・当事者への帰属に数えない（図の語自体が受け身なら数える）。
- 前の文の主語の持ち越しは弱い帰属として扱う。文に別の主題（「裁判長は」「当事者は」）があるのに当事者・帯の名前を持ち越したときは、自分への帰属には数えるが、取り違え（T06）の根拠にはしない。
- 条件つきの否定（「軽過失にとどまるときは、国は公務員に求償できない」）は例外の場面なので、矢印の原則（「国は公務員に求償権を有する」）と逆とはいわない。
- 条文番号は、同じ文の述語と照らす。同じ文になく、同じ段落の隣の文（自分の条文を挙げていない文）が述語を述べるときは T06 にせず「要読み比べ」にする（条文番号を次の文の末尾にまとめて書く本文があるため）。例示（「例：収賄罪」）は条文の内容ではないので、条文と照らさない。
- 問いへの答えの語の向き：「ある／ない」「でない／である」「した／しない」は、答えの語の形をそのまま事実の形とする（問い「…でないか」に「でない」なら否定）。「はい／いいえ」だけは問いの形に掛ける。中身のない答えの語は、問いの中身の語を半分以上含む文でなければ、その条件の文と数えない。
- 止め線（`stop`）は照合しない（「照合できず」として一覧に載る）。点検役が「〔元〕は〔先〕に〔語〕できない」と読み上げる。

機械が決めなかった関係は、結果の行に「要読み比べ（T08）」「照合できず」の数で出て、「照合できなかった要素」に一つずつ並ぶ。その全部を人が読む。機械の「所見なし」は、機械が読めた範囲で食い違いが見つからなかった、という意味でしかない。

### 機械が止められない誤り（独立採点 第4回の実測）

新しい種類の注入誤り38件のうち、`trace.py --strict` が止めたのは18件（47%）だった。次の種類は**検出0**で、木では誤りでも所見が出ないことがある。これらは必ず人が読む（出力の「機械で見ない種類」に毎回出る）。検出率を上げるために、採点で使った誤りに合わせて規則を足すことはしない（前回の誤りに合わせると、新しい誤りでは半分しか止まらないことが分かった）。

| 種類 | 例 |
|---|---|
| 要件と効果の取り違え | 流れ図の第1段と終点の入替え、枝の語（要件）と葉（効果）の入替え |
| 範囲の枠に余分な要素 | 判決の効力の枠に、本文が「及ばない」とする者を加える |
| 段の中の小枝の帰属 | 小枝を別の段へ移す |
| 時間軸の帯・出来事 | 帯の「前／後」の語の入替え、否定語の脱落 |
| 一つの段落が複数の枝を述べる木 | 兄弟の葉を入れ替えても所見が出ない |
| 本文にある別の条文・別の項 | 423条2項→3項（本文にある別の項）、155条1項→145条5項 |
| 止め線の除去・包含図のすり替え | 公務員への直接請求の止め線を外す、取締役の内側を業務執行取締役等にすり替える |

したがって、`trace.py` の所見なしを正確さの根拠として報告しない。点検者の読み上げ（`reviewer-prompts/figure-check.md`。全部の関係を一本ずつ）は省略できない工程である。

### 所見を退ける（偽陽性への対処）

`--strict` の所見が正しい図に出ることがある。第4回の採点では、正しい図9枚のうち5枚に偽陽性が出て、採点者は `--strict` を通すために国賠の図から「公権力の行使に当たる」（国家賠償法1条1項の要件そのもの）を外し、共犯と身分の図から業務上横領の枝の条件を落とした。どちらも図の正確さを下げた。第5回で照合の規則を直し（上の判定のしかた）、その9枚では偽陽性が0になったが、新しい本文では再び出うる。

**所見を消すために、要件の語・限定語・条文番号を図や本文から削ってはならない。** 次の順で扱う。

1. 所見の指す本文の文と図の要素を、読み上げの表の一行として並べて読む。
2. 図が誤りなら図を直す。本文の説明が足りない（図の語が本文にない）なら、本文に書き足す。
3. 所見が誤りだと読んだら、図も本文も変えずに、退ける表に一行書き、`--dismiss` を付けて回し直す。

```
| 記号 | 場所（所見の「←」の後ろか、ラベルの一部） | 理由 |
|---|---|---|
| T06 | nodes「公務員」の二行目 | 「公権力の行使に当たる公務員」は本文1段落の主語の連体修飾。国の属性ではない。1条1項の要件なので外さない |
| なし | 設定時 | 本文1段落の「抵当権を設定し」の時点。本文に「設定時」の語を足した |
```

- 理由が空の行は退けない（出力に「理由が書かれていない」と出る）。退けた所見は「［退けた：理由］」として出力に残り、`--out` の `dismissed` に入る。
- 退ける表は作業ファイルに置き、点検役が理由を読んで同意したかを記録する（`../reviewer-prompts/figure-check.md` 4）。
- 退けてよいのは、図と本文を読み比べて、図が本文どおりだと言える所見だけ。分からないときは退けず、要確認のまま点検役に回す。

**機械が原理的に見ないもの**（人が読む。`reviewer-prompts/figure-check.md` の読み上げの表）：同じ語を使った時点の前後の入替え（「基準時の後に生じた事由は主張できない」）、段の見出しの意味とセルの中身の食い違い（「争えない」の段に「及ばない」を置く）、本文自体の誤り、図にしか出てこない含意（線の太さ・位置が示す優劣）。

### 関係の表（`--relations`）

本文が、矢印の向きを一文で言い切っていないとき（設例の事実が散らばっているとき）は、本文を読んで先に関係の表を作り、図と突き合わせる。表は、図の仕様を見ずに、本文だけから作る。

```
| 主語 | 相手 | 述語 | 根拠 |
|---|---|---|---|
| 第二譲受人 | 第一譲受人 | 所有権を対抗できる | 177条 |
| 債権者 | 受益者 | 取消しと財産の返還を請求する | 424条の6第1項 |
| 本人との関係（無権代理型） | — | 真偽不明のとき原告が負ける | |
```

- 主語＝誰が（どの場面で）。相手＝誰に（なければ「—」）。述語＝何をする・どうなる（言い切りの形）。根拠＝条文・判例（任意）。
- 一行は、「主語は、相手に対し、述語（根拠）。」という一文として、本文と同じ重みで照合に使われる。
- 表と逆向きの矢印、表と逆の言い切りは T06 になる。JSON（`[{"主語":…,"相手":…,"述語":…,"根拠":…}]`）でも渡せる。

## 3　人の照合：読み上げの表（省略できない）

照合の中心は、機械ではなくこの読み上げである。図を作った本人ではない点検役が、`../reviewer-prompts/figure-check.md` の手順で、図の矢印・枠・枝・時点・小枝・止め線を一つずつ文にし、本文の該当する文と並べた表を作る。機械の所見（T06〜T08、照合できなかった要素）は、その表のどの行を先に読むかの手がかりにすぎない。表の行の立て方の要点は次のとおり。

| 順 | 見るもの | 問い |
|---|---|---|
| 1 | 矢印 | 一本ずつ「〔元〕が〔先〕に〔線の横の語〕」と声に出して読み、同じ文が本文にあるか。n 本あれば n 行。`trace.py` が所見・照合できなかった要素に挙げた矢印から先に読むが、所見のない矢印も全部読む |
| 1' | セル・出口 | 比較図は「〔列〕では〔段〕は〔セル〕」、流れ図は「〔段〕に当たらないと〔出口〕、〔出口〕は〔効果〕」と読み、同じ文が本文にあるか |
| 2 | 言い切り | 「勝つ・負ける」「成立する・しない」「できる・できない」「及ぶ・及ばない」の向きが、本文と同じか |
| 3 | 限定語 | 本文の「数人による」「善意の」「同一の」「〜に限り」が、図に残っているか |
| 4 | 条文番号・数字 | 条・項・号、年数、金額、日付が、本文と同じか。本文の側も原文で確かめてあるか |
| 5 | 強調 | えんじの位置が、図題の「強調は…」の言うとおりか。本文の争点と同じか |
| 6 | 時点・順序 | 左右・上下の順が、本文の時の順・判断の順と同じか |
| 7 | 落としたもの | 本文にあって図にない事情が、メッセージを変えないか（変えるなら注に書く）。特に、要件の語（「公権力の行使に当たる」「職務を行うについて」）が図から消えていないか |
| 8 | 機械で見ない種類 | 要件と効果、範囲の枠の中と外、小枝の帰属（〔段〕のうち〔小枝の語〕なら〔小枝の箱〕）、包含（〔外〕は〔内〕を含む）、時間軸の帯（〔時点〕から〔時点〕まで〔帯の語〕）、止め線、条文番号を挙げる本文の文がその要素の述語を述べているか |

## 4　仕様に根拠を持たせる

仕様の各ラベルが本文のどの文に当たるかを、作業ファイルに一行ずつ書いておくと、後の直しが速い。図の仕様そのものには入れず、ノートの作業ファイル（目録）に置く。

```
図3 chain-nijujoto
  nodes[1].sub 「先に契約したが、登記がない」 ← 本文 2.1 第2段落「第一譲受人は先に契約したが、登記を備えていない」
  relations[0].label 「対抗できる（177条）」   ← 本文 2.1 第3段落、条文は原文で確認済み
  notes[0] 背信的悪意者                         ← 本文 2.2。資料 p.14
```

## 5　一つの事案に複数の図があるとき

- 同じ人は、どの図でも同じ語・同じ位置にする（図1で左にいた売主は、図2でも左）。
- 同じ関係は、同じ線種にする（図1で破線だった対抗関係は、図2でも破線）。
- 強調の意味は、図ごとに変わってよいが、図題で毎回言う。
- 図の番号は、本文に出てくる順（T03）。

## 6　図を直したら本文も見る、本文を直したら図も見る

図と本文は一組である。片方だけを直すと食い違う。

| 直した所 | 見直す所 |
|---|---|
| 本文の結論・言い切り | その節の図の言い切り、図題のメッセージ |
| 本文の用語（言い換え） | 図のラベル、図題、注 |
| 条文番号・数字 | 図のラベル、注 |
| 図の型を変えた | 本文の「図N で確かめる」の文、図題の読み方 |
| 図を足した・消した | 図の番号の振り直し、本文の参照 |

直したら `trace.py` をもう一度回し、読み上げの表のその行を読み直す。

## 7　スライドに移すとき

ノートの図をスライドに移すときも、語を変えない。スライドの見出し・図・話す原稿の三つで同じ語を使う（`../slides/06-speech-sync.md`、`../slides/07-from-note.md`）。段ごとに出す図では、段の番号と原稿の番号を合わせる。

## 8　合格の目安

| 項目 | 目安 |
|---|---|
| 「語あり」＋「語あり（語ごと）」の割合 | 九割以上 |
| 「なし」 | 0（本文に書き足したか、「（補足）」と断ったか、理由つきで退けた） |
| T01・T02・T03 | 0 |
| T04・T05 | 人が読んで、全部に「問題なし」か「直した」が付いている |
| T06・T07 | 0（直したか、理由つきで退けた。退けた理由に点検役が同意している） |
| T08・照合できなかった要素 | 挙がった全部について、読み上げが済んでいる |
| 機械で見ない種類 | 出力に挙がった種類の全部を、読み上げの表で見た |
| 削った語 | 所見を消すために削った要件の語・限定語・条文番号が 0 |
| 本文と図の順 | 本文（図が示す関係の段落）が、図の仕様より先に書かれている |
| 読み上げの表 | 全部の矢印・枠・枝・時点・小枝・止め線について済んでいる（`trace.py` の所見の有無にかかわらず） |
