# 09　してはいけない図（41 例）

図の失敗を、原因ごとに並べる。それぞれ「どう見えるか」「なぜ悪いか」「直し方」「どこで止まるか（機械・人）」を書く。図を作る前に一度通読し、作った後に `checklists/04-figures.md` と合わせて見る。

「どこで止まるか」の欄の E・W は `scripts/fig_lint.py`、T は `scripts/figgen/trace.py`、「人」は点検役（`../reviewer-prompts/figure-check.md`）と採点表（`10-quality-rubric.md`）。

## 作る前に自分に問う五つ

1. この図で分かることを、主語と述語のある一文で言えるか（言えなければ 11〜14）。
2. その一文は、読み手がつまずく所についてか（そうでなければ 14）。
3. 型は、内容の形に合っているか（合っていなければ 18〜23）。
4. 図の語は、本文の語か（そうでなければ 2・3・26）。
5. 条文・判例・数字は、原文で確かめたか（そうでなければ 4・5・10）。

## 作った後に必ず見る六つ

1. 矢印を一本ずつ読み上げたか（1・7・8・33・34）。
2. 言い切りの向きを本文と照合したか（2）。
3. `fig_lint.py` の error は 0 か（24・25・29・31・32）。
4. `trace.py` の所見（「なし」と T01・T06・T07）を全部読み、直すか理由つきで退けたか。所見を消すために語を削っていないか（3・10・33・34・37・39）。
5. PNG を 150mm 幅で見たか（25・27・28・30・35・36・41）。
6. 読み上げの表を、所見の有無にかかわらず全部作ったか（40）。
