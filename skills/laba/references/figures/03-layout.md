# 03　配置

図の中で、どこに何を置くかの決まり。エンジン（`scripts/figgen`）が自動で配置するが、仕様（JSON）の書き方で結果が変わる所（当事者の位置、列の数、段の順）は人が決める。ここではその判断の基準を示す。

## 1　版面と単位

| 項目 | 値 | 説明 |
|---|---|---|
| 図の幅 | 1040 単位＝150mm | A4 の本文の幅いっぱい。1 単位は約 0.144mm（約 0.41pt） |
| 余白 | 四辺 30 単位 | 文字は端から 20 単位以内に入れない（E05） |
| 並の字 | 21 単位（約 8.6pt） | 箱の中、線の横、注 |
| 見出しの字 | 24 単位（約 9.8pt） | 列の題、区画の題 |
| 細い線 | 0.9 単位 | 箱、矢印、罫 |
| 太い線 | 2.5 単位 | 強調、主役の帯 |
| 箱の内側の余白 | 14 単位 | 文字と枠の間 |
| 高さ | 内容で決まる | 目安は 300〜800 単位（43〜115mm）。900 を超えたら分ける |

PNG は、幅 150mm・600dpi（横 3543 画素）で書き出す。Word に貼るときは幅 150mm のまま貼り、縮めない。

## 2　格子で考える

図は、見えない格子の上に置く。列の幅、段の高さ、すき間をそろえると、整って見え、読み順も迷わない。

- 同じ種類の箱は、同じ幅にする。
- 列と列のすき間、段と段のすき間は、図の中で一定にする。
- 箱の中心を、列の中心・段の中心に合わせる。
- 矢印は、箱の辺の中央から出て、相手の箱の辺の中央に入る。同じ二者の間に複数あるときだけ、平行にずらす。

## 3　当事者の置き方（当事者関係図）

仕様では `pos: [列, 行]` で格子の位置を決める。次の決まりで置くと、矢印が重ならず、読み順が自然になる。

| 決まり | 理由 |
|---|---|
| 請求する人を左、請求される人を右 | 読み始めが左だから |
| 主役の二者を同じ行に置き、横の矢印で結ぶ | 主な関係が一直線で読める |
| 三人目は、行を変えて、二者の間の列に置く | 三角形になり、三つの関係がどれも重ならない |
| 四人目以降は、関係の深い人の近くに置く | 矢印が短くなり、交差が減る |
| 同じ側の人（共同原告、連帯債務者）は縦に並べる | 「同じ立場」が見て分かる |
| 斜めの位置の二者の真下・真横に、別の箱を置かない（置くなら、線が回り道になることを見込む） | 線は、つないでいない箱を通れない。エンジンが迂回させるが、線が長くなる |
| 同じ段に並ぶ箱は、高さをそろえる（エンジンがそろえる） | 段がそろって見える |
| 一つの箱の同じ辺から、三本以上の線を出さない | 出る位置が詰まり、読めなくなる |

置き方の型：

```
二者          三者（三角）        三者（一列）         四者（菱形）
[甲]→[乙]     [甲]────→[乙]       [甲]→[乙]→[丙]           [乙]
                 ＼    ／                               ／    ＼
                  [丙]                              [甲]────→[丁]
                                                       ＼    ／
                                                        [丙]
```

線の折れ方は、エンジンが決める（7節）。菱形の配置のように、折れ方を自分でそろえたいときだけ `elbow` を書く（甲から上下の二者へは `elbow: 'vh'`、上下の二者から丁へは `elbow: 'hv'`。例：`specs/parties-tasu-tanpo.json`）。

## 4　列の数

| 列の数 | 一列の幅 | 入る字数（並の字） | 向く内容 |
|---|---|---|---|
| 2 | 約 410 単位 | 一行 18 字前後 | 二つの型の比較。文で書ける |
| 3 | 約 260 単位 | 一行 11 字前後 | 三つの類型の比較。句で書く |
| 4 | 約 190 単位 | 一行 7 字前後 | 語だけ。マトリクス、審級 |
| 5 以上 | — | — | 図にしない。表にするか、分ける |

列の中をさらに二つに割る（比較図の `split`）と、一つの部分の幅は約 170 単位、入る字数は一行 8 字前後になる。語で書ける内容だけを入れる。

### 箱の幅と、一行に入る字数

一行に入る和文の字数は「（箱の幅 − 28）÷ 21」（切り捨て）。28 は左右の余白、21 は並の字の大きさ。

| 箱の幅 | 150 | 180 | 200 | 230 | 250 | 430（流れ図の段） | 520 |
|---|---|---|---|---|---|---|---|
| 一行の字数 | 5 | 7 | 8 | 9 | 10 | 19 | 23 |

線の横の語は、線の長さから 18 を引いた幅に入る分だけ（横の矢印の場合。当事者関係図で箱の幅 230・三列なら約 4 字、二列なら約 11 字）。

入らないときは、次の順で手当てする。

1. 語を減らす。条文番号は `sub`（二行目）か注へ回す。
2. 箱を広げる。当事者関係図は、`nodeWidth` を書かなければ、語の途中で折れない最小の幅をエンジンが選ぶ（上限は、線の横の語が入る幅を残した所まで）。
3. 見出しの字を下げる。比較図の列の見出しは、三行以上に折れるとき 24 から 21 の太字に下がる。並の字（21）は下げない（字の大きさは二種類まで）。
4. それでも入らなければ、図を分ける。

## 5　段の数と順

- 段（行）は六つまで。それより多いと、どこが分かれ目か見えなくなる。
- 段の順は、判断の順にする。前提（誰が・何を）→分かれ目（証明責任・基準時・要件）→帰結。
- 矢印でつなぐ段と、つながない段を分ける。前提を並べる段は矢印でつながず詰めて置き、判断が進む段だけ矢印でつなぐ（比較図の `arrow: false`）。

## 6　中央に寄せ、片側を空けない

- 主な列を図の中央に置く。流れ図の主な列と出口の列は、合わせた幅を中央に寄せる。
- 右側（または左側）に、何もない縦の帯ができたら、配置をやり直す。機械は左右・上下の要素の量が四倍以上違うと警告する（W03）。
- 背の高い空の箱（出口の箱を、入ってくる矢印の範囲いっぱいに伸ばしたもの）は作らない。線を一本に集めて、小さな箱に落とす。出口の箱の高さは、中の字の高さ＋余白にし、二行目に帰結を一行で述べる（`exit.sub`）。
- 流れ図で出口を一本に集めると、右の列の上が空く。枝の下に、その段で落ちる例・理由を一行で置く（`exit.eg`）。左右の要素の量の比は 3：1 以内を目安にする。
- 段ごとに出口の箱を置く流れ図では、出口の箱が段の箱より高くならないよう、エンジンが段の箱の高さを合わせる。
- 並んだ列の下端はそろえる（W04）。そろわないときは、短い列の箱の高さを合わせるか、段を組み替える。

## 7　線の通し方

- 線は水平か垂直。斜めの線は引かない（直角に折る）。
- 線は、つないでいない箱の中を通らない（E11）。別の線と同じ筋に重ならない（E12）。文字を横切らない（E07）。
- 経路はエンジンが決める。二つの箱の位置から、直線・L 字（縦に出て横から入る／横に出て縦から入る）・Z 字（段の間・列の間で折る）・迂回（間に箱があるとき外を回る）の候補を作り、接続点を辺の中央と左右 0.3 の三か所に振り分けて、次の順に悪いものを捨てる：①端点でない箱を貫通する、②別の線と同じ筋に重なる、③文字を通る、④接続点が別の線の接続点と近い、⑤別の線のすぐ脇を長く並走する、⑥交差する、⑦折れが多い、⑧長い。同じ行・同じ列の組を先に決め、斜めの組を後から通す。
- どの候補でも貫通・重なりが残るとき、エンジンは warn を出す（「線が箱「…」を貫通する」）。そのときは `pos` を入れ替えるか、関係を二枚の図に分ける。warn を残したまま出さない。
- 形を自分で決めたいときだけ、`elbow`（`vh`／`hv`）、`port`（出る位置を辺の上でずらす。-1〜1）、`straight` を書く。書いた形で貫通・重なりが出れば、やはり warn が出る。
- 線どうしの交差は、できるだけ無くす。当事者の位置を入れ替えると消えることが多い。残るときは、交差は直角にし、一つの図で一か所まで。
- 線の横の語は、線の最も長い区間の上（横線）か右（縦線）に置く。空いていなければ、下・左、両端寄せ、上寄り・下寄りの順に試し、それでも駄目なら折り幅を狭めて試す。置き場がないとエンジンが警告するので、段のすき間（`rowGap`）を広げるか、語を短くする。当事者関係図は、`rowGap` を書かなければ、語が入る間隔（112・150・190）をエンジンが選ぶ。
- 一段目の横の矢印の上に二行の語を置くときは、エンジンが図全体を下げて場所を作る。
- 矢印の先は、箱の辺から 6 単位手前で止める（矢じりが枠に重ならない）。

## 10　機械が見る配置の項目

| 符号 | 内容 | 直し方 |
|---|---|---|
| E05 | 文字が端から 20 単位以内 | 語を短くする。列を減らす |
| E06 | 文字どうしが重なる | 段のすき間を広げる。語を短くする |
| E07 | 文字を線が横切る | 当事者の位置を変える。`elbow`・`port` で線を逃がす |
| E10 | 矢印の先・元が何にも届いていない | `from`・`to` を確かめる |
| E11 | 線が、つないでいない箱を貫通する | `pos` を入れ替える。関係を二枚に分ける |
| E12 | 線が別の線と同じ筋に重なる（同じ元から分かれる幹・同じ先への合流は除く） | `pos` を入れ替える。`elbow`・`port` |
| W03 | 空白が片寄る | 列の順・位置を組み直す |
| W04 | 列の下端がそろわない | 段を組み替える |
| W05 | 空白率が 90% 超、または詰めすぎ（線図は 50% 未満、表の形の図＝比較・マトリクス・条文の構造・積み上げ・座標・価値配分・審級は 38% 未満） | 要素を足す・減らす |
| W09 | 文字と枠が近い | 語を短くする。`nodeWidth` を広げる |
| W11 | 箱の中の語が四行以上 | 語を減らす。箱を広げる |
| W12 | 線の横の語が三行以上 | 条文番号を注へ。線を長くする |
| W13 | 語の途中で折れている疑い | `|` で折る位置を決める。語を減らす |

W05 を型で分けたのは、表の形の図（列を並べて読む図）が、線図より詰まって見えても読めるからである。比較図の三列は空白率が 40% 前後になるが、読みにくくはない（刷って確かめた範囲）。

## 11　折り返しの規則

折り返しはエンジンが決める。行数を最小にしたうえで、行の長さをそろえ、下の表の罰点の合計が小さくなる位置で折る。語の途中でしか折れないときは、一行増やす。

### 切ってよい位置の優先順

| 順 | 位置 | 例 |
|---|---|---|
| 1 | 読点・句点・閉じ括弧・中黒・斜線・コロンの後 | 「取消し、／返還」「424条1項・／424条の6第1項」 |
| 2 | 開き括弧の前 | 「職務の執行を監査／（381条1項）」 |
| 3 | 助詞（は・が・を・に・で・と・の・へ・も・や）の後で、次が漢字・カタカナ・数字 | 「財産の／返還」 |
| 4 | 「について」「として」「に対して」など機能語の後 | 「受益者に対して／請求する」 |
| 5 | 条・項・号・頁・日で終わる語の後で、次が漢字か「ただし書」 | 「9条1項／かっこ書」 |
| 6 | 熟語と熟語の間 | 「損害賠償／請求権」 |
| 最後 | ひらがなの語の途中、送り仮名の前、短い括弧の中 | 使うと warn（「語の途中で折れた」） |

### 切らない所（禁則）

| 対象 | 例 |
|---|---|
| 条文番号 | 「民法424条の2」「203条1項」「424条の6第1項」（法令名と数字の間でも切らない） |
| 判例の表記 | 「最判昭和43・3・8」「民集22巻3号551頁」 |
| 数字と単位 | 「24時間以内」「3か月」「2週間」 |
| 熟語 | 辞書の語（「不動産」「被相続人」「賃貸借」など）と、「二字＋接尾」（「債権者」「所有権」「会計士」「監査人」） |
| 送り仮名つきの語 | 「買い受け」「取消し」「差押え」「申立て」 |
| カタカナの語 | 九字まで |
| 括弧 | 開き括弧の直後、閉じ括弧の直前。中身が 12 字以内の括弧の途中 |
| 行頭 | 句読点、閉じ括弧、中黒、長音、小書きの仮名 |

### 法律語の辞書と、漢字の連なりの一般則（第5回）

漢字が続く所（「非業務執行取締役等」「株主総会」「共同正犯」）は、二字ずつ機械的に区切ると語の途中で折れる。エンジン（`core.js`）と lint（W13）は、同じ辞書 `scripts/figgen/lib/legal-words.json` で、漢字の連なりの切れ目が安全かを決める。

| 切れ目 | 判定 | 例 |
|---|---|---|
| 辞書の術語の途中で、両側がそれぞれ術語か「二字＋接尾」 | 安全 | 「債権者／代位権」「損害賠償／請求権」 |
| 辞書の術語の途中で、片側が四字以上の術語、他方が単独の二字語 | 安全 | 「株主総会／決議」 |
| 辞書の術語の途中で、上のどちらでもない | 安全でない（warn・W13） | 「共同／正犯」「株主／総会」「代表／取締役」「業務上横／領」 |
| 術語に掛からない連なりで、片側が分かる語（術語・二字＋接尾・単独の二字語） | 安全 | 「所有権／移転登記」「司法／警察員」 |
| 術語に掛からない連なりで、両側とも分からない語（辞書にない語の一般則） | 安全でない（warn・W13） | 「非業務執／行取締役等」 |
| 漢字と送り仮名の間 | 安全でない（W13） | 「損害を生／じさせる」 |
| 判例の日付の中黒の後 | 安全でない（W13） | 「大判昭和4・／12・16」 |

- 辞書は `python3 -B scripts/figgen/tools/build_words.py` が作る（手で書き換えない）。分野別の手書きの術語（民法・会社法・民訴・刑法・刑訴・行政法・憲法・労働知財倒産・共通）と、`references/fields/*.md` から機械的に集めた語（漢字四〜六字の連なりで二回以上出るもの）、単独で語になる二字の語（同じく三回以上）。足りない術語は、`build_words.py` の分野別の表に足して作り直す。
- 安全でない切れ目は、罰点 14（使えば warn）になり、ほかに切れ目があればそちらが選ばれる。warn が出たら、語の切れ目に `|` を置くか、箱を広げるか、長い術語を注に回す。

辞書に無い語が途中で折れたら、仕様で `|` を入れて折る位置を決める。`|` はその位置で必ず折る。

注（`notes`）は、版面の幅いっぱいで折る（行をそろえず、前の行から詰める）。
