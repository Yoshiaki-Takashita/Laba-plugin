# 11　学説の対立地図

二つか三つの学説が、どの問いで分かれ、どの問いでは一致するかを、同じ段で見比べさせる。

- レンダラ：`compare`（`scripts/figgen/lib/renderers/compare.js`）。この型は専用のレンダラを持たず、上のレンダラの使い方で作る
- 用例：`scripts/figgen/specs/compare-gakusetsu.json`

## いつ使うか

- 学説の名前より「結論がどこで分かれるか」を示したいとき
- 対立の軸を二つまでに絞れるとき
- 判例の立場を学説の中に位置づけたいとき（判例の列を一つ足す）

## 使わないとき

- 学説が四つ以上（表にする。二つの軸で整理できるなら座標図）
- 資料が学説の中身を示していないとき（名前だけ並べない）
- 指導者自身の学説を、原文を確かめずに入れること（入れない）

## 要素

- 列＝学説。列の見出しに学説の名前
- 段＝問い（「違法性の本質」「故意の位置づけ」）。上から、前提→分かれ目
- 矢印なし（`arrows:false`）。学説の中に進行はないため
- えんじ＝二つの立場が最もはっきり分かれる段。注＝一致する点

## 作り方

1. 対立の軸を一つか二つに絞る
2. `columns` に学説、`rows` に問いを書く
3. 分かれる段に `accent:[0,1]`
4. 同じ内容は同じ言い回しにする
5. 注に、どの立場でも一致する点を書く（対立を大きく見せすぎない）

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 学説の名前と提唱者を並べただけで、何が違うか分からない | 問いごとに答えを並べる |
| 全部の段を強調した | 最も分かれる一段だけ |
| 資料にない学説を足した | 資料の範囲にとどめる。補うなら「（補足）」と出所 |
| 確度を変えた（「有力説」を「通説」と書いた） | 資料の語のまま書く |

## 最小の仕様

`compare` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"compare","message":"…。","caption":"図N　…",
 "columns":[{"title":"善意の場合"},{"title":"悪意の場合"}],
 "rows":[{"label":"要件","cells":["知らなかった","知っていた"]},{"label":"帰結","cells":["保護される","保護されない"],"accent":[1]}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| 列を左右に割りたい（被告ごと） | そのセルを `{"split":["本人","代理人"]}` にする。最初に割った段が、その列の小見出しになる |
| 矢印を消したい | 全部なら `arrows:false`、その段の上だけなら `rows[].arrow:false` |
| 強調は何列まで | 違いが出る段を一つ。その段の列は全部強調してよい（一段＝一点） |
| 三列にしたら詰まって見える | 一行 11 字前後に収める。空白率の目安は、表の形の図では 38% 以上 |
| 結論の段を目立たせたい | `rows[].under:true`（下辺を太く） |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "compare",
  "message": "違法性の本質を結果に見るか行為にも見るかで、主観的な事情を違法性の判断に入れるかどうかが分かれる。",
  "caption": "図N　この図で分かること：違法性の本質について、結果無価値論は法益の侵害・危険だけを見るのに対し、行為無価値論（二元論）は行為の態様や行為者の意思も見るので、故意などの主観的な事情の位置づけが分かれる。同じ段を左右で見比べる。強調は、二つの立場が最もはっきり分かれる段。",
  "arrows": false,
  "columns": [
    {"title": "結果無価値論"},
    {"title": "行為無価値論（二元論）"}
  ],
  "rows": [
    {"label": "違法性の本質", "cells": ["法益の侵害またはその危険", "法益の侵害・危険に加えて、行為が社会的な相当性を欠くこと"]},
    {"label": "刑法の役割", "cells": ["法益を保護する", "法益の保護に加えて、行為の規範を示す"]},
    {"label": "故意の位置づけ", "cells": ["原則として責任の要素", "違法性の要素でもある"], "accent": [0, 1]}
  ],
  "notes": ["どちらの立場も、法益の侵害・危険がまったくない行為を処罰しない点では一致する。試験では、立場の名前より、結論がどこで分かれるかを設例で示す。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/compare-gakusetsu.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/compare-gakusetsu.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/compare-gakusetsu.json
python3 scripts/figgen/trace.py scripts/figgen/specs/compare-gakusetsu.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 刑法：結果無価値論と行為無価値論、因果関係の諸説、共犯の処罰根拠
- 民法：物権変動の時期、債権者代位権の転用、表見代理の重畳適用
- 憲法：違憲審査基準論と比例原則、私人間効力（直接・間接）
- 民訴：訴訟物論（旧訴訟物理論・新訴訟物理論）、既判力の根拠
- 行政法：処分性の判断枠組み、裁量の統制
