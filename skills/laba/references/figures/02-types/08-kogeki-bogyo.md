# 08　請求・抗弁・再抗弁の積み上げ図

原告と被告の主張が、請求原因→抗弁→再抗弁と階段のように積み上がる様子を、左右に振り分けて描く。

- レンダラ：`stack`（`scripts/figgen/lib/renderers/stack.js`）
- 用例：`scripts/figgen/specs/stack-kashikin.json`

## いつ使うか

- 設例を攻撃防御の順に検討するとき（`../../yoken-jijitsu.md`）
- 「否認」と「抗弁」の違い、抗弁と再抗弁の関係を示したいとき
- 一つの請求に対して抗弁が一筋あり、再抗弁まで進む事案

## 使わないとき

- 抗弁が三筋以上並ぶ事案（表にして、筋ごとに行を分ける）
- 訴訟要件の検討（流れ図を使う。訴訟要件は請求原因ではない）
- 刑事の犯罪の成否（流れ図で構成要件→違法性→責任）

## 要素

- 左の列＝請求する側が主張立証すること。右の列＝相手方が主張立証すること
- 箱＝一つの段。一行目に段の名前（「抗弁：消滅時効」）、次に要件となる事実（番号つき）、最後に「⇒」で効果
- 矢印＝前の段を受けて次の段へ。横に「認めたうえで」「これに対して」
- えんじ＝その設例で結論を決める段

## 作り方

1. `left.title`・`right.title` に「原告（貸主）が主張立証する」のように書く
2. `levels` を上から順に。`side` で左右、`name` に段の名前、`items` に事実、`effect` に効果、`against` に矢印の語
3. 結論を決める段に `accent`
4. 注に、否認と抗弁の違いなど、取り違えやすい点を一つ書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 請求原因の事実を争うこと（否認）を、抗弁の段に入れた | 否認は段を作らない。注に書く |
| 訴訟要件を請求原因の箱に入れた | 別の図（流れ図）にする |
| 再抗弁を右の列に置いた | 再抗弁は請求する側の主張なので左 |
| 資料にない段を作った | 資料にある段だけにする。補うなら「（補足）」 |

## 最小の仕様

`stack` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"stack","message":"…。","caption":"図N　…","left":{"title":"原告"},"right":{"title":"被告"},
 "levels":[{"side":"left","name":"請求原因","items":["金銭の交付","返還の合意"]},{"side":"right","name":"抗弁","items":["弁済"],"against":"請求原因に対して","accent":true}]}
```

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "stack",
  "message": "貸金返還請求では、原告が権利の発生を、被告が消滅を、原告がその消滅を妨げる事実を、順に主張立証する。",
  "caption": "図N　この図で分かること：貸金返還請求の攻撃防御は、請求原因・抗弁・再抗弁の順に積み上がり、最後に立証された段で勝敗が決まる。上から下へ、左右を行き来しながら読む。強調はこの設例で決め手になる再抗弁。",
  "left": {"title": "原告（貸主）が主張立証する"},
  "right": {"title": "被告（借主）が主張立証する"},
  "levels": [
    {"side": "left", "name": "請求原因", "items": ["① 金銭の返還の合意", "② 金銭の交付", "③ 弁済期の合意とその到来"], "effect": "貸金返還請求権が発生する"},
    {"side": "right", "name": "抗弁：消滅時効", "items": ["① 時効期間の経過", "② 時効を援用する意思表示"], "effect": "請求権が消滅する", "against": "認めたうえで"},
    {"side": "left", "name": "再抗弁：時効の更新", "items": ["時効完成前に、被告が債務を承認した（民法152条1項）"], "effect": "時効は完成していない", "against": "これに対して", "accent": true}
  ],
  "notes": ["請求原因の事実を被告が争うのは「否認」であり、抗弁ではない。抗弁は、請求原因の事実を前提にして、別の事実で効果を覆す主張である。"]
}
```

## 分野別の用例

- 民法：貸金返還請求（弁済・消滅時効・時効の更新）、所有権に基づく返還請求（占有権原・解除）、売買代金請求（同時履行・解除）
- 民訴：主張立証責任の分配の説明
- 会社法：任務懈怠責任の追及（請求原因と、帰責事由がないことの抗弁）
- 行政法：処分の適法性を基礎づける事実と、それを争う側の主張（主張立証の分担に争いがある旨を注に）
