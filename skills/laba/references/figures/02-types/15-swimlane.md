# 15　手続のスイムレーン

手続を「誰が」「どの順に」行うかで並べる。横の帯が主体、左から右へ時間が進む。

- レンダラ：`swimlane`（`scripts/figgen/lib/renderers/swimlane.js`）
- 用例：`scripts/figgen/specs/swimlane-taiho.json`

## いつ使うか

- 複数の主体が順番に関わる手続（逮捕から勾留、訴えの提起から判決）
- 「この段階で誰が判断するのか」を取り違えやすい手続
- 期間の制限が主体ごとにある手続（帯の中に「48時間以内」）

## 使わないとき

- 主体が一人の手続（流れ図）
- 枝分かれが多い手続（流れ図か決定木）
- 七段を超える手続（主な段に絞るか、二枚に分ける）。七段でも、二行目が長い段が多いと箱の語が四行になる。二行目は 10 字前後までにし（独立採点で、12〜20 字の二行目は箱が四〜五行になり語が折れた）、条文番号以外の説明は注へ

## 要素

- 横の帯＝主体（警察・検察官・裁判官／原告・裁判所・被告）
- 箱＝行為。行う主体の帯に置く。二行目に期間・条文
- 矢印＝次の行為へ。帯をまたぐときは、前の箱の真下（真上）から縦に下ろして、次の箱に横から入る。そのぶん前の箱と横に重ねて置けるので、七段まで版面の幅に入る（段の幅は中身から決まる。短い段は狭く、長い段は広く）
- 帯の見出しは `|` で折る位置を決められる（「会社|（監査役が代表）」）。`via`（矢印の語）は、帯をまたぐ矢印では前の箱の真下の余白に、同じ帯の矢印では線の上に置く（帯の境界にかからない）
- えんじ＝その手続の要になる判断（裁判官の判断など）

## 作り方

1. `lanes` に主体を上から
2. `steps` に行為を順に。`lane` に帯の番号（0 から）
3. 期間や条文は `sub` に書く
4. 要の判断に `accent`
5. 注に、通算の期間の制限など、帯をまたぐ規律を書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 行為を違う主体の帯に置いた | 条文の主語で確かめる（「検察官は」「裁判官は」） |
| 期間を記憶で書いた | 条文で確かめる |
| 例外の手続（緊急逮捕など）を同じ図に入れて流れが二本になった | 原則の流れだけを描き、例外は本文か別の図 |

## 最小の仕様

`swimlane` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"swimlane","message":"…。","caption":"図N　…","lanes":["原告","裁判所"],
 "steps":[{"lane":0,"text":"訴えの提起"},{"lane":1,"text":"訴状の審査","accent":true}]}
```

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "swimlane",
  "message": "逮捕された被疑者の身体拘束は、警察・検察官・裁判官が時間の制限の中で順に判断して続けられる。",
  "caption": "図N　この図で分かること：逮捕から勾留までは、警察が48時間以内に送致し、検察官が24時間以内に勾留を請求し、裁判官が勾留の当否を判断する（刑訴法203条・205条・207条）。左から右へ時間が進む。強調は裁判官による判断。",
  "lanes": ["警察", "検察官", "裁判官"],
  "steps": [
    {"lane": 0, "text": "逮捕"},
    {"lane": 0, "text": "検察官に送致", "sub": "48時間以内"},
    {"lane": 1, "text": "勾留を請求", "sub": "受け取ってから24時間以内"},
    {"lane": 2, "text": "勾留の裁判", "sub": "勾留質問のうえ判断", "accent": true}
  ],
  "notes": ["検察官の勾留請求は、逮捕の時から通算して72時間を超えることができない（205条2項）。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/swimlane-taiho.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/swimlane-taiho.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/swimlane-taiho.json
python3 scripts/figgen/trace.py scripts/figgen/specs/swimlane-taiho.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 刑訴：逮捕・勾留、起訴から公判、令状の請求と発付
- 民訴：訴えの提起から第一回口頭弁論、送達、上訴の手続
- 行政法：申請に対する処分の手続（行手法）、不利益処分の聴聞、審査請求
- 会社法：株主総会の招集から決議、組織再編の手続
- 憲法：法律の制定手続、条約の承認
