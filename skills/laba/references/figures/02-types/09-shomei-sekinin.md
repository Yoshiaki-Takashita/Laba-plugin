# 09　主張立証責任の分配の図

同じ争点について、相手ごと・場面ごとに誰が証明責任を負うかを並べ、真偽不明のときの帰結の違いを見せる。

- レンダラ：`compare`（`scripts/figgen/lib/renderers/compare.js`）。この型は専用のレンダラを持たず、上のレンダラの使い方で作る
- 用例：`scripts/figgen/specs/compare-split-shomeisekinin.json`

## いつ使うか

- 証明責任が相手によって逆向きになる所（無権代理人の責任と本人への請求）
- 「真偽不明のとき、誰が負けるか」が結論を分ける所
- 法律上の推定・立証責任の転換が働く場面と働かない場面の比較

## 使わないとき

- 証明責任の所在に争いがなく、要件を並べるだけのとき（要件効果の木）
- 攻撃防御の順序を見せたいとき（積み上げ図）

## 要素

- 列＝比べる二つの型。列の中を、相手（被告）ごとに左右に割る（`split`）
- 段＝被告→請求→争点→証明責任→真偽不明のとき→帰結。上から下へ判断が進む
- 矢印＝段から段へ。割ったセルは、割ったまま下へつなぐ
- えんじ＝帰結が悪い方に分かれる段（「原告が負ける」が並ぶ側）

## 作り方

1. `columns` に二つの型の名前（「無権代理型（法律上併存しない）」）
2. `rows` に段を書く。相手ごとに分かれる段は `{"split":[…]}` にする
3. 違いが出るセルに `{"text":…,"accent":true}`
4. 同じ内容のセルは同じ言い回しにそろえる（「原告が負う」）
5. 注に、制度の対象になるのはどちらの型かを書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 「勝つ」「負ける」が本文と逆になった | 本文の言い切りと一語ずつ照合する（trace.py の T04） |
| 割り方が段ごとに違い、どの相手の話か追えない | 割り方を全部の段でそろえる |
| 一つのセルに二人分を「〜は原告、〜は被告」と書いて読めない | セルを割る |

## 最小の仕様

`compare` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"compare","message":"…。","caption":"図N　…",
 "columns":[{"title":"善意の場合"},{"title":"悪意の場合"}],
 "rows":[{"label":"要件","cells":["知らなかった","知っていた"]},{"label":"帰結","cells":["保護される","保護されない"],"accent":[1]}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| 列を左右に割りたい（被告ごと） | そのセルを `{"split":["本人","代理人"]}` にする。最初に割った段が、その列の小見出しになる |
| 矢印を消したい | 全部なら `arrows:false`、その段の上だけなら `rows[].arrow:false` |
| 強調は何列まで | 違いが出る段を一つ。その段の列は全部強調してよい（一段＝一点） |
| 三列にしたら詰まって見える | 一行 11 字前後に収める。空白率の目安は、表の形の図では 38% 以上 |
| 結論の段を目立たせたい | `rows[].under:true`（下辺を太く） |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "compare",
  "message": "証明責任が被告ごとに逆向きに置かれていれば原告はどちらかに勝てるが、どちらの被告との関係でも原告に置かれていれば両方に負けうる。",
  "caption": "図N　この図で分かること：二人の被告への請求が両立しないとき、争点の証明責任が被告ごとに逆向きなら原告はどちらかに勝てるが、どちらも原告にあると両方に負けうる。各列の中の左右が被告ごとの違い、上から下が判断の順。強調は、原告が両方に負ける原因（どちらの被告との関係でも原告が証明責任を負うこと）とその帰結。下辺の太い段が帰結。",
  "columns": [
    {"title": "無権代理型（法律上併存しない）"},
    {"title": "相手方不明型（事実上併存しない）"}
  ],
  "rows": [
    {"label": "被告", "cells": [{"split": ["本人", "代理人"]}, {"split": ["甲", "乙"]}]},
    {"label": "請求", "arrow": false, "cells": [{"split": ["契約の履行", "無権代理人の責任"]}, {"split": ["契約の履行", "契約の履行"]}]},
    {"label": "争点", "arrow": false, "cells": ["代理権があったか", "契約の相手方は甲か乙か"]},
    {"label": "証明責任", "cells": [{"split": ["原告が負う", "代理人が負う"]}, {"split": [{"text": "原告が負う", "accent": true}, {"text": "原告が負う", "accent": true}]}]},
    {"label": "真偽不明のとき", "cells": [{"split": ["原告が負ける", "原告が勝つ"]}, {"split": ["原告が負ける", "原告が負ける"]}]},
    {"label": "帰結", "cells": ["同じ手続で審理されれば、どちらかには勝てる", "同じ手続で審理されても、両方に負けることがある"], "accent": [1], "under": true}
  ],
  "notes": ["左の型でも、弁論が分離されて代理権の判断が食い違うと、原告は両方に負ける。これを防ぐのが同時審判の申出（民訴41条）で、対象は左の型に限られる。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/compare-split-shomeisekinin.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/compare-split-shomeisekinin.json out.svg --png

python3 scripts/figgen/trace.py scripts/figgen/specs/compare-split-shomeisekinin.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 民訴：同時審判の申出（41条）と証明責任、法律上の推定
- 民法：無権代理人の責任（117条）、使用者責任の免責、債務不履行の帰責事由
- 刑訴：検察官の挙証責任と、例外的に被告人が負担する場面
- 行政法：処分の適法性の主張立証
- 会社法：任務懈怠と帰責事由
