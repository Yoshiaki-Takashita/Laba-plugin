# 20　比較図

似た二つ（か三つ）の場面を左右に並べ、同じ問いを同じ高さに置いて、違いが出る段だけを強調する。

- レンダラ：`compare`（`scripts/figgen/lib/renderers/compare.js`）
- 用例：`scripts/figgen/specs/compare-kaisei.json`

## いつ使うか

- 似た制度・似た場面で帰結が分かれる所（改正前と改正後、原則と例外、二つの類型）
- 分かれ目が一つの事実・一つの要件にあるとき
- 読み手が二つを混同しやすい所

## 使わないとき

- 比べる対象が四つ以上（表か座標図）
- 違いが一つの語だけ（文で足りる）
- 段が六つを超える（詰まる。表にする）

## 要素

- 列＝比べる場面。見出しは大きい字
- 段＝問い。左端に段の名前。上から「前提→分かれ目→帰結」
- 矢印＝判断が上から下へ進むときだけ（`arrows`）。項目を並べるだけなら矢印なし
- えんじ＝違いが出る段。列の間に細い灰色の線

## 見出しの帯と、セルの例外

- 列の見出しの下に、列の幅いっぱいの太い線を引く（見出しの帯。既定）。罫線の表と見分けるための線で、色は増やさない。やめるときは `header: "plain"`。
- ただし書・適用除外は、セルを `{"text": "…（13条1項）", "except": "公益上、緊急に処分をする必要があるときなどは適用しない（13条2項）"}` にすると、箱の下の点線より下に一行で出る。注に回さない。
- 比較図が章の図の半分を超えるなら、一枚を当事者関係図・流れ図・時間軸に描き直す（`../../algorithms/figure-type.md`「表の形を後回しにする」）。

## 作り方

1. 比べる対象を二つに絞る
2. `columns` に見出し、`rows` に段
3. 同じ内容は同じ言い回しにし、違いだけが目に入るようにする
4. 違いが出る段に `accent:[列番号]`
5. 注に、根拠条文や、比較から漏れた事情を書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 左右で段の順が違う | 同じ問いを同じ高さに置く |
| 全部の段に違いがあるように書いた | 同じ所は同じと書く。違いは一つか二つに絞る |
| 空白率が 50% を切った（詰めすぎ） | 語を減らすか、段を減らす。fig_lint の W05 |

## 最小の仕様

`compare` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"compare","message":"…。","caption":"図N　…",
 "columns":[{"title":"善意の場合"},{"title":"悪意の場合"}],
 "rows":[{"label":"要件","cells":["知らなかった","知っていた"]},{"label":"帰結","cells":["保護される","保護されない"],"accent":[1]}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| 列を左右に割りたい（被告ごと） | そのセルを `{"split":["本人","代理人"]}` にする。最初に割った段が、その列の小見出しになる |
| 矢印を消したい | 全部なら `arrows:false`、その段の上だけなら `rows[].arrow:false` |
| 強調は何列まで | 違いが出る段を一つ。その段の列は全部強調してよい（一段＝一点） |
| 三列にしたら詰まって見える | 一行 11 字前後に収める。空白率の目安は、表の形の図では 38% 以上 |
| 結論の段を目立たせたい | `rows[].under:true`（下辺を太く） |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "compare",
  "message": "債権の消滅時効は、平成29年の民法改正で、起算点が二つになり、職業別の短い時効と商事の時効がなくなった。",
  "caption": "図N　この図で分かること：債権の消滅時効は、平成29年の民法改正の前は「行使できる時から10年」が原則で職業別・商事の特則があったが、改正後は「知った時から5年」と「行使できる時から10年」の二本立てに統一された。同じ段を左右で見比べる。強調は、改正で新しく加わった主観的な起算点。",
  "arrows": false,
  "columns": [
    {"title": "改正前"},
    {"title": "改正後（現行）"}
  ],
  "rows": [
    {"label": "原則", "cells": ["権利を行使することができる時から10年", "権利を行使することができることを知った時から5年、または行使することができる時から10年"], "accent": [1]},
    {"label": "職業別の短期時効", "cells": ["あり（1年から3年）", "廃止"]},
    {"label": "商事の時効", "cells": ["5年（商法の特則）", "廃止（民法の原則による）"]}
  ],
  "notes": ["改正後の原則は民法166条1項。人の生命・身体の侵害による損害賠償請求権は、行使することができる時から20年に延びる（167条）。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/compare-kaisei.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/compare-kaisei.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/compare-kaisei.json
python3 scripts/figgen/trace.py scripts/figgen/specs/compare-kaisei.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 民法：改正前と改正後の規律、詐欺と強迫、無効と取消し、連帯債務と保証
- 刑法：共同正犯・教唆犯・幇助犯、正当防衛と緊急避難
- 民訴：通常共同訴訟と必要的共同訴訟、既判力と争点効
- 憲法：二つの審査基準、検閲と事前抑制
- 行政法：取消訴訟と無効等確認訴訟、行政指導と処分
- 会社法：公開会社と非公開会社、取締役会設置会社と非設置会社
