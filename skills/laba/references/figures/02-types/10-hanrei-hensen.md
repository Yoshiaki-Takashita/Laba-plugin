# 10　判例の変遷の図

ある論点について、判例の立場が時期によってどう移ったかを、時間軸とその下の「その時期の規律」の帯で見せる。

- レンダラ：`timeline`（`scripts/figgen/lib/renderers/timeline.js`）。この型は専用のレンダラを持たず、上のレンダラの使い方で作る
- 用例：`scripts/figgen/specs/timeline-hanrei-hensen.json`

## いつ使うか

- 判例変更があった論点
- 判例が段階を追って進んだ論点（充当を認め、次いで返還請求を認めた、など）
- 法改正の前後で判例の意味が変わる所（帯を「改正前」「改正後」にする）

## 使わないとき

- 判例が一つしかない論点
- 判例が「変わった」のか「事案が違うだけ」なのかを資料が示していないとき（変遷として描かない。判例マトリクスで事案の違いを並べる）

## 要素

- 軸の上＝判決（裁判所名と年月日）。軸の下＝その判決の結論
- 帯＝その時期に通用していた規律。古い時期は灰色、現在はえんじ
- 印（`mark`）＝「現在の立場」「判例変更」
- 注＝「変更する」と判決が自ら述べたのか、事案による使い分けなのか

## 作り方

1. 資料の判例を年月日の順に並べ、裁判所の公表資料で年月日と結論を確かめる
2. `events` に判決、`tracks` に規律の帯を書く
3. 現在の立場を決めた判決に `accent` と `mark`
4. 注に、判例変更の有無を、確かめた範囲で書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 事案が違うだけの二つの判例を「変更」と描いた | 判決文に「変更する」とあるかを確かめる。なければ「区別」として本文で説明する |
| 年月日を記憶で書いた | 書誌と要旨は、裁判所の公表資料で確かめてから書く。確かめられないものは図に入れない（用例は、裁判所ウェブサイトで確かめた二つの判決だけで作ってある） |
| 古い規律を黒、新しい規律も黒にして、どれが現在か分からない | 現在だけをえんじ、過去は灰色 |

## 最小の仕様

`timeline` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"timeline","message":"…。","caption":"図N　…",
 "events":[{"date":"契約時","label":"売買契約"},{"date":"引渡し時","label":"目的物の引渡し","accent":true}],
 "tracks":[{"name":"危険の負担","segments":[{"from":0,"to":1,"label":"売主が負う"},{"from":1,"label":"買主が負う","accent":true}]}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| `from`・`to` に何を書くか | `events` の番号（0 始まり）。`to` を省くと右端まで |
| 間が長く空く所を示したい | `breaks:[i]`＝ i 番目と i+1 番目の間に省略の印 |
| 基準時から下へ線を下ろしたい | 強調・印（`mark`）つきの出来事からは自動。ほかは `guide:true`。やめるなら `guides:false` |
| 「ない」状態の帯 | `dash:true` か `gray:true`。太い実線で描くと warn |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "timeline",
  "message": "利息制限法の制限を超えて任意に支払った利息について、判例は、まず残存元本への充当を認め、次いで元本とともに支払った場合の返還請求を認めた。",
  "caption": "図N　この図で分かること：利息制限法の制限を超えて任意に支払った利息・損害金について、判例は、残存元本への充当を認めたうえで、元本とともに支払った場合には制限に従った元利合計額を超える分の返還請求も認めた。左から右へ時間が進み、下の帯がその判決以後の規律を示す。強調は返還請求を認めた判決。",
  "events": [
    {"date": "最大判昭和39・11・18", "label": "制限を超える部分は残存元本に充当される"},
    {"date": "最判昭和44・11・25", "label": "元本とともに支払った場合、超過額の返還を請求できる", "accent": true, "mark": "返還請求を認めた"}
  ],
  "tracks": [
    {"name": "債務者の救済", "segments": [{"from": 0, "to": 1, "label": "元本が残っていれば、元本に充当"}, {"from": 1, "label": "元利合計額を超える支払額は、返還を請求できる", "accent": true}]}
  ],
  "notes": ["書誌は、民集18巻9号1868頁（昭和39年の大法廷判決）、民集23巻11号2137頁（昭和44年の第三小法廷判決）。昭和44年の判決は、支払に当たり充当について特段の意思表示がないことを前提とする。この二つの前後の判決は省いた（補足）。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/timeline-hanrei-hensen.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/timeline-hanrei-hensen.json out.svg --png

python3 scripts/figgen/trace.py scripts/figgen/specs/timeline-hanrei-hensen.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 憲法：尊属殺、議員定数、非嫡出子の相続分など、大法廷で判断が変わった論点
- 民法：利息制限法をめぐる判例の展開、有責配偶者の離婚請求
- 刑法：共謀共同正犯の成立範囲
- 民訴：一部請求と残部請求
- 行政法：処分性・原告適格の判断の広がり
