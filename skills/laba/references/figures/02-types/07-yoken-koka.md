# 07　要件効果の木

一つの法律効果を上に置き、それを支える要件を下に並べる。要件がすべてそろって効果が生じることを形で見せる。

- レンダラ：`tree`（`scripts/figgen/lib/renderers/tree.js`）。この型は専用のレンダラを持たず、上のレンダラの使い方で作る
- 用例：`scripts/figgen/specs/tree-yoken.json`

## いつ使うか

- 要件が三つから五つあり、どれが争点になりやすいかを示したいとき
- 要件の下にさらに下位の要件（解釈で加わる要件）がある条文
- 答案の骨組み（要件を順に検討する）を見せたいとき

## 使わないとき

- 要件が二つ以下（文で足りる）
- 要件ごとに「誰が証明するか」が分かれる所が主題のとき（積み上げ図か、主張立証責任の分配の図）
- 要件の間に順序・枝分かれがあるとき（流れ図か決定木）

## 要素

- 上の箱＝効果と根拠条文
- 下の箱＝要件。一行目に要件の名前（太字にしない。葉は並字）、二行目に中身
- 線＝矢じりなし（`noHeads:true`）。「支える」関係で、向きのある進行ではないため
- えんじ＝実際に争いが集まる要件。注＝主張立証の分担

## 作り方

1. `direction:"down"`、`noHeads:true`
2. `root.text` に効果、`sub` に条文
3. `children` に要件を、条文の順か検討の順で並べる
4. 争点になりやすい要件に `accent`（二つまで）
5. 注に、どちらが主張立証するかを書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 要件の一つを落とした | 条文を原文で確かめ、数を数える（`../../statute-verification.md`） |
| 条文にない解釈上の要件を、条文の要件と同じ見た目で並べた | 解釈上の要件は破線の箱（`dash`）にするか、注に回す |
| 矢印を付けて「要件が効果に変わる」ように見えた | 矢じりを付けない |

## 最小の仕様

`tree` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"tree","message":"…。","caption":"図N　…",
 "root":{"text":"実行に着手したか","children":[{"edge":"した","text":"未遂か既遂","accent":true},{"edge":"しない","text":"予備にとどまる"}]}}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| 向き | `direction:"right"`（既定。決定木）・`"down"`（要件効果の木・組織図）。枝の語が四字を超えるなら `down` |
| 矢じりを消したい | `noHeads:true`（要件効果の木・組織図） |
| 葉の下辺が太いのは | 結論の印。やめるなら `leafUnder:false` |
| 兄弟の箱の間を広げたい | `gapY`（`right` のとき） |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "tree",
  "direction": "down",
  "noHeads": true,
  "message": "不法行為による損害賠償請求権は、四つの要件がそろって初めて発生し、争いは多くの場合、過失と因果関係に集まる。",
  "caption": "図N　この図で分かること：不法行為による損害賠償請求権（民法709条）は、権利・利益の侵害、故意・過失、損害、因果関係の四つがそろって発生する。上の効果を、下の要件がすべて支える。強調は、実際の事件で争いが集まりやすい要件。",
  "root": {"text": "損害賠償請求権が発生する", "sub": "民法709条", "children": [{"text": "権利・利益の侵害", "sub": "他人の権利または法律上保護される利益を侵害した"}, {"text": "故意・過失", "sub": "結果を予見でき、|回避する義務に違反した", "accent": true}, {"text": "損害の発生", "sub": "財産的な損害と精神的な損害"}, {"text": "因果関係", "sub": "加害行為によってその損害が生じた", "accent": true}]},
  "notes": ["四つの要件は、原則として請求する側（被害者）が主張立証する。責任能力がないこと、正当防衛に当たることなどは、請求される側が主張立証する。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/tree-yoken.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/tree-yoken.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/tree-yoken.json
python3 scripts/figgen/trace.py scripts/figgen/specs/tree-yoken.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 民法：不法行為（709条）、債務不履行による損害賠償（415条）、表見代理（109条・110条・112条）、取得時効（162条）
- 刑法：構成要件の要素（主体・行為・結果・因果関係・故意）
- 行政法：取消訴訟の訴訟要件、国家賠償法1条の要件
- 会社法：取締役の対第三者責任（429条）の要件
- 民訴：既判力の作用する場面の要件
