# 21　判例マトリクス

多くの判例を、「誰が誰に」と「何を求めるか」の二つで仕分け、欄ごとに結論を置く。

- レンダラ：`matrix`（`scripts/figgen/lib/renderers/matrix.js`）
- 用例：`scripts/figgen/specs/matrix-kyoyu.json`

## いつ使うか

- 判例が五件以上あり、当事者の向きと請求の内容で結論が分かれる論点
- 資料が判例を列挙しているが、仕分けの基準が見えにくい所
- 類型ごとの要件・効果の一覧（意思表示の瑕疵と第三者保護など）

## 使わないとき

- 判例が四件以下（本文で足りる）
- 欄に判例の事案を書き込みたいとき（入らない。表にする）
- 判例を自分で確かめていないとき（欄に入れない）

## 要素

- 横罫だけの表の形。上端と下端は太い線、見出しの下は細い線
- 行の見出し＝訴えの向き・類型。列の見出し＝求める内容・観点
- 欄＝結論を一行、例を一行。判例の年月日は本文の表に書く
- えんじの枠＝主題の欄（全員が当事者になる必要がある場面など）

## 作り方

1. 資料の判例を一件ずつ、行と列に仕分ける（作業ファイルに一覧を作る）
2. `corner`・`cols`・`rows` を書く
3. 欄には結論と例だけ。書誌は入れない
4. 主題の欄に `accent`
5. 注に、仕分けは資料の判例を確かめたものに限ることを書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 確かめていない判例を欄に入れた | 入れない。空いた欄は「資料に判例なし」と書く |
| 判例の結論を逆の欄に入れた | 判決の結論を一件ずつ確かめる（`../../case-verification.md`） |
| 「同左」「—」で欄を埋めた | 同じ内容でも語で書く。該当なしは理由を書く |

## 最小の仕様

`matrix` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"matrix","message":"…。","caption":"図N　…","corner":"訴えの向き","cols":["持分権に基づく請求","共有関係についての請求"],
 "rows":[{"label":"第三者へ","cells":["単独でできる",{"lines":["全員が原告になる"],"accent":true}]}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| 行の見出しが折れる | `labelWidth` を広げる |
| セルに二行入れたい | `{"lines":["結論","例：…"],"accent":true}` |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "matrix",
  "message": "共有物をめぐる訴えは、誰が誰を訴えるか、何を求めるかによって、共有者全員が当事者になる必要があるかが分かれる。",
  "caption": "図N　この図で分かること：共有に関する訴えで全員が当事者になる必要があるかは、訴えの向きと求める内容で分かれる。行が訴えの向き、列が求める内容。強調は全員がそろう必要のある場面。各欄の根拠になる判例は、本文の表に示す。",
  "corner": "訴えの向き",
  "cols": ["各自の持分権に基づく請求", "共有関係そのものについての請求"],
  "rows": [
    {"label": "共有者から第三者へ", "cells": [{"lines": ["各共有者が単独でできる", "例：不実の登記の抹消を求める"]}, {"lines": ["共有者全員が原告になる", "例：共有権の確認を求める"], "accent": true}]},
    {"label": "共有者どうし", "cells": [{"lines": ["争っている当事者の間で足りる", "例：持分の確認を求める"]}, {"lines": ["共有者全員が当事者になる", "例：共有物の分割を求める"], "accent": true}]}
  ],
  "notes": ["全員が当事者になる必要があるか（固有必要的共同訴訟か）の整理は、判例の類型を二つの軸で単純にしたものである（補足）。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/matrix-kyoyu.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/matrix-kyoyu.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/matrix-kyoyu.json
python3 scripts/figgen/trace.py scripts/figgen/specs/matrix-kyoyu.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 民訴：共有・共同所有をめぐる訴えと固有必要的共同訴訟、確認の利益
- 民法：意思表示の瑕疵と第三者保護、94条2項の類推適用の類型、177条の「第三者」
- 憲法：表現の自由の規制類型と審査
- 行政法：処分性が認められた例・否定された例、原告適格
- 刑法：不作為犯の作為義務の発生根拠
