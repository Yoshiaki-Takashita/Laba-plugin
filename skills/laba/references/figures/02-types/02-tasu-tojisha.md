# 02　三者間・多数当事者の関係図

四人以上の当事者や、同じ相手に向かう複数の関係を、線を重ねずに描く。

- レンダラ：`parties`（`scripts/figgen/lib/renderers/parties.js`）。この型は専用のレンダラを持たず、上のレンダラの使い方で作る
- 用例：`scripts/figgen/specs/parties-tasu-tanpo.json`

## いつ使うか

- 保証人と物上保証人、連帯債務者が複数いるなど、同じ立場の者が並ぶ事案
- 同じ二者の間に関係が二本以上ある（請求と求償、債権と担保）
- 三角の関係（債権譲渡、債務引受、第三者のためにする契約）

## 使わないとき

- 当事者が七人を超える（箱が小さくなり読めない。主役だけに絞るか、表にする）
- 線が五本を超えて交差が避けられない（二枚に分ける。複合図で上下に並べる）

## 要素

- 中央の横一列に主役の二者（債権者と主債務者）。上下の段に、それぞれと関係する者
- 同じ二者の間の矢印は、平行にずらして積む（エンジンが自動でずらす）
- 同じ立場の者は同じ高さ・同じ大きさにそろえる
- 箱の二行目に、その者の責任の範囲や立場の違いを書く（「全財産で責任を負う」「不動産だけで責任を負う」）

## 作り方

1. 主役の二者を中段の左右に置く
2. 同じ立場の者を、上段と下段に分けて中央の列に置く
3. 線は、つないでいない箱を通らない経路をエンジンが選ぶ。折れ方をそろえたいときだけ `elbow`（上段へは `vh`＝縦に出て横から入る、が多い）
4. 求償など「後から生じる関係」を強調し、もとの請求は黒のままにする
5. 注に、立場の違い（債務を負うか、責任だけか）を主語のある文で書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 線が、つないでいない箱の中を通った・別の線に重なった | エンジンが避ける。避けきれないと warn「線が箱「…」を貫通する」が出て、fig_lint は E11（貫通）・E12（重なり）で止める。`pos` を入れ替えるか、関係を二枚に分ける |
| 判決の効力が及ぶ者・同じ側の当事者を、言葉だけで説明した | 範囲の枠（`groups`）で囲み、枠に名前を付ける（用例：`parties-hanketsuko-hani`） |
| 同じ立場の二人を違う大きさの箱にした | `nodeWidth` を一つに決める |
| 三角の関係で、どの矢印が請求でどれが移転か分からない | 片方を破線にするか、線の横の語で区別し、図題に書く |

## 最小の仕様

`parties` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"parties","message":"…。","caption":"図N　この図で分かること：…。矢印は請求の向き。強調は…。",
 "nodes":[{"id":"x","label":"債権者"},{"id":"y","label":"債務者","pos":[1,0]}],
 "edges":[{"from":"x","to":"y","label":"貸金の返還を請求","accent":true}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| `pos` は何を書くか | `[列, 行]`。左上が `[0,0]`。省くと左から順に一列に並ぶ |
| `from`・`to` に何を書くか | `nodes` の `id`（`label` ではない）。請求する人・渡す人が `from` |
| 箱の幅を決めたい | `nodeWidth`。省くと、語の途中で折れない最小の幅になる |
| 線の横の語が入らない | 条文番号を `sub` に分ける。`rowGap` を広げる（省くと 112・150・190 から選ばれる） |
| 線の折れ方を変えたい | ふつうは任せる。`elbow:"vh"`／`"hv"`、`port`（-1〜1）、`straight` は、形を自分で決めたいときだけ |
| 人でないものを置きたい | `kind`：`thing`（物・書類）、`right`（権利）、`proc`（手続）、`organ`（会議体の機関）。`legend` も付ける |
| 範囲を示したい | `groups:[{members:[id…], label}]` |
| 手続上の行為（告知・通知）を権利と分けたい | `dash:"dot"`（点線の矢印） |
| 段ごとに出したい（スライド） | `edges[].step` に番号。`--steps` で段ごとの図 |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "parties",
  "message": "一つの貸金債権を、保証人と物上保証人がそれぞれ別の方法で担保し、弁済した者は主債務者に求償できる。",
  "caption": "図N　この図で分かること：一つの貸金債権について、保証人は自分の全財産で、物上保証人は差し出した不動産だけで責任を負い、どちらも弁済すれば主債務者に求償できる。実線の矢印は請求・権利行使の向き。強調は、担保した者から主債務者への求償。",
  "nodeWidth": 210,
  "rowGap": 44,
  "nodes": [
    {"id": "g", "label": "債権者", "sub": "貸主", "pos": [0, 1]},
    {"id": "h", "label": "保証人", "sub": "全財産で責任を負う", "pos": [1, 0]},
    {"id": "s", "label": "主債務者", "sub": "借主", "pos": [2, 1]},
    {"id": "b", "label": "物上保証人", "sub": "不動産だけで責任を負う", "pos": [1, 2]}
  ],
  "edges": [
    {"from": "g", "to": "s", "label": "貸金の返還を請求"},
    {"from": "g", "to": "h", "label": "保証債務の履行を請求", "elbow": "vh"},
    {"from": "g", "to": "b", "label": "抵当権を実行", "elbow": "vh"},
    {"from": "h", "to": "s", "label": "求償", "accent": true, "elbow": "hv"},
    {"from": "b", "to": "s", "label": "求償", "accent": true, "elbow": "hv"}
  ],
  "notes": ["保証人は債権者に対して債務を負うが、物上保証人は債務を負わず、不動産の価値の限度で責任を負うだけである。求償の根拠は、保証人は民法459条など、物上保証人は372条・351条。"]
}
```

## 分野別の用例

- 民法：保証人と物上保証人、連帯債務、債権譲渡（譲渡人・譲受人・債務者）、詐害行為取消し（債権者・債務者・受益者・転得者）
- 民訴：共同訴訟（原告と複数の被告）、独立当事者参加
- 会社法：親会社・子会社・債権者
- 行政法：行政庁・名宛人・第三者の三面関係
- 憲法：国家・私人・私人（私人間効力）
