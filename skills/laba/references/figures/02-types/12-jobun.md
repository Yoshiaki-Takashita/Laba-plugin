# 12　条文の構造図

一つの条文を、本文・ただし書・各号に分け、それぞれが定める場面と効果を左右に並べる。原則と例外の関係を形で見せる。

- レンダラ：`statute`（`scripts/figgen/lib/renderers/statute.js`）
- 用例：`scripts/figgen/specs/statute-415.json`

## いつ使うか

- 本文とただし書で主張立証の分担が分かれる条文
- 各号が並ぶ条文で、号ごとの場面と効果を見せたいとき
- 1項と2項が原則と例外の関係にある条文

## 使わないとき

- 一文で済む条文
- 条文を写すだけになるとき（写しは図にならない。場面と効果に分けられる条文に限る）
- 複数の条文にまたがる制度（要件効果の木か流れ図）

## 要素

- 左の箱＝区分（本文・ただし書・1項・2項・各号。太字）
- 中の箱＝その区分が定める場面（条文の言葉を縮めずに。左ぞろえ）
- 右の箱＝効果。矢印で結ぶ
- えんじ＝例外・免責など、取り違えやすい側。注＝主張立証の分担

## 作り方

1. 条文を法令の原文で確かめる（`../../statute-verification.md`）。限定の語（「同一の」「〜に限り」）を落とさない
2. `name` に「民法○条○項（見出し）」
3. `parts` に区分ごとの `kind`・`text`・`effect`
4. 例外の側に `accent`
5. 注に、どちらが主張立証するかを書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 条文を要約して限定の語を落とした | 原文と照合する。縮めるなら、落とした語がないかを一語ずつ見る |
| ただし書の効果を「無効」などと言い換えて意味が変わった | 条文の語のまま書く |
| 古い条文番号（改正前）を書いた | 現行の条文で確かめる。改正前を示すなら「改正前」と書く |

## 最小の仕様

`statute` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"statute","message":"…。","caption":"図N　…","name":"民法○条",
 "parts":[{"kind":"本文","text":"……のときは、……できる","effect":"原則"},{"kind":"ただし書","text":"……のときは、この限りでない","effect":"例外","accent":true}]}
```

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "statute",
  "name": "民法415条1項（債務不履行による損害賠償）",
  "message": "債務不履行があれば損害賠償を請求できるのが原則で、債務者の責めに帰することができない事由があるときだけ免責される。",
  "caption": "図N　この図で分かること：民法415条1項は、本文で損害賠償請求の原則を定め、ただし書で債務者の免責を定める。左が要件、右が効果。強調は例外であるただし書。",
  "parts": [
    {"kind": "本文", "text": "債務者が債務の本旨に従った履行をしないとき、又は債務の履行が不能であるとき", "effect": "債権者は損害賠償を請求できる"},
    {"kind": "ただし書", "text": "その債務の不履行が、契約その他の債務の発生原因及び取引上の社会通念に照らして債務者の責めに帰することができない事由によるものであるとき", "effect": "この限りでない（免責される）", "accent": true}
  ],
  "notes": ["ただし書の事由（免責事由）は、債務者が主張立証する。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/statute-415.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/statute-415.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/statute-415.json
python3 scripts/figgen/trace.py scripts/figgen/specs/statute-415.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 民法：415条1項、94条、96条、177条と例外、612条
- 民訴：41条（同時審判の申出）の各項、115条1項の各号
- 刑法：36条・37条（本文と過剰の場合）、43条（本文とただし書）
- 憲法：29条の各項の関係
- 行政法：行訴法9条1項・2項、行手法の適用除外
- 会社法：356条・365条（利益相反取引）、423条
