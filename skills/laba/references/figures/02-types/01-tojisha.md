# 01　当事者関係図

設例に出てくる人と、その間の請求・契約・権利を一枚で見せる。事案を読む前の地図になる。

- レンダラ：`parties`（`scripts/figgen/lib/renderers/parties.js`）
- 用例：`scripts/figgen/specs/parties-mukendairi.json`

## いつ使うか

- 当事者が三人以上いて、請求や契約が二本以上ある設例の冒頭
- 「誰が誰に何を求めているか」を取り違えやすい事案（代理、保証、債権譲渡、転貸）
- 争点になる関係が一つあり、それを強調して見せたいとき

## 使わないとき

- 二人・一つの契約だけの事案（文で足りる）
- 結論が分かれる理由を見せたいとき（当事者を並べても理由は見えない。比較図・流れ図・積み上げ図を使う）
- 一つのノートに三枚目の当事者関係図（二枚まで。`../../algorithms/figure-type.md`）

## 要素

- 箱＝当事者。一行目に立場の語（太字）、二行目に事案での役（「買主」「売主とされた者」）
- 実線の矢印＝請求・移転など向きのある関係。請求する人から請求される人へ
- 破線＝争いのある関係・まだ確定していない関係（「代理権を与えたか」）
- 線の横の語＝関係の名前と根拠の条文
- えんじ＝争点になる関係一本だけ

## 作り方

1. 当事者を数え、請求する側を左、請求される側を右に置く。三人目は下の段の中央
2. `nodes` に `pos:[列,行]` で位置を書く。列は左から 0、行は上から 0
3. `edges` に関係を一本ずつ書く。`from` は請求する人・渡す人
4. 争点の関係に `accent`、争いのある関係に `dash` を付ける
5. 経路はエンジンが決める。warn「線が箱を貫通する」「同じ筋に重なる」が出たら `pos` を入れ替える（折れ方を自分で決めたいときだけ `elbow`）
6. 人でないもの（物・書類・手続）を置くときは `kind` を付け、`legend` で形の意味を断る

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 矢印の元と先が逆で、請求の向きが本文と反対になった | 矢印を一本ずつ本文の文と突き合わせる。「AがBに請求する」なら from は A |
| 記号だけの箱（A・B・C）にした | 「買主」「本人」など立場の語を一行目に置く。記号を使うなら「買主 A」 |
| 関係を全部強調した | 争点の一本だけにする |
| 事案の紹介で終わり、何が問題かが見えない | 図題に争点を書き、難所は別の型の図で解く |

## 最小の仕様

`parties` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"parties","message":"…。","caption":"図N　この図で分かること：…。矢印は請求の向き。強調は…。",
 "nodes":[{"id":"x","label":"債権者"},{"id":"y","label":"債務者","pos":[1,0]}],
 "edges":[{"from":"x","to":"y","label":"貸金の返還を請求","accent":true}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| `pos` は何を書くか | `[列, 行]`。左上が `[0,0]`。省くと左から順に一列に並ぶ |
| `from`・`to` に何を書くか | `nodes` の `id`（`label` ではない）。請求する人・渡す人が `from` |
| 箱の幅を決めたい | `nodeWidth`。省くと、語の途中で折れない最小の幅になる |
| 線の横の語が入らない | 条文番号を `sub` に分ける。`rowGap` を広げる（省くと 112・150・190 から選ばれる） |
| 線の折れ方を変えたい | ふつうは任せる。`elbow:"vh"`／`"hv"`、`port`（-1〜1）、`straight` は、形を自分で決めたいときだけ |
| 人でないものを置きたい | `kind`：`thing`（物・書類）、`right`（権利）、`proc`（手続）、`organ`（会議体の機関）。`legend` も付ける |
| 範囲を示したい | `groups:[{members:[id…], label}]` |
| 手続上の行為（告知・通知）を権利と分けたい | `dash:"dot"`（点線の矢印） |
| 段ごとに出したい（スライド） | `edges[].step` に番号。`--steps` で段ごとの図 |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "parties",
  "message": "無権代理が疑われるとき、相手方は本人への履行請求と無権代理人への責任追及の二つを考える。",
  "caption": "図N　この図で分かること：相手方は、代理権があれば本人に、なければ無権代理人に請求できるので、二つの請求は両立しない関係にある。矢印は請求の向き（条文は民法）。強調は争いになる代理権の有無。",
  "nodes": [
    {"id": "x", "label": "相手方", "sub": "買主", "pos": [0, 0]},
    {"id": "y1", "label": "本人", "sub": "売主とされた者", "pos": [2, 0]},
    {"id": "y2", "label": "代理人と称した者", "pos": [1, 1]}
  ],
  "edges": [
    {"from": "x", "to": "y1", "label": "契約の履行を請求", "sub": "（代理権があるとき）"},
    {"from": "x", "to": "y2", "label": "無権代理人の責任を追及", "sub": "（117条1項）"},
    {"from": "y1", "to": "y2", "label": "代理権を与えたか", "accent": true, "dash": true, "head": "none"}
  ]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/parties-mukendairi.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/parties-mukendairi.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/parties-mukendairi.json
python3 scripts/figgen/trace.py scripts/figgen/specs/parties-mukendairi.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 民法：無権代理（相手方・本人・代理人と称した者）、転貸借（賃貸人・賃借人・転借人）
- 民訴：補助参加（原告・被告・参加人）、訴訟告知
- 会社法：代表訴訟（株主・会社・取締役）
- 刑訴：告訴・告発と捜査機関
- 行政法：処分の名宛人と第三者（周辺住民・競業者）
