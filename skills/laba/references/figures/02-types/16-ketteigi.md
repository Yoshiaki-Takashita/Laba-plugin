# 16　決定木

問いに「はい／いいえ」で答えていくと結論に行き着く場合分けを、左から右へ枝分かれする木で描く。

- レンダラ：`tree`（`scripts/figgen/lib/renderers/tree.js`）
- 用例：`scripts/figgen/specs/tree-misui.json`

## いつ使うか

- 結論が三つ以上に分かれる場合分け
- 問いの順序が決まっている判断（先の問いの答えで、次の問いが変わる）
- 条文の適用関係（どの条文が当てはまるか）

## 使わないとき

- 問いが一直線で、外れたら同じ出口に落ちるとき（流れ図。訴訟要件など）
- 二つの観点の組合せだけのとき（座標図）
- 深さが四段を超える（読めない。二つの木に分ける）

## 要素

- 太字の箱＝問い。並字の箱＝結論（葉）
- 枝＝答え。枝の上に「した」「しない」「はい」「いいえ」と語で書く
- えんじ＝取り違えやすい結論、または設例が行き着く結論
- 葉の二行目に効果と条文

## 作り方

1. `direction:"right"`
2. `root.text` に最初の問い。`children` に答えごとの枝を書き、`edge` に答え
3. 結論の葉には `children` を書かない
4. 設例が行き着く葉に `accent`
5. 注に、木に入らない前提（未遂を罰する規定があるか等）を書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 問いが名詞だけで、何を聞いているか分からない（「実行の着手」） | 問いの形にする（「実行に着手したか」） |
| 枝に答えの語がない | `edge` を必ず書く |
| 同じ結論の葉が何か所にも出てくる | 問いの順を入れ替えるか、流れ図にして出口を一つにまとめる |

## 最小の仕様

`tree` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"tree","message":"…。","caption":"図N　…",
 "root":{"text":"実行に着手したか","children":[{"edge":"した","text":"未遂か既遂","accent":true},{"edge":"しない","text":"予備にとどまる"}]}}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| 向き | `direction:"right"`（既定。決定木）・`"down"`（要件効果の木・組織図）。枝の語が四字を超えるなら `down` |
| 矢じりを消したい | `noHeads:true`（要件効果の木・組織図） |
| 葉の下辺が太いのは | 結論の印。やめるなら `leafUnder:false` |
| 兄弟の箱の間を広げたい | `gapY`（`right` のとき） |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "tree",
  "direction": "right",
  "message": "犯罪が既遂に至らなかったとき、実行の着手の有無と、やめた理由によって、扱いが四つに分かれる。",
  "caption": "図N　この図で分かること：既遂・障害未遂・中止未遂・予備は、実行の着手、結果の発生、自己の意思による中止の三つの問いで分かれる。左から右へ問いに答えて進む。強調は刑が必ず減軽又は免除される中止未遂（条文は刑法）。下辺の太い箱が結論。",
  "root": {"text": "実行に着手したか", "children": [{"edge": "した", "text": "結果が発生したか", "children": [{"edge": "した", "text": "既遂"}, {"edge": "しない", "text": "自己の意思でやめたか", "children": [{"edge": "はい", "text": "中止未遂", "sub": "刑を必ず減軽|又は免除", "accent": true}, {"edge": "いいえ", "text": "障害未遂", "sub": "刑を減軽できる"}]}]}, {"edge": "しない", "text": "予備にとどまる", "sub": "処罰する規定があるときだけ処罰"}]},
  "notes": ["中止未遂は刑法43条ただし書、障害未遂は43条本文による。未遂が処罰されるのは、各本条に未遂を罰する規定があるときに限られる（44条）。"]
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/tree-misui.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/tree-misui.json out.svg --png
python3 scripts/fig_lint.py out.svg --spec scripts/figgen/specs/tree-misui.json
python3 scripts/figgen/trace.py scripts/figgen/specs/tree-misui.json --body 本文.md --fig N --strict
```

## 分野別の用例

- 刑法：既遂・未遂・予備（43条）、正当防衛と過剰防衛、錯誤の処理
- 民法：意思表示の瑕疵の類型、無権代理の後の処理（追認・取消し・責任追及）、解除の可否
- 民訴：訴えの変更・反訴の可否、上訴の種類
- 行政法：取消訴訟・無効等確認訴訟・義務付け訴訟の選択
- 会社法：決議の瑕疵を争う訴えの選択（取消し・無効・不存在）
