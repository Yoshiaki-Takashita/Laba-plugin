# 05　対抗関係の図

同じ人から二人が権利を得たとき、どちらが優先するかを、移転の線と対抗の線を分けて描く。

- レンダラ：`chain`（`scripts/figgen/lib/renderers/chain.js`）。この型は専用のレンダラを持たず、上のレンダラの使い方で作る
- 用例：`scripts/figgen/specs/chain-nijujoto.json`

## いつ使うか

- 二重譲渡（不動産・債権）、差押えと譲渡の競合
- 「登記・通知を先に備えた方が優先する」という規律を見せたいとき
- 対抗要件を備えた者と備えていない者の関係

## 使わないとき

- 対抗要件の先後ではなく、善意・悪意で決まる関係（権利移転の連鎖か比較図）
- 三人以上が競合する場合（表にする）

## 要素

- 左にもとの権利者、右に上下二段で二人の譲受人
- 実線の矢印＝譲渡。番号で契約の順を示す（「① 売買」「② 売買と移転登記」）
- 縦の矢印＝対抗できる、という関係（移転ではない）。対抗できる人から対抗される人へ。確定した帰結は細い実線（`solid:true`）、まだ争いうる関係は破線（既定）
- えんじ＝優先する側の箱と、そこへの譲渡

## 作り方

1. `nodes` に売主と二人の譲受人。譲受人の二行目に「先に契約したが、登記がない」のように事情を書く
2. `links` に二本の譲渡。優先する側に `accent`
3. `relations` に対抗の関係を書く。「b が a に対抗できる」なら `head:"a"`（矢じりは a の側）。書いたら「〔元〕が〔先〕に対抗できる」と声に出して読み、本文と比べる
4. 注に、例外（背信的悪意者など）を主語のある文で書く

## よくある失敗

| 失敗 | 直し方 |
|---|---|
| 対抗の線を横の太い矢印にして、権利が譲受人の間で移ったように見えた | 対抗は `relations`（縦の細い線）で描き、移転（`links`）と見た目を分ける |
| 対抗の矢印の向きが逆（「第一譲受人が第二譲受人に対抗できる」） | `head` を確かめる。`trace.py` が本文の文と向きを照合する（T06） |
| 先に契約した方を上に置かず、契約の順が読めない | 上を先の契約、下を後の契約にし、番号を付ける |
| 例外を図の中に書き込んで主張が二つになった | 例外は注に回す。例外が主題なら別の図にする |

## 最小の仕様

`chain` で図になる最小の形。ここから項目を足す（全部の項目は `scripts/figgen/README.md` 5 節）。

```json
{"type":"chain","message":"…。","caption":"図N　…",
 "nodes":[{"id":"a","label":"売主"},{"id":"b","label":"買主"},{"id":"c","label":"転得者"}],
 "links":[{"from":"a","to":"b","label":"売買"},{"from":"b","to":"c","label":"転売","accent":true}]}
```

## 仕様を書くときに迷う所

| 迷う所 | 答え |
|---|---|
| `links` と `relations` の違い | `links`＝権利が移る（左から右へ並ぶ）。`relations`＝移転でない関係（対抗・優劣。縦の線） |
| `relations` の `head` | 矢じりの付く側。「b が a に対抗できる」なら `head:"a"`。`both`（既定）・`none` もある |
| 確定した帰結を破線で描きたくない | `solid:true` |
| 線の横の語が入らない | `rowGap`（上下の箱の間隔）・`nodeWidth` を調える。条文番号は `sub` へ |

## 仕様の例

そのまま `node cli.js` に渡せば生成できる（図題の「図N」は、ノートでの番号に置き換える）。

```json
{
  "type": "chain",
  "message": "同じ不動産が二重に譲渡されたとき、二人の譲受人の優劣は、契約の先後ではなく登記の先後で決まる。",
  "caption": "図N　この図で分かること：二重譲渡では、先に契約した第一譲受人でも登記がなければ、先に登記を備えた第二譲受人に所有権を対抗できない（民法177条）。左から右へ権利が移り、①②は契約の順を示す。縦の矢印は「第二譲受人が第一譲受人に対抗できる」向き、強調は優劣を決める登記とその帰結。",
  "nodes": [
    {"id": "a", "label": "売主", "sub": "もとの所有者"},
    {"id": "b", "label": "第一譲受人", "sub": "先に契約したが、|登記がない"},
    {"id": "c", "label": "第二譲受人", "sub": "後に契約したが、|先に登記を備えた", "accent": true}
  ],
  "links": [
    {"from": "a", "to": "b", "label": "① 売買"},
    {"from": "a", "to": "c", "label": "② 売買と移転登記", "accent": true}
  ],
  "relations": [
    {"a": "b", "b": "c", "head": "a", "label": "所有権を対抗できる", "sub": "（177条）", "accent": true, "solid": true}
  ],
  "notes": ["登記を先に備えた方が優先する。第二譲受人が背信的悪意者に当たるときは、第一譲受人は登記がなくても対抗できる（判例）。"],
  "nodeWidth": 250,
  "rowGap": 150
}
```

```
node scripts/figgen/cli.js check scripts/figgen/specs/chain-nijujoto.json      # 仕様の検証
node scripts/figgen/cli.js scripts/figgen/specs/chain-nijujoto.json out.svg --png

```

## 分野別の用例

- 民法：不動産の二重譲渡（177条）、債権の二重譲渡（467条2項）、動産の二重譲渡（178条）、賃借権と新所有者（605条・借地借家法）
- 民事執行：差押えと譲渡の先後
- 会社法：株式の二重譲渡と名義書換
- 知的財産：特許権の移転の登録
