# 04　文字と色

## 1　色は三つ

| 色 | 値 | 役割 | 使ってよい所 | 使ってはいけない所 |
|---|---|---|---|---|
| 黒 | #1A1A1A | 図の本体 | 文字すべて、箱の枠、矢印、軸 | — |
| 灰 | #8C9493 | 文脈・補助 | 区切りの罫、主役でない当事者の枠、不要・対象外を示す帯、注の上の罫 | 文字（読みにくい） |
| えんじ | #943522 | 強調 | 強調する箱の枠、強調する矢印、基準時の目盛り、主役の帯 | 文字、塗り、三か所を超える強調 |

地は白（#FFFFFF）。これ以外の色を使うと機械が止める（E01）。文字が黒でないと止める（E02）。

### なぜ三色か

- 色が増えると、読み手は色の意味を覚えなければならない。三色なら「黒が本体、灰が背景、えんじが大事な所」と一度で分かる。
- ノートは白黒で刷られることが多い。えんじは白黒で刷っても黒より少し薄く、太い線にしているので区別が付く。色だけに意味を持たせず、必ず太さか線種も変える。
- 色覚の違いがあっても読める。えんじと黒は明るさが近いので、強調は色と太さの両方で示す。

### 強調の決め方

強調は、次のどれか一つに使う。一つの図で二種類を混ぜない。

| 強調するもの | 例 |
|---|---|
| 争点 | 「代理権を与えたか」の線 |
| 分かれ目 | 二つの型で違いが出る段、基準時 |
| 変わった所 | 改正で新しく加わった規律、判例が変更した結論 |
| 決め手 | 攻撃防御で勝敗を決める再抗弁 |
| この段で新しく加わった関係 | 積み上げ式の図で、今の段の矢印 |

図題の最後に「強調は〜。」と書く。機械は、強調があるのに図題に「強調」の語がないと警告する（W08）。

## 2　文字

| 項目 | 決まり |
|---|---|
| 書体 | ゴシック一種類（Noto Sans CJK JP。無ければ Noto Sans JP、それも無ければ既定のゴシック） |
| 大きさ | 二種類だけ。並 21 単位（約 8.6pt）、見出し 24 単位（約 9.8pt） |
| 太さ | 並と太字。太字は箱の見出し語だけ |
| 色 | 黒だけ |
| 行間 | 文字の高さの 1.38 倍 |
| 字間 | 詰めない・空けない |
| 下線・斜体・囲み文字 | 使わない |

三種類目の大きさを使うと機械が止める（E03）。

### 本文との大きさの関係

図は幅 150mm で作る。そのとき図の中の字は約 8.6pt で、本文（10〜10.5pt）よりひと回り小さい。これより小さくなると読みにくい。図を縮めて貼ると字も縮むので、縮めない。図を小さく見せたいときは、図の高さを減らす（段を減らす、語を減らす）。

### 字数の目安

| 場所 | 一行の字数 | 行数 |
|---|---|---|
| 箱の見出し語 | 10 字まで | 1〜2 行 |
| 箱の添え語 | 16 字まで | 1〜2 行 |
| 線の横の語 | 12 字まで | 1〜2 行 |
| 列の題 | 16 字まで | 1 行 |
| 区画の題（複合図） | 22 字まで | 1 行 |
| 注 | 40 字前後で折り返す | 2 行まで×2 個 |

機械は、図の本体の一行が 18 字幅を超えると警告する（W06）。

## 3　言葉づかい

図の中の言葉は、本文の言葉づかい（`../style-imitation.md`）に合わせる。図だけ別の言い回しにしない。

| 決まり | よい例 | 悪い例 |
|---|---|---|
| 語で書く | 債務者、第一譲受人、原告が負う | A、X1、P↓ |
| 動詞で言い切る | 成立する、対抗できない、原告が負ける | 成立、対抗×、原告× |
| 本文と同じ語を使う | 本文が「買受人」なら図も「買受人」 | 図だけ「競落人」 |
| 条文は数字で | 民法177条、民訴41条 | 177、§177 |
| 記号で意味を表さない | 「当たる」「当たらない」 | ○、×、△ |
| 略さない | 法定地上権、同時審判の申出 | 法地、同時審判 |
| 限定語を落とさない | 設定時に建物がある | 建物がある |
| 補足には印 | 〜とする説明がある（補足） | 印なし |

○×△を使わない理由：何が○なのか（成立するのか、請求が通るのか、原告に有利なのか）が図によって変わり、読み手が取り違えるからである。

番号（①②）は、順序を示すときだけ、語に添えて使う（「① 売買」「② 売買と移転登記」）。番号だけで何かを指さない（「要件③」と書かず、要件の中身を書く）。

## 4　線の太さと種類

| 種類 | 太さ | 使い道 |
|---|---|---|
| 細い実線 | 0.9 | 箱、矢印、軸、ふつうの関係 |
| 太い実線 | 2.5 | 強調（えんじ）、主役の帯（黒） |
| 細い破線 | 0.9 | 争いのある関係、仮定、対抗関係 |
| 太い破線 | 2.5 | 強調した破線（争点そのもの） |
| 細い点線 | 0.9 | 補助、省略 |
| 灰の細い実線 | 0.9 | 区切り、文脈 |

太さは二種類だけ（E04）。線種は三つまで（W07）。

## 5　刷ったときの確かめ

- 白黒で刷っても、強調が太さで見分けられるか。
- 幅 150mm で刷って、一番小さい字が読めるか。
- 灰色の罫が消えていないか（薄い刷りでは消えることがある。消えても意味が通る図にしておく）。
- 破線と点線の区別が付くか。
