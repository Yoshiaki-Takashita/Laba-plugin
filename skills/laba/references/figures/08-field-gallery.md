# 08　分野別の用例集（7 分野 × 12）

分野ごとに、図にする値打ちのある難所と、向く型、メッセージの例を並べる。ノートを作るとき、資料の論点がここにあれば、型とメッセージの形をここから取る。

使い方の注意：

- 「この図で分かること（例）」は、メッセージの**形**の見本である。資料の立場・語に合わせて書き直す。資料が別の立場なら、資料に従う。
- 条文番号・期間・判例の立場は、図に入れる前に必ず原文で確かめる（`../statute-verification.md`、`../case-verification.md`）。ここに書いた番号も、確かめずに写さない。
- 「用例」の欄に名前があるものは、`scripts/figgen/specs/` にそのまま生成できる仕様がある。「—」のものは、同じ型の用例を写して中身を入れ替える。
- 型の詳しい作り方は `02-types/` の各ファイル。

## 9　用例を自分のノートに使う手順

1. 資料の論点に近い行を探し、型を決める（近い行がなければ `../algorithms/figure-type.md`）。
2. 「用例」の仕様を写す（`cp scripts/figgen/specs/〇〇.json 作業フォルダ/図N.json`）。
3. `message` を、資料の立場と語で書き直す。
4. ラベルを、本文の語に入れ替える。条文番号・期間は原文で確かめてから入れる。
5. 強調（`accent`）を、そのノートの争点に付け直す。
6. 生成・点検・照合・採点（`00-principles.md` 10節）。

## 11　条文の照合の記録

用例と型解説に出てくる条文は、法令の現行の原文（e-Gov 法令検索の条文）と照合した。照合したのは、民法・民事訴訟法・刑法・行政事件訴訟法・刑事訴訟法・会社法の 73 か条（用例の仕様が引く条文の全部を含む）。照合で直したのは次の所。

| 用例 | 直した所 |
|---|---|
| `numberline-koso` | 送達の対象を、現行の「電子判決書」に直した（民訴法285条）。電子調書の場合（254条2項）を注に足した |
| `flow-torikeshisosho` | 「回復すべき利益」→「回復すべき法律上の利益」（行訴法9条1項かっこ書）。「上から順に審査され」をやめ、並べた順は説明の順であると断った |
| `statute-415` | ただし書の「契約その他の債務の発生原因及び取引上の社会通念に照らして」を落とさない |
| `panel-hoteichijoken`・`timeline-hoteichijoken` | 「売却後／買い受ける」→「競売後／競売で買い受ける」（民法388条の「その実行により」） |
| `timeline-hanrei-hensen` | 架空の例をやめ、裁判所ウェブサイトの裁判例検索で書誌と裁判要旨を確かめた二つの判決にした |

判例の書誌・要旨は、裁判所ウェブサイトで確かめたものだけを用例に書く。確かめていない判例は、用例に入れない。条文は改正されるので、用例を写して使うときも、その時点の原文で確かめ直す（`../checklists/` の条文の確認）。
