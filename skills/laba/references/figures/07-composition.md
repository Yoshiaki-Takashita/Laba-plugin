# 07　紙面の組み方（講義ノートとスライド）

一枚の図がよくても、紙面の中での置き方が悪いと読まれない。ここでは、図を講義ノートの頁とスライドにどう組むかを決める。作品集（ポートフォリオ）や図面集の紙面づくりで確かめられてきた考え方を、法学のノートに移したものである。

## 1　もとにした考え方と、ノートへの移し方

| 作品集・図面集での考え方 | 法学のノートでは |
|---|---|
| 図は、データ（建物の寸法）から道具で作る。毎回手で描くと、決まりを思い出し損ねて粗くなる | 図は、仕様（JSON）から `figgen` で作る。手で SVG を書かない |
| 図の種類をそろえる。平面ばかりを並べず、断面・立面・分解図・ダイアグラムを組み合わせる | 当事者関係図ばかりを並べない。一つの章で、関係（誰が）・順序（いつ）・違い（なぜ分かれる）の三つの見方を組み合わせる |
| 一つの見開きに一つの主題。図は一つから三つ、文は 200〜500 字 | 一つの節に一つの難所。図は一つか二つ。図の前後に、図を指す文と受ける文 |
| 比べるものは、同じ枠・同じ縮尺・同じ向きで並べ、変わった所だけを一色で示す | 成立する場合としない場合は、同じ時間軸・同じ当事者の配置で上下に並べる（複合図）。違う所だけえんじ |
| 白は紙面の六割から八割。ただし、頁の下半分が空いたままにしない | 図の中の空白は六割前後。図の横に大きな空白の列を作らない。図だけの頁を作らない |
| 資料・推定・創作の三層を、図の中で見分けられるようにし、図題で断る | 条文や判例にあること（実線）、争い・仮定（破線）、書き手の補足（「（補足）」）を分け、図題で断る |
| 「まだ分からないこと」は一か所にまとめる。図ごとに書かない | 留保は節の終わりにまとめる。図の注は二つまで |
| 図の線は、太さの段で主役を示す（太細の比は三倍前後） | 細 0.9・太 2.5 の二段。太い線は強調か主役だけ |
| 寸法や根拠は、確かめた値だけを事実として書く | 条文番号・判例の書誌・期間は、原文で確かめたものだけを図に入れる |
| 出す前に、見開きごとに図の数・文字数・空白の割合を数える | 出す前に、節ごとに図の数・図の型の種類・図と参照の距離を数える（6節） |

## 2　一つの章の図の組み立て

一つの章（講義一回分）で、図は三つか四つまで。次の順に組むと、読み手が迷わない。

| 順 | 役割 | 向く型 | 置く所 |
|---|---|---|---|
| 1 | 地図：誰がいて、何が問題か | 当事者関係図、権利移転の連鎖、包含図 | 設例のすぐ後 |
| 2 | 仕組み：結論がなぜ分かれるか | 比較図、流れ図、時間軸、積み上げ図、複合図 | 難所の説明の直後 |
| 3 | 整理：全体をどう覚えるか | 座標図、判例マトリクス、決定木、要件効果の木 | 節の終わり |

- 1 は省いてよい（当事者が二人なら要らない）。2 は省かない。図を一つしか置けないなら 2 にする。
- 同じ型を三つ続けない。同じ型が続くときは、複合図にまとめられないかを考える。
- 一つの事案に図が二つあるときは、人の位置と語をそろえる（`06-traceability.md` 5節）。

## 3　ノートの頁への置き方

### 幅と大きさ

- 図は版面いっぱい（150mm）で作り、その幅で貼る。縮めない。縮めると、図の字が本文より大幅に小さくなる。
- 小さな図（当事者が二人、段が二つ）でも幅は変えない。エンジンが中央に寄せ、高さを低くする。
- 図の高さは、頁の半分（約 120mm、図の単位で 830）までを目安にする。超えるなら、段を減らすか二つに分ける。複合図は頁の三分の二までよい。

### 置く位置

- 図は、それを指す文の**すぐ後**に置く。指す文と図の間に、別の論点の段落を挟まない。
- 図が頁をまたいで次の頁に送られるときは、指す文も一緒に送るか、図の前で改頁する。図と図題を別の頁に分けない。
- 節の見出しのすぐ下に図を置かない。先に、何が問題かを一段落で書く。
- 図の上下は、本文の一行ぶん空ける。図題は図の下、図から半行。

### 図・表・段の使い分け

| 内容 | 向くもの |
|---|---|
| 関係・順序・違いが難所 | 図 |
| 項目が四つ以上あり、項目ごとに複数の属性を見比べる | 表（横罫だけ） |
| たとえ・言い換えで分かる | 「ざっくり理解」の段（太字の見出し＋字下げ。枠・網掛けは使わない） |
| 条文の文言そのもの | 条文の引用（ノートでは字下げの段。スライドでは条文の枠） |
| 一文で言える | 本文 |

図と表で同じ内容をくり返さない。図の下に同じ内容の表を置くのは、表に図にない属性（判例の書誌など）があるときだけにする。

### 頁の見た目

- 図だけの頁、図が三つ並ぶ頁を作らない。一頁に図は二つまで。
- 頁の下三分の一が空いたまま次の頁に図が送られるときは、前の段落を見直す（文を足すのではなく、図の位置を一段落ぶん前後に動かす）。
- 図の左右に本文を回り込ませない。

## 4　比べる図の組み方（同じ枠のくり返し）

比べることが目的のときは、次の三つをそろえる。そろっていないと、読み手は違いを探せない。

1. **枠**：同じ型、同じ幅、同じ並び順。一方を写して作り、違う事実だけを変える。
2. **語**：同じ内容は一字も変えない。「抵当権設定」と「抵当権の設定」を混ぜない。
3. **強調**：違う所だけを、両方の図の対応する位置で強調する。

置き方は、上下（複合図）が基本。左右に並べると、一つの図の幅が半分になり字が入らない。二つの場合までにし、三つ以上は表にする。

## 5　スライドへの組み方

ノートの図をスライドに移すときは、作り直す。画像を貼らない（拡大するとぼやけ、字の大きさが合わない）。詳しくは `../slides/03-diagram-on-slide.md`。

| ノート | スライド |
|---|---|
| 図題の「この図で分かること」 | スライドの見出し（一枚一メッセージ） |
| 図の本体 | 図形で描き直す。箱の字は 16pt 以上 |
| 図題の読み方・強調の意味 | 図の下に一行 |
| 注 | 話す原稿に移す。スライドには載せないか、一つだけ |
| 段の多い流れ図・積み上げ図 | 段ごとに一枚ずつ出す。前の段は黒のまま残し、新しい段だけを強調する |
| 比較図 | 列を一つずつ出すか、段を一つずつ出す。違いの段を最後に強調する |
| 複合図 | 上の図→下の図の順に二枚。三枚目で並べて違いを強調する |

段ごとに出すときの配置は、最終形を先に決めて動かさない。人も箱も、出てきた位置から動かない（`02-types/03-tsumiage.md`、`../slides/04-step-reveal.md`）。

一枚のスライドに入れる図は一つ。図の箱は七つまで、矢印は六本まで。超えるなら二枚に分ける。

## 6　出す前に数えるもの

節ごと・章ごとに、次を数える。目安から外れたら、理由を言えるかを確かめ、言えなければ直す。

| 数えるもの | 目安 | 外れたとき |
|---|---|---|
| 章の図の数 | 三つか四つまで（長い章で五つ） | 難所でない図を落とす |
| 図の型の種類 | 図が三つ以上なら二種類以上 | 当事者関係図を、仕組みを見せる型に替える |
| 当事者関係図の数 | 一つのノートに二枚まで | 同上 |
| 「仕組み」の図（2節の表の 2）の数 | 章に一つ以上 | 最大の難所に図を足す |
| 図と、それを指す文の距離 | 同じ頁、間に別の論点なし | 図を動かす |
| 図の高さ | 頁の半分まで（複合図は三分の二） | 段を減らす・分ける |
| 一頁の図の数 | 二つまで | 図を次の節に送るか、落とす |
| 図の中の空白 | 五割から九割（`fig_lint.py` W05） | 語を減らす・分ける |
| 図題の形 | 「図N　この図で分かること：…。読み方。強調は…。」 | `05-caption.md` |
| 本文との照合 | 「なし」0、T01〜T03 が 0 | `06-traceability.md` |

## 7　よくある組み方の失敗

| 失敗 | 直し方 |
|---|---|
| 設例の当事者関係図を置いて、難所の図がない | 当事者関係図を落としてでも、仕組みの図を置く |
| 図が節の最後にまとめて置かれ、説明と離れている | 説明の直後に動かす |
| 図を縮めて二つ横に並べた | 上下に並べる。複合図にする |
| 成立する場合の図だけがある | しない場合を同じ枠で並べる |
| 同じ人が、図1では左、図2では右にいる | 位置をそろえる |
| 図と表が同じことを言っている | どちらかを落とす |
| 図題が図の上にある・図の中にある | 図の下に置く |
| 留保の注が三つ以上付いて、図より注が目立つ | 留保を節の終わりにまとめる |
| スライドにノートの図の画像を貼った | 図形で描き直す |
