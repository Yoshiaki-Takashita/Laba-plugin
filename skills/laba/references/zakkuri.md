# 「ざっくり理解」の書き方

本文の前に置く、短くて平易な解説。本文が正確さを担い、「ざっくり理解」が入口を担う。読者はここで場面と問題をつかんでから、本文の厳密な説明に入る。

## 目次
1. 置き場所　2. 体裁　3. 流れ（7つの部品）　4. 守ること　5. 例1：法定地上権　6. 例2：同時審判の申出　7. チャットで短く答えるとき

## 1. 置き場所
- 一覧化の段階で書き出した「文章だけでは分かりにくい点」の直前に置く。章の頭に機械的に置かない。
- 表紙の直後に「この回の全体像（ざっくり）」を半頁以内で置く。何の話か、大きく何本立てかを示す。
- 目安：10〜15頁に2〜4か所。多すぎると本文が細切れになる。
- 図を参照するなら、その図は2頁以内に置く。

## 2. 体裁
- 太字の見出し「ざっくり理解：○○」。左に字下げして本文と分ける。色・枠・網掛けは使わない。
- 段の中はすべて、です・ます。疑問は「〜でしょうか」。
- 半頁以内。
- ビルダーでは `ZH`（見出し）、`Z`（段落）、`ZB`（箇条書き）、`ZN`（番号）を使う。

## 3. 流れ（7つの部品）
全部を使う必要はない。場面と「ひとこと」は必ず入れる。

| 部品 | 中身 | 書き方 |
|---|---|---|
| 場面 | 具体的な人物（A・B・C）で、何が起きるかを1〜2文で | 「Aが…したとします。」 |
| 前提 | 理解に必要な仕組みを一つだけ | 太字の小見出し＋2文 |
| 何が困るのか | 場合分け①②を短い箇条書きで。最後の行が「困ること」 | 1行1事実 |
| なぜ前もって防げないのか | 当事者が自分で備えられない理由 | 2文 |
| そこで○○（条文） | 制度の名前と条文。要件は番号で | 番号付き |
| なぜこの制度があるのか | 理由を2つまで。誰の利益か | 箇条書き |
| ひとことでまとめると | 1文 | 太字の小見出し＋1文 |

## 4. 守ること
- 本文の理由の列挙を繰り返さない。同じ文を3つ以上重ねない。本文の側は、同じ設例を「前述の設例において」で受ける。
- 短くしたために不正確になる所は言い切らない。「正確には→本文○○」と一言添えて、本文へつなぐ。
- 資料に対応する文が無い説明を入れるなら「（補足）」を付ける。確度の語（余地がある、とされる）は、ここでも保つ。
- 段ごとに、理由の文を1つ入れる（「〜からです」「〜ので」）。場面と結論だけを並べない。
- 例の限定語を落とさない（「数人が起こす婚姻取消しの訴え」を「婚姻取消し」に縮めない）。
- 平易な言い換え（「両方に負ける」「まとめて審理する」）は、ここでだけ使ってよい。

## 5. 例1：法定地上権

**ざっくり理解：抵当権の実行で土地と建物の持ち主が別人になったとき**

土地と建物の持ち主が同じ人、たとえばAだったとします。Aが土地か建物の一方だけに抵当権をつけてお金を借り、返せなくなって競売になると、土地と建物の持ち主が別々の人に分かれます。

**前提：土地と建物は別々の財産**　日本の民法では、土地と建物はそれぞれ独立した不動産です。そのため、片方だけに抵当権をつけることができ、競売も片方だけで行われます。

**何が困るのか**
- ①土地だけに抵当権がついていた場合：土地が競売でCのものになる。建物はAのもの。Aは、Cの土地に建物を置く権利を持っていない。
- ②建物だけに抵当権がついていた場合：建物が競売でCのものになる。今度はCが、Aの土地を使う権利を持っていない。
- どちらも、このままでは建物を壊すしかなくなる。

**なぜ前もって防げないのか**　土地と建物が両方Aのものである間は、Aは自分の土地に自分のための借地権を設定できません。あらかじめ備える手段がないのです。

**そこで法定地上権（民法388条）**　法律が、建物のための地上権を自動的に成立させます。要件は次の4つです。
1. 抵当権を設定した時に、土地の上に建物がある
2. その時に、土地と建物の持ち主が同じ
3. 土地か建物、または両方に抵当権が設定された
4. 抵当権の実行で、土地と建物の持ち主が別々になった

**なぜこの制度があるのか**
- まだ使える建物を壊すのは、社会全体の損失だから。
- 当事者も、建物を残すつもりだったと考えられるから。

**ひとことでまとめると**　競売で土地と建物の持ち主が分かれても建物を壊さずにすむよう、法律が土地の利用権を与える仕組みです。（各要件の細かい判断は→本文）

## 6. 例2：同時審判の申出

**ざっくり理解：どちらか一方には勝てるはずなのに、両方に負けるのを防ぐ**

Xは、Y1の代理人だと名乗るY2と交渉して、Y1から物を買う契約を結んだとします。ところがY1は「Y2に代理権を与えていない」と言って、物を渡してくれません。

**何が困るのか**
- Xは、Y1には「契約どおり渡せ」と請求できる。ただし、Y2に代理権があった場合に限る。
- Xは、Y2には「無権代理人として責任をとれ」と請求できる。ただし、Y2に代理権がなかった場合に限る。
- 代理権は「あった」か「なかった」かのどちらかなので、Xはどちらかには勝てるはずである。
- ところが、二つの裁判が別々に進むと、Y1との裁判では「代理権はなかった」、Y2との裁判では「代理権はあった」と判断され、両方に負けることがありうる。

**なぜ一緒に訴えるだけでは足りないのか**　二人をまとめて訴えても、裁判所は審理を分けることができます。分けられると、同じことが起こります。

**そこで同時審判の申出（民事訴訟法41条）**　原告が申し出ると、裁判所は審理と判決を分けることができなくなります。主な条件は次のとおりです。
1. 二つの請求が、法律上、両立しない関係にある
2. 原告が申し出る（控訴審の口頭弁論が終わるまで）

**ひとことでまとめると**　両立しない二つの請求を同じ手続で同時に判断してもらい、判断の食い違いで両方に負けるのを防ぐ仕組みです。（「法律上両立しない」の意味と、上訴での扱いは→本文）

## 7. チャットで短く答えるとき
利用者が「今この場で教えて」「簡潔に」と聞いたら、ファイルを作らず、この形（太字の小見出し＋短い文＋箇条書き、最後に「ひとことでまとめると」）で答える。
