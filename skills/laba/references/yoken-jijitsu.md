# 設例の論じ方（請求→抗弁→再抗弁、ほか分野ごとの型）

設例・演習事例は、分野ごとの論証の型に沿って論じ、結論を言い切る。型を示さずに結論だけ書いたノートは、答案に転用できない。

1. 民事：請求→抗弁→再抗弁　2. 間違えやすい振り分け　3. 段階ごとの書き方　4. 結論の言い切り方　5. 刑事の型　6. 行政の型　7. 憲法の型　8. 会社法・民事訴訟法の設例　9. 検査

## 1. 民事：請求→抗弁→再抗弁

設例の章の冒頭に「前提：請求・抗弁・再抗弁」の段を置く。書くことは次の3点と表。

- 請求する側は、権利が「発生した」ことを基礎づける事実だけを主張し、争われれば証明すればよい。権利は、いったん発生すれば、消滅の原因がない限り存続するものとして扱われる。「消えていないこと」の証明はほぼ不可能であり、消滅を主張する側のほうが原因を知っているからである。
- 相手方は、権利の発生を妨げる事実、消滅させる事実、行使を阻む事実を主張し、争われれば証明することで、請求を退けられる（抗弁）。
- 請求する側は、抗弁の効果を妨げる事実を主張・証明すれば、抗弁を退けられる（再抗弁）。以下、再々抗弁と続く。請求原因・抗弁の振り分けは、証明責任の分配であると同時に、主張責任の分配でもある（主張がなければ、裁判所はその事実を判決の基礎にできない）。

| 段階 | 誰が | 何を証明するか | 問い |
|---|---|---|---|
| 請求（請求原因） | 請求する側 | 権利の発生を基礎づける事実 | 請求の根拠は何か |
| 抗弁 | 相手方 | 発生の障害・消滅・行使の阻止を基礎づける事実 | どうすれば請求を退けられるか |
| 再抗弁 | 請求する側 | 抗弁の効果を妨げる事実 | どうすれば抗弁を退けられるか |

## 2. 間違えやすい振り分け

| 間違い | 正しい扱い |
|---|---|
| 請求原因を争うことを「抗弁」と書く | 相手の主張する事実を争うのは「否認」。抗弁は、請求原因と両立する別の事実で効果を覆すもの |
| 訴訟要件を請求原因に入れる | 訴訟要件（当事者適格、訴えの利益、代表訴訟の提訴要件など）は、請求原因とは別の項目として先に検討する |
| 判例の原則と例外を一つの段階に書く | 原則を基礎づける事実＝抗弁（または再抗弁）、例外（特段の事情）を基礎づける事実＝その次の段階、に分ける |
| 評価（「潜脱である」「信義則に反する」）を独立の段階にする | 評価は、その段階の要件を基礎づける事情として書く。規範的要件では、評価を基礎づける事実と、妨げる事実とに分ける |
| 別の筋の抗弁を混ぜる | 効果が出る道筋が違う抗弁（例：その債務自体の消滅と、主たる債務の消滅を通じた消滅）は、抗弁Ⅰ・抗弁Ⅱと分ける |
| 資料にない段階を作る | 資料・判例に根拠のある段階だけを書く。足すなら「補足」と明記する |
| ある主張の位置を固定して覚える（例：94条2項は常に再々抗弁） | 位置は、何を請求し、相手が何を主張したかで変わる。原告が所有権に基づいて請求し、被告が売買による所有権喪失を抗弁とし、原告が虚偽表示を再抗弁とすれば、第三者の保護は再々抗弁になる。第三者が原告となって請求する場合や、別の請求の立て方では、請求原因や抗弁の中に現れる。その設例の請求に即して決める |

## 3. 段階ごとの書き方
- 見出しを【請求】X→Y、【抗弁Ⅰ】、【再抗弁Ⅰ】、【抗弁Ⅱ】…とし、どの段階の話かを一目で分かるようにする。
- 各段階は「要件（条文）→本件への当てはめ→この段階の結論」の順。
- 日付や事情による場合分け（①②）は、それが効いてくる段階で書く。冒頭でまとめて場合分けしない。
- 小さな設例でも、誰が何を主張するのかを1文で示す（「XがYに明渡しを求め、Yが占有権原を抗弁として主張する、という構図である」）。
- 事実関係は図にする（当事者関係、時間軸）。

## 4. 結論の言い切り方
各ケース・各設問・各パターンの最後に、太字の「結論」を置く。

1. 問いへの答えを1文で言い切る（「Xは、Yに対し、甲の明渡しを請求できる。」）。
2. 理由を2〜3文で（どの段階が決め手か）。
3. 見解が分かれるなら「ただし、○○説によれば〜」と添える。
4. 資料が結論を示していない（「？」で止めている）点は、判例・資料の傾きに従ってノートとしての結論を示し、「資料は結論を明示していない」と書く。

章の末尾に「各ケースの結論一覧」の表（ケース／問い／結論／決め手の条文・判例）。

## 5. 刑事の型
罪責を問う設例は、行為者ごと・行為ごとに、次の順で論じる。

1. 構成要件該当性：実行行為→結果→因果関係→故意（過失）。身分・目的などがあればここで。
2. 違法性阻却事由：正当防衛、緊急避難、正当行為、被害者の同意など。問題になるものだけ。
3. 責任：責任能力、違法性の意識の可能性、期待可能性。問題になるものだけ。
4. 共犯：共同正犯・教唆・幇助、間接正犯との区別、共犯と錯誤・離脱。正犯の罪責を確定した後で論じる。未遂（実行の着手、中止）は構成要件該当性の問題なので、1 の中で、結果が生じなかったときに論じる。
5. 罪数：成立する罪の関係（観念的競合、牽連犯、併合罪、包括一罪）。

刑事訴訟法の設例は、捜査なら「強制処分か任意処分か→任意処分としての限界」、証拠なら「証拠能力（関連性・伝聞・違法収集・自白）→証明力」の順。結論は「〜罪が成立する」「証拠能力は認められる／否定される」と言い切る。

## 6. 行政の型
取消訴訟を念頭に置くと、次の順になる。

1. 訴訟要件：処分性→原告適格→訴えの利益（狭義）→被告適格・出訴期間・管轄など。
2. 本案：処分の違法。実体の違法（要件の解釈・当てはめ、裁量の逸脱・濫用）と、手続の違法（理由の提示、聴聞・弁明など）を分ける。
3. 訴訟の選択：取消訴訟で足りるか、無効等確認・義務付け・差止め・当事者訴訟・国家賠償のどれが適切か。仮の救済。

行政立法・行政指導・行政契約などの行為形式が問題のときは、「法的性質→法律の根拠の要否→限界→争い方」の順。

## 7. 憲法の型
権利の制約が問題の設例は、次の順。

1. 保障：その行為・利益が、どの条文の保障の範囲に入るか。
2. 制約：国の行為が、その権利を制約しているか。
3. 正当化：形式（法律の根拠、明確性）と実質（目的と手段）。判断の枠組みは、資料に合わせる。資料が審査基準（厳格な審査・中間の審査・合理性の審査）で書いているか、比例原則（適合性・必要性・狭義の比例性）で書いているか、判例の利益衡量（考慮要素の総合）で書いているかを見て、同じ枠組みで書く。審査基準で書くなら、権利の性質と制約の態様から基準を選び、理由を示す。枠組みを混ぜない（`fields/kenpo.md` ①）。
4. 当てはめと結論：合憲か違憲か（法令違憲か適用違憲か）。

統治の設例は「条文の文言→制度の趣旨→判例の枠組み→当てはめ」。

## 8. 会社法・民事訴訟法の設例
- 会社法：責任追及なら「訴えの種類と要件（訴訟要件）→請求原因（任務懈怠・損害・因果関係など）→抗弁（帰責事由の不存在など）」。決議・行為の効力なら「瑕疵の種類→争う手段（訴えの種類・提訴期間・原告適格）→効力→取引の相手方の保護」。
- 民事訴訟法：手続の設例は「何が問題になる場面か（訴えの適法性／審理／判決の効力／上訴）→条文→判例の基準→当てはめ」。当事者が複数なら、まず類型（通常共同訴訟か必要的共同訴訟か）を決める。

## 9. 検査
- 各段階の見出しに段階名があるか。
- 否認を抗弁と書いていないか。訴訟要件を請求原因に入れていないか。
- 各ケースの最後に、1文で言い切った結論があるか。
- 結論一覧の表と、本文の結論が食い違っていないか。
- 資料にない段階・結論に「補足」「ノートとしての結論」の表示があるか。
