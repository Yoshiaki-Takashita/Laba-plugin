# 確認表⑦：渡す前

- □ ファイル名に、科目・回・題・版が入っている。前の版を残した。
- □ 利用者の指定（体、図、分量、形式）を満たしている。
- □ スライドを渡すなら：`deck_lint.py` が error 0 でも、全枚を画像にして1枚ずつ見た（図形の重なり、帯の下端で切れる行、白字・灰色、書体・飾り、判例研究の決まり＝条文番号・判旨の出典・相関図の順序・強調の付け先。`references/slides/09-quality-rubric.md`）。
- □ 表紙に、不要な個人名・所属を書いていない。資料の認証つき URL を載せていない。
- □ 報告を書いた（`delivery.md` の型）：
  - □ 何が何頁でできたか。図・表の数。
  - □ 各ケース・各設問の結論（ノートとしての判断は、そう書く）。
  - □ 判例：確認できたもの／できなかったもの（扱い）／補ったもの。
  - □ 条文：照合した数と方法。資料の表現に条文の語を補った箇所。
  - □ 資料の誤記と思われる箇所。
  - □ 授業・原典で確かめてほしい点。
  - □ 採点を回した場合：総合点、判定、誤りの件数、未採点の項目。
  - □ 最後の版が独立の点検を受けたか。
- □ 報告に、作業中の呼び名（ラウンド番号、スクリプト名）を使っていない。
- □ 確かめていないことを、確かめたように書いていない。自分で付けた点・数えた値を、独立の評価のように書いていない。
- □ 報告の数値は、機械で数えた値だけを書いた（`report_numbers.py` の `numbers.md`、各検査の出力）。手で数えた値、途中の版の値、覚えていた値を書いていない。
  - □ 数え方を併記した（字数は空白を除くか、巻末を含むか。頁数は何で変換した PDF か）。
  - □ 前の版と並べる値は、前の版も同じ道具で数え直した（道具や数え方の違う値を前後に並べない）。
  - □ 最後に作り直した版で数え直した（直した後の版と、数えた版が同じ）。
  - □ 機械で数えられない値（点検者の点、読んで判断した件数）は、だれがどう数えたかを書いた。
- □ 丸写しの程度を報告するなら、生の値と除外後の値の両方。
- □ 利用者に決めてほしいこと（体の統一、範囲、次の回）があれば、最後に、選びやすい形で書いた。
