# 点検者への指示文のひな形

本文を書いていない点検者（別のエージェント、または人）に渡す指示文。〔 〕を埋めて使う。どれも「修正はしない。指摘だけ」。作成の経緯や自己評価は渡さない。

| ファイル | 用途 | いつ |
|---|---|---|
| `legal-accuracy.md` | 法的正確さ（条文・判例・論証・結論・図） | 必ず |
| `added-text.md` | 足した文の意味照合 | 資料があるとき、必ず |
| `style-author.md` | 文体：同じ書き手に見えるか | 教科書型のとき |
| `score-16.md` | 基本4指標＋独自12指標の採点 | 採点を回すとき |
| `field-review.md` | 分野の専門の目での査読（分野ごとの見どころ） | 分野に特有の論点が多いとき |
| `figure-check.md` | 図と本文の照合 | 図が3枚以上あるとき |

一人の点検者に全部を頼むと、一つ一つが浅くなる。法的正確さと、足した文の照合は、分けて頼む。
