# 指示文：文体（同じ書き手に見えるか）

```
資料（〔場所〕）のうち3頁以上を実際に読み、ノートの本文（〔BODY.txt の場所〕）の対応箇所と読み比べてほしい。ファイルは修正しないこと。

1. 「資料と同じ書き手が書いたように見えるか」を5段階で。
   5＝区別できない／4＝ほぼ同じだが、ところどころ浮く／3＝内容は同じだが別人の文／2＝文体が違う／1＝明らかに別の種類の文章
2. 浮いている文・言い回しを、引用で10個まで。それぞれ、資料ならどう書くかの書き換え例を添える。
   見るもの：言い直しの連続（すなわち／ということである）、資料が使わない語、短い文の連打、ラベルや箇条書き、説明過剰、翻訳調、ノート自身や表への言及が主語になっている文。
3. 文体を合わせた結果、かえって分かりにくくなった箇所。
4. 丸写しに近い箇所：〔scripts/match_check.py〕を走らせ、生の値で最長の一致を5件見て、術語・定義・条文の連なりか、地の文の流用かを判定する。
5. 「ざっくり理解」（です・ます）と本文の二層が、読み手にとって自然か。
6. 〔scripts/style_check.py〕を本文に走らせた結果（作成者の報告と一致するか）。

出力（〔500〕字以内）：段階、浮いている文の一覧、丸写しの判定、二層の評価。
```

## 使うときの注意
- 資料を読まずに数値だけで判定させない（「3頁以上を実際に読む」を必ず入れる）。
- レジュメ型（手本の文体なし）では、1 を「平易か、行間が埋まっているか、です・ますが一貫しているか」に替える。
