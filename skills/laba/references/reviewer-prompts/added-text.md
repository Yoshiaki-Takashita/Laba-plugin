# 指示文：足した文の意味照合

```
講義ノートのうち、資料に足された説明だけを、資料の該当段落と突き合わせてほしい。ファイルは修正しないこと。

対象：〔ノートの場所〕
資料：〔資料の場所（書き起こしと、頁の画像）〕
作成者の照合表：〔work/added.md。無ければ「なし」〕（鵜呑みにせず、抜き取りで確かめる）

突き合わせるもの
- 言い換えの文、資料にない具体例
- 「ざっくり理解」の段、「この回の全体像」
- 「まとめ」、論点カード
- 表のセル、図のラベルと注記、図題

列挙してほしいもの
1. 意味のずれ：資料と違うことを言っている。
2. 理由のすり替え：資料・判例が挙げた理由と、別の理由になっている。
3. 限定語の脱落：「一般には」「原則として」「〜に限り」「数人による」など。複数を指す語を1件に狭めていないか。
4. 確度の変化：「余地がある」「要請されよう」「不明確である」が断定になっている。その逆。
5. 法的な効果と、運用上の望ましさの混同。
6. 論理の向きを決める句（「これを認めないと」「〜でない限り」）の脱落。
7. 資料にない内容なのに「（補足）」の表示がないもの。
8. 「と説明されることもある」のような、出所のない帰属。

出力（〔700〕字以内）
- 件数。
- 各件「ノートの文の冒頭15字／資料の対応箇所（頁・冒頭の語）／ずれの内容／直し方」。
- 重いもの（意味が逆になる、結論が変わる）を先に。
```

## 使うときの注意
- 資料が画像のときは、点検者にも画像を渡す（書き起こしの誤りを引き継がないため）。
- 対象が多いときは、難所の周り・判例の理由・まとめ・表・図を優先する、と書き添える。
