# 指示文：法的正確さ

```
〔分野〕に詳しい査読者として、講義ノート1本の法的な正確さを点検してほしい。ファイルは修正しないこと。

対象：〔ノートの場所（docx と全文テキスト）〕
元の資料：〔資料の場所。無ければ「なし」〕

確認してほしい点
1. 条文：番号・項・号・ただし書、要件（限定の語）、効果、名宛人、改正の前後。対象は〔主な条文〕。現行の条文で確かめること（e-Gov 法令検索など）。
2. 判例：事案、結論、判決が挙げる理由、主文（棄却・破棄差戻し・破棄自判）、書誌。「」の引用が原文と一字一句一致するか。
   対象：〔判例の一覧〕。作成者が原典を確認していない判例：〔一覧〕は特に。
   表の「判決が挙げる理由」の欄が、本当に判決文にあるか（資料の説明が混ざっていないか）。
   裁判所の判例検索で確かめてよい。確かめられなかったものは、そう書くこと。
3. 論証の構造：請求原因・否認・抗弁・再抗弁の振り分け、訴訟要件の位置づけ〔刑事・行政・憲法なら、その分野の型〕。
4. 各ケース・各設問の結論と理由。資料・判例の立場と合っているか。
5. 図：矢印・ラベル・例示が本文と合っているか。
6. 資料からの拾い漏れ、論理の飛躍、言い過ぎ（確度を強めていないか）。

出力（〔600〕字以内）
- 重大な誤りを先に、軽微な点を後に。
- 各指摘は「該当文の冒頭15字／何が誤りか／正しくはどうか（根拠の条文・判例）」。
- 推測・記憶による指摘は、そう明記する。
- 誤りが無ければ「なし」。確かめた範囲（どの条文・判例を何で確かめたか）を最後に1〜2行。
```

## 使うときの注意
- 対象の条文・判例の一覧は、`statute_check.py`・`cite_check.py` の出力から作る。
- 点検者の「記憶によれば」は、作成者が原典で照合してから直す。
- 重大な誤りが出たら、直した後にもう一度、同じ点検を頼む。
