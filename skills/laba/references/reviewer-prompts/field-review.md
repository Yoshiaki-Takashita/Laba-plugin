# 指示文：分野別の正確さの査読

`legal-accuracy.md` の指示文に、分野ごとの見どころを足して使う。〔分野の見どころ〕に、下の表から該当する行を写す。

```
〔分野〕を専門とする査読者として、講義ノートを点検してほしい。ファイルは修正しないこと。
対象：〔ノート〕　資料：〔資料〕
共通の確認点：（legal-accuracy.md の1〜6）
この分野で特に見てほしい点：
〔分野の見どころ〕
出力：〔600〕字以内。重大な誤りを先に。「該当文の冒頭15字／誤り／正しくは（根拠）」。推測は明記。
```

## 分野の見どころ

| 分野 | 特に見てほしい点 |
|---|---|
| 憲法 | 法廷意見と個別意見を混ぜていないか。登載誌（民集か刑集か）。後の判決が前の判決を変更したのか、区別したのか。審査の枠組みを選んだ理由が書かれているか。法令違憲と適用違憲の区別 |
| 民法（総則・物権） | 改正（平成29年・令和3年）の前後。善意か善意無過失か。第三者が現れた時点（取消しの前か後か）。対抗要件の有無。設定時・譲渡時の権利関係と図の一致 |
| 民法（債権） | 改正前の判例の扱い（瑕疵担保、危険負担、詐害行為取消権、時効）。条文の枝番号。特別法（利息制限法、割賦販売法、消費者契約法、借地借家法）の要件と数値。債務不履行と不法行為の構成の区別 |
| 民法（親族・相続） | 改正（平成30年・令和3年・令和4年）と施行日。相続分の計算の検算。遺産分割の対象になるか（預貯金・可分債権）。手続（調停・審判・訴訟）の振り分け |
| 商法・会社法 | 会社の類型（公開・非公開、取締役会設置）で規律が変わる点。旧商法の判例と現行法の対応。条文の名宛人。施行規則・計算規則に委ねられた事項。訴訟要件と請求原因の区別。損害額の基準 |
| 民事訴訟法 | 旧法の判例の条文番号。法と規則の区別。判例の事案と結論の対応。既判力・参加的効力・反射効の区別。特別法（人事訴訟法・会社法）が定める判決効の範囲。条文の限定の語 |
| 刑法 | 構成要件・違法性・責任の順。判例の基準と事案の対応。最判と最決の別。罪名・法定刑の改正（拘禁刑、性犯罪）。罪数の処理。資料の立場（学説）と当てはめの一致 |
| 刑事訴訟法 | 条文の号・枝番号。強制処分と任意処分の基準の文言。伝聞の判断での要証事実の特定。違法収集証拠の排除の基準。改正で入った制度の施行の有無 |
| 行政法 | 個別法の条文（判決当時か現行か）。処分性・原告適格・訴えの利益の区別。手続の違法と実体の違法の区別。下級審判決の結論。通達・要綱の法的性質。平成16年改正の前後 |
| 労働・知財・倒産 | 改正の有無と施行日。行政解釈と判例の区別。どの法律の何条か（破産法・民事再生法・会社更生法の別）。下級審の裁判例の確認の有無 |

## 使うときの注意
- 分野の見どころは手がかりである。`fields/` の該当ファイルの④⑤も、点検者に渡してよい。
- 点検者が確かめられなかった点は、報告に「未確認」として残す。
