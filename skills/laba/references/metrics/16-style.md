# 指標⑯　文体（基本指標・10点）

教科書型：本文が、資料と同じ書き手が書いたように読めること。レジュメ型：平易で、行間が埋まり、です・ますが一貫していること。

## 1. 定義と測り方

- 点検者が5段階で付ける（点検C。資料を3頁以上読んでから、ノートの本文を読む）。10 × 段階 ÷ 5。合格線4。
- 機械は数値と「浮いた文」を出す。
  - `style_profile.py`：資料の文体の測定（平均文長、文長の分布、段落あたりの文数、である文末率、接続語で始まる文の率、読点の種類、漢字率、括弧の率）。
  - `style_check.py`：ノートの本文の同じ値が、資料の許容幅に入っているか。外れると WARN。
  - `word_swap_check.py`：数値に出ない浮き。置き換えの型（「すなわち、…ということである」の連発）、資料に出ない文頭の語・文末の型、解説書に出にくい言い回し、数の予告の型、平易な言い換えの本文への混入。
- `style_check.py` の WARN が残っていれば、点検者の判定にかかわらず4以下とする。点検者がいないとき、機械だけの値は（10 − 1.5 × WARN の数）× 0.8 を上限の目安として出す（成果としては報告しない）。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 言い直しの連発 | 「すなわち、…ということである。」が何度も出る | 「つまり」を機械的に置き換えた |
| 資料に出ない平易な語 | 「そのため」「まとめて審理する」が本文に残る | です・ますの下書きを直した |
| 短い文の連打 | 30字前後の文が続く。ラベル（何か／なぜか）で区切る | レジュメの書き方を持ち込んだ |
| 読点の混在 | 「，」と「、」が混ざる | 層の間で文を移した |
| ざっくり理解に、である調が混じる | 本文の文をそのまま入れた | 体を直さなかった |
| 評価語・案内文 | 「非常に重要である」「以下で見ていこう」 | 解説の口調になった |
| 巻末の表の導入文が浮く | 巻末の説明文が、本文に無い文末の型で書かれる | 本文と別の時に書いた |
| 術語の言い換え | 一致を下げるために術語を崩した | 指標⑩を優先した |

## 3. 9.5 に届く条件（5段階で4.75以上に当たる）

1. `style_check.py` の WARN が0。
2. `word_swap_check.py` の、置き換えの型0、資料に出ない語0、出にくい言い回し0、平易な言い換えの混入0。数の予告は1節1回まで。
3. 本文の読点・数字・括弧の使い方が、資料と同じ（`style_profile` の `comma_full` など）。
4. ざっくり理解の段は、全部です・ます。本文は、全部である（資料がそうなら）。巻末の表の導入文も、本文と同じ体。
5. 点検者（点検C）が、資料を読んだうえで「同じ書き手に見える」（5）または「ほぼ見える」（4.75相当）と判定している。浮いていると指摘された文が0。

## 4. 手順

1. 取り込みの後、`style_profile.py` で資料を測る。数値のほか、資料の言い回しの型（理由の述べ方、対比の導き方、留保の付け方）を10〜20個拾って控える（`../style-imitation.md` 3）。
2. 本文は、拾った型を使って書く。資料に出ない接続語・文末を使わない。
3. `style_check.py` を走らせ、外れた数値を直す。数値を合わせるために語を機械的に替えない。浮いた文を、資料の同じ働きの文に倣って書き直す。
4. `word_swap_check.py -v` で、文単位の浮きを拾って直す。
5. 一致（指標⑩）を走らせ直す。文体を合わせると一致が増えることがあるので、両方が条件に入る所で止める。

## 5. 検査

```
python3 scripts/style_profile.py SOURCE.txt --out checks/profile.json
python3 scripts/style_check.py BODY.txt --profile checks/profile.json --out checks/style.json
python3 scripts/word_swap_check.py BODY.txt --source SOURCE.txt --out checks/swap.json -v
```
見る所：WARN の項目、置き換えの型、資料に出ない語、出にくい言い回し。本文テキスト（`--body-out`）に、巻末の表の導入文が含まれることに注意する（そこも資料の体で書く）。

## 6. 良い例・悪い例

- 良い例：「もっとも、この場合にも、申出の効果は弁論および裁判の分離が禁じられるにとどまり、共同訴訟人独立の原則（39条）は、なお妥当する。」
- 悪い例：「ただ、ここで注意すべきなのは、申出をしても独立の原則はそのままである、ということである。すなわち、弁論が分離されないだけ、ということである。」
- 悪い例：「申出の効果は2つある。1つ目は…。2つ目は…。」（資料がこの型を使っていないとき）
- 良い例（ざっくり理解）：「申出をしても、変わるのは『ばらばらに審理・判決されない』という点だけです。一方の被告がした自白が、もう一方の被告に及ぶわけではありません。」
