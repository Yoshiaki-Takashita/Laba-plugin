# 指標⑤　定義の精度

定義文が、過不足なく、限定の語を保って書かれていること。同じ語の定義が、箇所によって変わらないこと。

## 1. 定義と測り方

- 点を付けるのは点検者。資料の定義文とノートの定義文を並べ、要素（上位の概念、区別の基準、限定の語）を照らす。
- 機械の補助：`definition_check.py` が、資料とノートの定義文（「Aとは、…をいう」「…をAという」の形）を拾い、術語ごとに並べた照合表（`definition.md`）を作る。資料の定義にあってノートの定義に無い語（落ちた語の候補）、定義が無い術語、ノートの中で文言が違う定義の組を出す。`match_check.py` は、定義文を丸写しの数から除く（定義は資料の語のまま書いてよいため）。
- 換算：全定義が正確＝10。軽い欠落（限定語1つ）1件ごとに−1。主要な概念の定義で要素が1つ欠ける＝5。合格線8。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 限定の語が落ちる | 「判決の内容が共同訴訟人の全員について一致しなければならない訴訟」から「全員について」が落ちる | 短くした |
| 要素が足りない | 二つの要件で定義される概念を、一つで定義した | 資料の定義が2文に分かれていた |
| 広げすぎ | 例示を定義に入れた（「…など」を定義の本体にした） | 例と定義を分けなかった |
| 言い換えで別の概念になる | 術語を日常語に置き換えた（「合一確定」を「同じ結論」） | 平易にしようとした |
| 箇所による違い | 本文と表と論点カードで、同じ語の定義が違う | 層ごとに別に書いた |
| 定義が無い | 術語を、定義せずに使い始めた | 資料が前の章で定義していた |

## 3. 9.5 に届く条件

1. 定義の照合表（`definition.md`）の全行を読み、「判定」の欄を埋めている。「定義なし」が0、「語が落ちた候補」は1件ずつ読んで、意味が変わっていないことを確かめている。機械が拾わない形の定義（2文に分かれたもの、表の中の定義）は、手で表に足している。
2. 術語は資料の語のまま書いている。平易な言い換えは、ざっくり理解の層だけに置き、「（＝術語）」で術語に戻している。
3. 同じ語の定義が、本文・表・論点カードで同じ文言である（定義は本文に1回書き、他の層は本文を参照する）。
4. 資料が前の章で定義した語を使うときは、初出で1文の定義を補い、「（補足）」を付けている。
5. 点検者が、定義の欠落0と判定している。

## 4. 手順

1. 一覧化で、定義文を全部控える。定義が2文以上に分かれているときは、まとめて1件として控える。
2. 本文では、定義は資料の文の構造のまま書く（主語、上位の概念、区別の基準の順）。短くするのは、例示の部分だけにする。
3. 定義の直後に、定義に当たる例と当たらない例を1つずつ置く（指標⑦にも効く）。
4. 書き終えたら `definition_check.py` で照合表を作り、1行ずつ読む。落ちた語が限定の語（全員、同一、のみ、法律上 など）なら戻す。言い換えで意味が保たれているなら、判定の欄に「言い換え」と書く。
5. 表・カードに定義を書くときは、本文の文を写す。書き直さない。

## 5. 検査

```
python3 scripts/definition_check.py SOURCE.txt blocks.json --out checks/definition.json --md checks/definition.md -v
python3 scripts/definition_check.py --note-only blocks.json        # 資料が無いとき（ノートの中の食い違いだけ）
```
見る所：資料の定義の数と「ノートに定義あり」の数、「語が落ちた候補」の語、「ノートの中の食い違い」。機械は、定義の中身が正しいかは見ない。拾える形も限られる（「とは…をいう」型）。照合表は作成者が仕上げ、点検者が抜き取りで確かめる。

## 6. 良い例・悪い例

- 良い例：「必要的共同訴訟とは、判決の内容が共同訴訟人の全員について一致しなければならない共同訴訟をいう。」
- 悪い例：「必要的共同訴訟とは、全員が同じ判決を受ける訴訟である。」→「一致しなければならない」（法的な要請）が「受ける」（結果）に変わり、「共同訴訟」であることも落ちている。
- 良い例（ざっくり理解）：「全員について同じ内容の判決にしなければならない、ということです（これを合一確定といいます）。」
- 悪い例（表）：本文と違う言い方で定義を書き直す。→ 本文の定義を写すか、「12-4-1 参照」とする。
