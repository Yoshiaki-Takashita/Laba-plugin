# 指標⑪　情報効率

同じ内容を繰り返さず、資料に対して適正な分量で書かれていること。層（本文・ざっくり理解・表・図題・まとめ・巻末の表）が、それぞれ別の役目を持っていること。

## 1. 定義と測り方

- 機械だけで測る。
  - `density.py`：重複率（ノートの中で、15字以上の同じ並びが2回以上出る割合。書誌を除く）。
  - `info_efficiency.py`：層の間の重複（各層の文・セルが本文と12字単位で50%超重なる数）、言い直しの層（まとめ＋全体像）の割合、まとめの数、節ごとの分量比、新しい情報の少ない文、削る候補の一覧。
  - `summary_dup_check.py`：まとめの文が本文の言い直しになっていないか。
  - `info_efficiency.py` の「巻末」：巻末の表（論点カード・短答・出所表・索引）の字数と本編に対する比、中身のない列（半分を超えるセルが「—」「同上」「規範の欄と同じ」か空）、巻末どうしの重複（巻末の表のセルが、巻末の別の表のセルと12字単位で50%超重なる）。
  - `report_numbers.py --pdf`：頁数と、下が4割を超えて空く頁（最後の頁を除く）。
- 分量比は3つ出る。点に使うのは main。
  - main：本文＋ざっくり理解＋まとめ＋表＋図題 ÷ 資料（巻末の表を除く）
  - body：本文だけ ÷ 資料
  - all：巻末の表（論点カード・短答・索引・出所表）まで含めた全部 ÷ 資料
- 換算：10 − max(0, 重複率 − 3) −（main が1.15倍を超えた分：1.3倍までは0.15倍につき1点、1.3倍を超えると0.1倍につき2点）−（0.7倍を下回った分）− max(0, 言い直しの層% − 4) −（まとめが2か所以上なら1）− 0.3 × max(0, 表と本文の二重 − 2) − 0.2 × max(0, 新情報の少ない文 − 2) − 0.5 ×（中身のない列の数）− 0.2 ×（巻末どうしの重複のセルの数）−（巻末が本編の0.5倍を超えた分：0.1倍につき1点）− 0.3 ×（下が4割を超えて空く頁の数）。合格線7。
- 分量比（main）は巻末を除いて数える。だから、巻末の無駄は main には出ない。巻末は上の4つ（中身のない列、巻末どうしの重複、本編に対する比、空く頁）で別に測る。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 同じ要約が3回 | 全体像・章末のまとめ・全体のまとめに、同じ内容 | まとめを機械的に置いた |
| 判例の二重記載 | 判例の事案・結論・理由が、本文と表の両方に同じ文で | 本文を書いてから表を作った |
| 表のセルが本文の文 | セルに本文の文をそのまま入れた | 表を要約に使わなかった |
| 再説明 | 「前述のとおり、…」で、前の節の内容を2〜3文繰り返す | 読者が忘れていると考えた |
| 図題が本文の言い直し | 図の説明文が、直前の段落と同じ | 図題の役目（図の読み方）を外した |
| ざっくり理解が本文と同じ語 | 本文の文を、です・ますに直しただけ | 噛み砕いていない |
| 節の膨らみ | 資料の短い節が、ノートで1.5倍を超える | 表と図題を足した分を、本文で削らなかった |
| 範囲外の加筆 | 資料に無い論点を、補足として長く書く | 知っていることを書いた |
| 中身のない列 | 論点カードの「関連判例」の列が、12行のうち10行で「規範の欄と同じ」「—」 | 「全論点に同じ欄をそろえる」という条件を、埋め草で満たした |
| 巻末どうしの重複 | 論点カードの「短答で問われる形」12問のうち8問が、短答の表の問と同じ知識 | カードと短答の表を別々に作った |
| 1つの論点が2つの表に分かれる | 規範・理由は1枚目、短答・書き出しは2枚目の表（別の頁） | 欄を足すとき、表を足した |
| 空白の多い頁 | まとめ7行だけの頁、表の残り2行だけの頁、図や表を次の頁に送って下が半分空く頁 | 改頁を機械的に入れた。行を切れない表が続いた |

## 3. 9.5 に届く条件

1. 重複率3%以下。
2. 分量（main）が資料の1.15倍以内。超えるなら、どの層が増やしているかを `by_section` で特定し、報告に書く（表・図題の分は増えてよいが、その分だけ本文の言い直しを削る）。上限は1.3倍。
3. まとめは全体の1か所。章末のまとめは置かず、論点カードに置き換える。言い直しの層（まとめ＋全体像）が全体の4%以下。
4. 表と本文の二重記載（50%超重なるセル）が2以下。判例は、本文に書くか表に書くかを決める（`../algorithms/case-placement.md`、`../algorithms/table-or-prose.md`）。
5. 新しい情報の少ない文が2以下。再説明は「前述（12-3-1）」の参照に縮める。
6. 1.5倍を超える節が無い。超える節があるときは、その節の資料の字数が少ない（1000字未満）ために比が出やすいのか、言い直しがあるのかを確かめ、後者なら削る。
7. 削る候補（`cut_candidates`）が0。
8. 巻末：中身のない列が0。巻末どうしの重複が0（同じ問・同じ理由は、一方を番号の参照にする）。巻末が本編の0.5倍以内。1つの論点は1か所で読める（`../ronten-card.md` 1）。
9. 頁：下が4割を超えて空く頁が0（最後の頁を除く）。まとめだけの頁、表の残りの数行だけの頁を作らない。

## 4. 手順

1. 構成の段階で、層ごとの役目を決める：本文＝規律と理由、ざっくり理解＝噛み砕き（本文に無い言い方）、表＝比較・一覧（本文に無い並べ方）、図題＝図の読み方、まとめ＝全体の筋を1か所、巻末の表＝索引。
2. 判例は、4段（事案の型／結論／理由／射程）を1か所に書く。表に入れたら、本文は結論と位置づけだけにする。
3. 書き終えたら `info_efficiency.py -v` を走らせ、削る候補を字数の多い順に削る。
4. 節ごとの分量比を見て、1.5倍を超える節から削る。削るのは、言い直し、二重記載、範囲外の加筆の順。資料の内容（網羅）は削らない。
5. 削った後、網羅（指標⑬）と論証密度（指標⑥）を走らせ直す。理由の文を削っていないかを確かめる。
6. 巻末を作ったら、`info_efficiency.py` の「巻末」の行を見る。中身のない列はやめ、中身のあるセルは隣の欄に移す。重複するセルは、短答の表の番号の参照にする。
7. PDF にして `report_numbers.py --pdf` を走らせ、下が空く頁を直す。直し方は、内容を変えない順に：(a) 図と前後の段落の順を1つ入れ替える（図そのものは変えない）、(b) 4行を超える表は行の間で頁をまたがせ、10行を超える行だけは行の途中で切ってよいことにする、(c) 巻末の表の前の改頁を1回にする（まとめに続けて巻末を始める）、(d) 表の列幅を、いちばん長い欄に合わせて配り直す、(e) ざっくり理解・補足など足した層の文を1行分だけ詰める（意味は変えない）。本文の段落は、最後の行が1〜3字だけのときに、1語を言い換えて1行減らすことまで（内容・確度の語・術語は変えない）。(e) を使ったら、どの文をどう変えたかを直した点の一覧に書く。

## 5. 検査

```
python3 scripts/info_efficiency.py blocks.json --source SOURCE.txt --out checks/efficiency.json -v
python3 scripts/summary_dup_check.py blocks.json --out checks/summary.json
python3 scripts/density.py BODY.txt --source SOURCE.txt --out checks/density.json
python3 scripts/report_numbers.py NOTE.txt --blocks blocks.json --source SOURCE.txt --pdf NOTE.pdf --out checks/numbers.json --md checks/numbers.md --pages-out checks/pages.json
```
見る所：分量比（main・body・all）、節ごとの比、層の間の重複、言い直しの層、削る候補、巻末（字数・本編比・中身のない列・巻末どうしの重複）、頁数と下が空く頁。

注意：表の第1列（行の見出し）と、巻末の表（論点カード・結論一覧・短答・索引・出所表）は、本文と重なるのが役目なので、削る候補にしない。

してはいけない上げ方：資料の内容を削って分量を合わせる。理由の文を削る。ざっくり理解を削る（指標⑧が下がる）。頁を減らすために表の字を小さくする、行間を詰める。

機械が見ないこと：巻末の表が実際に役に立つか（本文に無い情報か、本文の再配列か）。点検者が、巻末の表ごとに読む。

## 6. 良い例・悪い例

- 良い例：本文「判例は、この場合を通常共同訴訟とする（表3の②）。」表3に、事案の型・結論・判決が挙げる理由・資料の説明。
- 悪い例：本文に事案・結論・理由を3文で書き、表3にも同じ3文を入れる。
- 良い例（再説明の代わり）：「この点は、独立の原則（12-3-1）の帰結である。」
- 悪い例：「前述のとおり、通常共同訴訟では、各共同訴訟人は独立して訴訟を追行し、1人の訴訟行為は他の共同訴訟人に影響を及ぼさない。そのため、…」
- 良い例（図題）：「図2　上訴した人としなかった人の地位。実線は上訴人、破線は上訴人にならないが判決の効力を受ける人を示す。」
- 悪い例（図題）：直前の段落の結論を、もう一度文章で書く。
