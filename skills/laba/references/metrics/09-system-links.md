# 指標⑨　体系連関

節と節、制度と制度のつながりが書かれていること。相互参照（⇨、節番号、表・図の参照、前掲）と、他の制度との対比があり、巻末に概念の索引があること。

## 1. 定義と測り方

- 機械だけで測る。
  - `density.py`：相互参照と対比の標識の数（1万字あたり）と資料比。
  - `xref_index.py`：概念の索引（術語→出てくる節）、相互参照の内訳、対比の一覧、節どうしのつながり、孤立した節。資料の ⇨ がノートに残っているか。3つ以上の節に出るのに、どの箇所にも参照がない語（つなぎの候補）。
- 換算：10 ×（資料比 − 0.4）÷ 0.8 − 1.5 ×（資料の ⇨ の欠落の数）− 0.3 ×（参照のない語の数）。合格線6。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 資料の相互参照を落とす | 資料の「⇨12-3-4」が、ノートに無い | 範囲外と考えて削った |
| 参照先が無い | 「前述のとおり」とあるが、どこのことか分からない | 節番号を書かなかった |
| 同じ概念が別々に説明される | 同じ術語が3つの節に出るが、互いを参照しない | 節を独立に書いた |
| 対比が無い | 通常共同訴訟と必要的共同訴訟を、それぞれ単独で説明する | 資料の「これに対して」を落とした |
| 対比の相手が書かれていない | 「これとは異なり、…」の「これ」が、前の節の何を指すか分からない | 指示語で済ませた |
| 孤立した節 | どこからも参照されず、どこも参照しない節 | 発展・コラムを切り離して置いた |
| 索引が無い | 術語がどの節に出るかを探せない | 巻末を論点カードだけにした |

## 3. 9.5 に届く条件

1. 相互参照と対比の数が、資料比1.2以上（1万字あたり）。
2. 資料の ⇨ の欠落が0。範囲外を指す参照は、「（本ノートの範囲外。資料○章）」と書いて残す。
3. 3つ以上の節に出る術語のうち、どこにも参照がない語が0。2回目以降の箇所に、初出の節への参照が1つある。
4. 巻末に概念の索引（術語／出てくる節）がある。語は、2つ以上の節に出るものと、1つの節にしか出なくても次のどれかに当たるもの：資料の見出しの術語、論点カードの論点の術語、短答の命題で問う術語。語の数は機械で数える（`xref_index.py --block` の「索引の表に載せた語」、`derived_check.py --index` の「索引 N 語」）。語が、書かれた節の本文・表に実際に出る（`derived_check.py --index` の所見0）。
5. 対比の文には、比べる相手が語で書かれている（「これ」ではなく「通常共同訴訟」）。資料の対比の箇所の数と、ノートの対比（文または区別表）の数が合う。
6. 孤立した節が、定義だけの節と範囲外の注記を除いて無い。

## 4. 手順

1. 一覧化で、資料の相互参照と「これに対して」「〜とは異なり」の箇所を控える。
2. 本文では、資料の ⇨ をそのまま残す。ノートの節番号が資料と違うなら、ノートの番号に直す。
3. 節を書き終えるごとに、前の節で説明した概念を使った箇所に「（12-3-1）」を添える。「前述のとおり」と書くなら、必ず節番号を付ける。再説明はしない（指標⑪）。
4. `xref_index.py --block xref_blocks.json` で索引の表を作り、巻末に足す。語の一覧を見て、術語でないもの（一般の語）を除く。論点カードの論点と短答の命題に出る術語を `--terms` で渡す（1つの節にしか出ない語も載る。表にしか出ない語も、表のある節として載る）。語を人が選ぶときは `--only-terms` を付ける。`--terms` の語がどの節にも出ないときは WARN が出るので、載せたことにしない。
5. 「つなぎの候補」を1語ずつ見て、参照を足す。

## 5. 検査

```
python3 scripts/xref_index.py blocks.json --source SOURCE.txt --out checks/xref.json --md checks/xref.md --block xref_blocks.json -v
```
見る所：資料の ⇨ の欠落、つなぎの候補、孤立した節、対比の一覧（比べる相手が語で書かれているか）、索引の表に載せた語の数と、`--terms` の語で載らなかったもの。

甘くなりやすい所：索引は「あるか」だけでは足りない。論点カードの論点・短答で問う術語が索引に無ければ、索引として使えない。語の数を報告するときは、機械の出力を写す。

してはいけない上げ方：意味のない「（前述）」を散らす。対比の標識（「これに対して」）を、対比でない文に付ける。参照は、読者がそこへ戻ると理解が進む箇所にだけ置く。

## 6. 良い例・悪い例

- 良い例：「必要的共同訴訟では、通常共同訴訟（12-3-1）とは異なり、1人がした訴訟行為は、全員の利益になる限りで全員に効力を生ずる（40条1項）。」
- 悪い例：「前に述べたのとは異なり、ここでは全員に効力が生ずる。」→ 何と比べているのか、どこを見ればよいのかが分からない。
- 良い例（範囲外の参照）：「補助参加人の地位（⇨第13章。本ノートの範囲外）との違いは、…」
- 良い例（索引の1行）：「合一確定｜12-1、12-4-1、12-4-3、12-4-5」
