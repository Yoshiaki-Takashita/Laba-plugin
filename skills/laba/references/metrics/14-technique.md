# 指標⑭　説明技法（基本指標・15点）

`../techniques.md` の12項目（整理軸／規範の直後に記号事例／理由は利益で／判例は4段／制度は6段／区別表／反例／確度の語／段落の組み方／二重記載の禁止／相互参照と境界／接続語の用途）が、全体で一貫して使われていること。

## 1. 定義と測り方

- 点を付けるのは点検者。各項目0〜2点（0＝ない、1＝一部、2＝一貫している）。根拠として、ノートの短い引用を付ける。24点満点を15点に換算。合格線20点。
- 機械は、いくつかの項目の形を補助する。

| 技法 | 機械の補助 | 見る値 |
|---|---|---|
| 2 記号事例 | density、argument_check | 具体例密度、例のない規範の段落 |
| 3 理由は利益で | argument_check | 論証密度、理由のない段落（誰の利益かは見ない） |
| 4 判例は4段 | reason_source_check、reason_table | 出所の書き分け |
| 6 区別表・7 反例 | xref_index | 対比の一覧 |
| 8 確度の語 | certainty_check | 保存率 |
| 9 段落の組み方 | argument_check、style_check | 段落の型、段落あたりの文数 |
| 10 二重記載の禁止 | info_efficiency、summary_dup_check | 層の間の重複 |
| 11 相互参照 | xref_index | 資料の ⇨ の欠落、つなぎの候補 |
| 12 接続語 | style_check、word_swap_check | 接続語で始まる文の率、置き換えの型 |
| 1 整理軸・5 制度は6段 | なし | 点検者が読む |

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 一部の節だけで使う | 前半は規範の直後に例があるが、後半は規範だけ | 後半で分量を詰めた |
| 整理軸が置かれるだけ | 章の冒頭に表はあるが、各節で「軸のどこか」を確かめていない | 表を作って終わった |
| 制度の節が要件から始まる | 問題の具体例・従来の対処・その限界が無い | 条文の順に書いた |
| 反例が無い | 通説の説明だけで、当てはまらない場合が無い | 資料の「もっとも」を落とした |
| 区別表に「同左」 | セルを空けた | 対比の軸が合っていない |
| 接続語の誤用 | 「したがって」が、帰結でない文に付く | 文をつなぐために置いた |

## 3. 9.5 に届く条件（24点中23点以上）

1. 12項目のうち11項目以上が2点（一貫している）。1点の項目は1つまで、0点が無い。
2. 作成者が、項目ごとに「どの節で使ったか」の対応表を作っている（空欄の節が、なぜ空欄かを説明できる）。
3. 上の表の機械の値が、それぞれの指標の9.5の条件を満たしている（⑥⑦⑨⑪、④、文体）。
4. 点検者が、根拠の引用つきで23点以上を付けている。

## 4. 手順

1. 構成の段階で、節ごとに使う技法を決める（制度の節は6段、判例の節は4段、対比のある節は区別表）。
2. 本文を書き終えたら、`../techniques.md` の各項目の「検査」を、節ごとに当てる。
3. 対応表を作る：行＝技法、列＝節。使っていれば○。
4. 機械の検査で補助の値を見て、低い項目の節を直す。
5. 点検者に、対応表は渡さない（自己評価に当たる）。点検者は、ノートだけを読んで採点する。

## 6. 良い例・悪い例

- 良い例（制度は6段）：「XがY1とY2のどちらかに請求できるが、どちらかは分からない、という場合がある（問題）。別々に訴えると、両方で負けることがあり得る（従来の対処と限界）。そこで、…という制度が設けられた（新制度）。要件は…（要件）。申出を原告に限るのは…からである（各要件の理由）。」
- 悪い例：「同時審判の申出の要件は、①…、②…、③…である。」から始まる。
- 良い例（整理軸の確認）：各節の冒頭に「この類型は、表1の右上（合一確定が必要で、全員が当事者になる必要はない場合）に当たる。」
