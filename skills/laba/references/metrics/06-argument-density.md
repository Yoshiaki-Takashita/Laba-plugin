# 指標⑥　論証密度

規律や結論に、理由が付いている割合。本文だけでなく、足した層（全体像・ざっくり理解・まとめ・図題）にも理由があること。

## 1. 定義と測り方

- 機械だけで測る。
  - `argument_check.py`：段落ごとに、文を5つの働き（主題／理由／例／帰結／限定）に分ける。層ごとの論証密度（理由の標識を含む文の割合）、理由のない本文段落、足した層で理由の文が1つもない塊、理由のない「（補足）」を出す。資料があれば、節ごとに資料と比べる。
  - `density.py`：本文テキスト全体の論証密度（層を見ない簡易な値）。
- 理由の標識：からである／ためである／という理由／ので／ため、／ことから／以上、／趣旨である／に基づく／根拠。ざっくり理解では「からです／ためです」も数える。
- 換算：10 ×（地の文全体の密度 ÷ 資料の密度 − 0.5）÷ 0.5 − 0.5 ×（足した層で理由のない塊の数）− 0.25 ×（理由のない補足の数）。資料が無いときは、密度 ÷ 2.5 から同じ減点。合格線7。
- 「地の文全体」は、本文＋ざっくり理解・全体像＋まとめ。表・図題・巻末の表は分母に入れない（セルは理由を書く場所ではないため）。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 足した層に理由がない | 全体像が「Aは…です。Bは…です。Cは…です。」と結論だけを並べる | 要約として書いた |
| まとめが結論の列挙 | 全体のまとめに「〜である。〜である。」が続く | 本文の主題文だけを集めた |
| 本文で理由を落とす | 資料「…できない。なぜなら…からである。」→ ノート「…できない。」 | 分量を減らした |
| 理由を表に移して本文から消す | 判例の理由が表にだけあり、本文は結論だけ | 二重記載を避けようとして削りすぎた |
| 補足に根拠がない | 「（補足）この場合も同じ扱いになる。」 | 足した命題に理由を付けなかった |
| 標識だけを足す | 「…である。これは重要だからである。」 | 数値を上げようとした |
| 節ごとの偏り | ある節だけ、資料より5ポイント低い | その節を表中心で書いた |

## 3. 9.5 に届く条件

1. 地の文全体の論証密度が、資料の −1 ポイント以内（比で0.975以上）。
2. 足した層（ざっくり理解・全体像・まとめ）で、理由の文がない塊が0。各塊に「なぜそうなるのか」が少なくとも1文ある。
3. 「（補足）」で始まる文・段落の全部に、根拠（条文、判例、資料の箇所、または理由の文）がある。
4. 資料より3ポイントを超えて低い節が無い。
5. 理由のない本文段落（`argument.json` の `paragraphs_without_reason`）を全部読み、資料の対応箇所に理由があるのにノートで落としたものが0（資料自体に理由が無い段落、定義だけの段落は、そのままでよい）。
6. 理由の文に、誰の利益かが書かれている（`techniques.md` 3）。

## 4. 手順

1. 本文は、段落を［主題文→理由→例→限定］で組む（`techniques.md` 9）。資料の理由文は、言い回しを変えても、落とさない。
2. 理由を表に書くときは、本文にも1文で理由を残し、表は詳細に回す。
3. ざっくり理解を書くとき、段ごとに「〜からです」「〜ためです」の文を1つ入れる。入れられないなら、その段は結論の言い直しになっている。削るか、理由を書く。
4. 全体のまとめは、結論を並べず、「AはBである。CだからDとなるためである。」のように、結論と理由を組で書く。
5. `argument_check.py` を走らせ、足した層の塊と、理由のない本文段落を読む。資料と照らして、落とした理由を戻す。

## 5. 検査

```
python3 scripts/argument_check.py blocks.json --source SOURCE.txt --out checks/argument.json -v
```
見る所：「層ごとの論証密度」「資料との差」「足した層の塊」「理由のない本文段落」「補足」。節ごとの WARN。

してはいけない上げ方：文末に「からである」を付けるだけ。理由の中身が、前の文の言い直しになっていないかを読む。標識の数ではなく、「なぜそう言えるのか」に答えているかで判断する。機械は標識しか見ないので、点検者（点検B）が意味を見る。

## 6. 良い例・悪い例

- 良い例（本文）：「申出をすることができるのは、原告に限られる。この制度は、原告が両方の請求で敗訴する危険に対処するためのものだからである。被告の側には、弁論が分離されないことについて独自の利益がない。」
- 悪い例（本文）：「申出をすることができるのは、原告に限られる。」
- 良い例（ざっくり理解）：「申出ができるのは原告だけです。両方で負ける危険を負うのは原告だからです。」
- 悪い例（ざっくり理解）：「申出ができるのは原告だけです。控訴審の口頭弁論が終わるまでにする必要があります。」（結論が2つ並ぶだけ）
- 悪い例（標識だけ）：「申出ができるのは原告だけである。これは、原告だけが申出をすることができるとされているからである。」
