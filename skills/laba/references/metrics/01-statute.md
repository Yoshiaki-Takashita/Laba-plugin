# 指標①　条文の正確さ

条番号・項号・本文とただし書・要件（限定の語）・効果・名宛人・改正の前後が、現行の条文と一致していること。

## 1. 定義と測り方

- 点を付けるのは点検者。現行の条文（e-Gov 法令検索、またはコネクタの `law_get_article`）と1件ずつ照らす。
- 機械は一覧と候補を出すだけである。`statute_check.py` が、ノートに出る条文の一覧（`statute.md`）、同じ条文に向きの違う説明がある組（食い違いの候補）、法令名が補えない条文を出す。`yoken_table.py` が、要件と効果の形になっている文を並べ、効果が言い切りでない行を出す。
- 換算：誤り0＝10点。軽微1件ごとに−0.5、中1件で−3、重大（要件・効果の取り違え）1件で−6。合格線8。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 限定の語が落ちる | 「控訴審でも弁論は併合される」（「同一の控訴裁判所に各別に係属するとき」が無い） | 資料の要約をさらに縮めた |
| 名宛人の取り違え | 子会社に向けた禁止を、親会社の取締役の義務として書く | 条文の主語を見ていない |
| 項・号のずれ | 2項の規律を1項として引く。前段と後段を区別しない | 資料の「同条」を追わなかった |
| 改正前の番号・用語 | 資料や判決が改正前のもので、そのまま写した | 現行の条文を見ていない |
| 効果の強さが変わる | 「できる」を「しなければならない」に、「推定する」を「みなす」に | 言い換えた |
| 箇所による食い違い | 本文は「全員の利益においてのみ」、表は「全員に効力が及ぶ」 | 本文・表・図・カードを別々に書いた |
| 準用の読み替え | 準用される条文を、読み替えなしで当てはめた | 準用規定を読んでいない |

## 3. 9.5 に届く条件

1. `statute.md` の全件について、現行の条文と照らした記録がある（照合した日、法令名、条・項、照らした結果）。照らしていない条文が1件でもあれば、報告に列挙する。
2. 食い違いの候補を全部読み、「原則と例外の書き分け」か「食い違い」かを1件ずつ記録している。食い違いは0。
3. 法令名なしの条文が0（ノートの冒頭に「条文は特に断りのない限り○○法」と書き、他の法令は名前を付ける）。
4. 条文を要約した文に、限定の語（主体・場合・時期・範囲）が残っている。落とした語が無いことを、条文と並べて確かめている。
5. 図・表・論点カード・短答の命題に出る条文の表記と中身が、本文と同じである。
6. 点検者の点検で、条文の誤りが0。

## 4. 手順

1. 一覧化の段階で、資料に出る条文を全部控える（`inventory.py`）。
2. 本文を書くとき、条文は要約せずに一度原文を置いてみてから、落とせる語だけを落とす。迷う語は残す。
3. 書き終えたら `statute_check.py` を走らせ、`statute.md` の表を上から順に、現行の条文と照らす。照らした結果を表の右の欄に書く。
4. 食い違いの候補は、両方の文を読む。原則と例外なら、それが読者に分かる書き方かを確かめる。
5. 改正がある条文は「旧○条（現○条）」と書き、規律が変わっていないかも確かめる（`statute-verification.md` 6）。

## 5. 検査

```
python3 scripts/statute_check.py NOTE.txt --default-law 民事訴訟法 --out checks/statute.json --md checks/statute.md
python3 scripts/yoken_table.py blocks.json --check --out checks/yoken.json --md checks/yoken.md
```
見る所：`statute.md` の件数と自分の照合記録の件数が合うか。「食い違いの候補」「法令名なし」「効果が言い切りでない行」。機械は、条文の中身が正しいかどうかは見ない。

## 6. 良い例・悪い例

- 良い例：「各共同被告に係る控訴事件が同一の控訴裁判所に各別に係属するときは、弁論および裁判は、併合してしなければならない（民事訴訟法41条3項）。」
- 悪い例：「控訴審でも、弁論は併合される（41条3項）。」→ 同一の控訴裁判所に係属する場合に限られること、各別に係属する場合の規律であることが落ちている。
- 良い例（食い違いの候補への対応）：本文に「共同訴訟人の1人がした訴訟行為は、全員の利益においてのみ効力を生ずる（40条1項）。したがって、不利な行為は、全員がしなければ効力を生じない。」と、原則と帰結を続けて書く。
- 悪い例：本文に「効力を生ずる（40条1項）」、表に「効力を生じない（40条1項）」とだけ書き、どの場合の話かが別々の箇所に分かれている。
