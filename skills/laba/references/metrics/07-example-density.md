# 指標⑦　具体例密度

規範・定義・区別に、事例が付いている割合。事例が、規範の構成要素に対応していること。

## 1. 定義と測り方

- 機械だけで測る。`density.py` が、例示の型（たとえば／という場合／を例にとると／がこれに当たる／X・Y などの当事者記号）を含む文の割合を出す。資料があれば資料比。`argument_check.py` は、段落ごとに「例」の働きの文があるかを出す。
- 換算：10 ×（資料比 − 0.5）÷ 0.6。資料比1.1以上＝10、0.8＝5。資料が無いときは、密度 ÷ 2.0。合格線7。
- 資料より例が多いことが、ノートが資料を上回る数少ない経路の一つである（もう一つは⑧）。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 規範だけで終わる | 「各共同訴訟人は独立して訴訟を追行する。」 | 資料が例を別の頁に置いていた |
| 例が規範から遠い | 規範の3段落後に例が出る | 資料の順のまま書いた |
| 例が構成要素に対応しない | 要件が3つあるのに、例は1つの要件だけを示す | 例を1つで済ませた |
| 記号が節ごとに変わる | 12-3 では X・Y、12-4 では A・B で同じ事例 | 節を別々に書いた |
| 当たらない例がない | 定義に当たる例だけで、境界の外の例がない | 反例を置かなかった |
| 資料の例を落とす | 資料の設例を、要約で消した | 分量を減らした |
| 例に結論がない | 「XがYを訴えた場合はどうか。」で終わる | 帰結を書かなかった |

## 3. 9.5 に届く条件

1. 具体例密度が資料比1.1以上。
2. 資料の事例（設例、当事者記号つきの例）が全部ノートにある（網羅の一覧で確かめる）。
3. 規範・条文の文の次の2文以内に、例の文がある。例外は、定義だけの段落と、直前の段落の例をそのまま使う場合。
4. 例の帰結が、①②③で列挙され、規範の構成要素（要件・効果）のそれぞれに1つ以上対応している。
5. 同じ事例を、節をまたいで同じ記号で使い回している（記号の対応を、初出で書く）。
6. 定義・区別の節に、当たる例と当たらない例が組で置かれている。

## 4. 手順

1. 一覧化で、資料の事例を全部控える（記号、事実、資料が示す帰結）。
2. 章の冒頭で、基本の事例を1つ決める（「X1・X2 が Y を訴える」「X が Y1・Y2 を訴える」）。以後の規範は、できるだけこの事例で説明する。
3. 規範を書いたら、直後に「たとえば、…という場合、①…、②…。」を置く。
4. 資料に例が無い規範には、例を足して「（補足）」を付ける。足した例の帰結が規範から一義的に出るかを確かめる。出ないなら足さない（`added-text-safety.md`）。
5. `density.py` で資料比を見る。低ければ、`argument_check.py -v` で「例のない段落」を読み、規範の段落から順に例を足す。

## 5. 検査

```
python3 scripts/density.py BODY.txt --source SOURCE.txt --out checks/density.json
python3 scripts/argument_check.py blocks.json --source SOURCE.txt --out checks/argument.json -v
```
見る所：具体例密度と資料比。段落の型のうち、主題と帰結だけで例のない段落。

してはいけない上げ方：当事者記号を文に散らすだけ。足した例の帰結を、確かめずに書く（足した例の誤りは、指標⑮で重く減点される）。

## 6. 良い例・悪い例

- 良い例：「共同訴訟人の1人がした訴訟行為は、他の共同訴訟人に影響を及ぼさない（39条）。たとえば、X1 と X2 が Y を訴えた場合、① X1 が請求を放棄しても、X2 の請求には影響がない、② Y が X1 との関係でだけ自白しても、X2 との関係では証明が要る、③ X1 だけが控訴すれば、X2 の請求についての判決は確定する。」
- 悪い例：「共同訴訟人の1人がした訴訟行為は、他の共同訴訟人に影響を及ぼさない（39条）。これを共同訴訟人独立の原則という。」
- 良い例（当たらない例）：「これに対して、X1 が提出した証拠から得られた心証は、X2 の請求の判断にも使われる。これは、X1 の訴訟行為の効力が X2 に及ぶのではなく、同じ事実についての裁判所の心証が1つだからである、と説明される。」
