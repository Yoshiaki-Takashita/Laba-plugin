# 指標②　判例書誌の正確さ

裁判所・裁判の種別（判決／決定）・年月日・登載誌・巻号頁が正しく、表記が全体で揃っていること。

## 1. 定義と測り方

- 機械：`cite_check.py` が書誌の形式（和暦、中黒、登載誌の略称、巻号頁の形、前掲の先）と、同じ判例の表記ゆれを見る。`coverage_check.py` が、資料の書誌とノートの書誌の食い違いを出す。
- 実在と一致の確認：`case_lookup.py`（裁判所の裁判例検索）で、日付から候補を取り、登載誌の巻号頁が一致するかを見る。コネクタがあれば `case_verify_citation`。
- 点検者：抜き取りで原典と照らす。機械の誤検知があれば補正した点を付ける。
- 換算：10 − 2×（形式の所見の数）− 3×（資料との食い違いの数）。合格線9。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 登載誌の取り違え | 刑事事件に「民集」、民集に載らない判決に「民集」 | 記憶で補った。資料の誤記を写した |
| 年・巻・頁の誤り | 昭和と平成、巻と号の入れ替わり、頁の1桁違い | 書き写しの誤り |
| 種別の取り違え | 決定を「最判」、大法廷を「最判」 | 資料の略記を確かめなかった |
| 表記ゆれ | 本文は「昭和43・3・15」、表は「昭和43年3月15日」 | 層ごとに別に書いた |
| 前掲の先が無い | 「前掲最判…」が、初出より前にある | 段落を入れ替えた |
| 書誌の省略 | 2回目以降に登載誌を省き、どの判決か分からない | 短くした |

## 3. 9.5 に届く条件

1. `cite_check.py` の所見0、資料との食い違い0。
2. ノートに出る全判例について、実在と書誌を原典（裁判所の裁判例検索、判例集）で確かめた記録がある。確かめられなかった判例（大審院、登載誌が雑誌だけのもの等）は、「当たれない」として報告に列挙する。実在しないとは書かない。
3. 同じ判例の表記が、本文・表・図・論点カード・短答の命題で同じである。
4. 資料の書誌に誤記があったときは、ノートは正しい形で書き、報告に「資料の誤記」として挙げている。

## 4. 手順

1. 一覧化で、資料の判例を全部控える（裁判所、年月日、登載誌、巻号頁）。
2. 書誌は、控えた一覧から写す。記憶で書かない。本文に初めて出る箇所で完全な書誌を書き、以後は「前掲最判昭和43・3・15」の形にする。
3. `cite_check.py` を走らせ、所見を1件ずつ直す。
4. `case_lookup.py 年月日 --save DIR` で、日付から裁判所サイトの詳細ページと全文を取り、巻号頁が一致するかを見る。1件ずつ、間隔を空けて取る。取れた全文は、指標③の照合に使う。

## 5. 検査

```
python3 scripts/cite_check.py NOTE.txt --inventory checks/inventory.json --out checks/cite.json
python3 scripts/case_lookup.py 昭和43・3・15 --save work/fulltext          # 1件ずつ。--from-note NOTE.txt でノート中の判例を順に引く
```
見る所：所見の数、「資料と違う書誌」の一覧、判例の件数（資料の件数と合うか）。

## 6. 良い例・悪い例

- 良い例：初出「最判昭和43・3・15民集22巻3号607頁」、2回目以降「前掲最判昭和43・3・15」。表でも同じ表記。
- 悪い例：本文「最判昭43.3.15」、表「最高裁昭和43年3月15日判決」、カード「昭和43年判決」。同じ判決かどうかを読者が照合しなければならない。
- 悪い例：確かめられなかった判決を「判例は存在しない」と書く。→「裁判所の裁判例検索では確認できなかった。原典で確認してほしい」と書く。
