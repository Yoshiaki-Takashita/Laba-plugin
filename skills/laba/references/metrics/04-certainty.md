# 指標④　確度の保存率

資料が留保を付けて書いたこと（余地がある、不明確である、要請されよう、有力である等）が、ノートでも同じ強さで書かれていること。

## 1. 定義と測り方

- 機械（資料→本文）：`certainty_check.py` が、資料の留保つきの文を拾い、節で絞ってノートの対応文を探し、留保が保たれたか・弱まったか・強まったかを出す。ブロック（.json／.py）を渡すと、足した層（ざっくり理解・図題・表・論点カード）で留保を落とした候補も出す。
- 機械（本文→派生物）：`derived_check.py` が、論点カードの各欄・短答の命題・まとめの文を、根拠にした本文の節の、最も近い文と照らす。本文の文に留保の語があるのに、行の文に留保の語が一つもないとき、「留保の脱落」（強い留保）か「断定になっている」（とされる・と考えられている）を出す。除外の一覧は無い。
- 点検者：「見当たらない」とされた文を読み、対応づけの誤りなら補正する。
- 換算：（保存率 − 50）÷ 5。保存率100%＝10、95%＝9、75%＝5。派生物の「留保の脱落」「断定になっている」は、1行につき1点を引く。合格線7。

確度の4段階（`techniques.md` 8）：1＝留保が強い（不明確、議論がある）／2＝留保（余地がある、であろう、有力）／3＝通説・多数説（と解される）／4＝確定（条文、判例）。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 留保が消える | 資料「…と解する余地がある」→ ノート「…と解される」 | 文を短くした |
| 言い切りになる | 資料「運用上、…が要請されよう」→ ノート「…は禁止される」 | 噛み砕くときに強めた |
| 足した層で落とす | 本文は「射程は不明確」、ざっくり理解は「〜には及びません」 | 平易に書くとき、留保を省いた |
| 表・カードで落とす | 当てはめの欄に結論だけ書き、「余地がある」が無い | セルを短くした |
| 短答の命題で落とす | 議論のある点を○×で言い切った | 命題を作るとき、確度を見なかった |
| 見解の出所が消える | 資料の筆者の見解を、通説のように書いた | 「〜と考える」を落とした |
| 強まる（逆向き） | 判例が確定している点に「と考えられる」を付けた | 自信が無かった |
| 派生物で断定になる | 本文「この関係にあるとされるのに対し、…この関係にはないと考えられている」→ カードの当てはめ「…これに当たる。…にとどまる」。同じ点を問う短答は「考えられている」を保っていた | カードの欄を本文から短く写すとき、文末だけを落とした。資料→本文の検査は通るので、気づかない |

## 3. 9.5 に届く条件

1. 保存率95%以上。「弱まった」「見当たらない」を1件ずつ読み、落としていたものは戻している。
2. 足した層の候補が0（層つきの検査で、留保のある術語を含むのに留保の語がない文が無い）。
2-2. 派生物の照合（`derived_check.py`）で、「留保の脱落」「断定になっている」が0。論点カード・短答の全部の行に、根拠にした本文の節（`section`）が書いてある。
3. 論点カードの「当てはめの要点」と、短答の命題の根拠の欄に、本文と同じ確度の語がある。議論のある点は、短答の命題にしないか、「〜とする見解が有力である」という形の命題にする。
4. 資料の筆者の見解は、「（資料の見解）」「〜とされる」で出所を示している。
5. 判例・条文で確定している点に、不要な留保を付けていない。

## 4. 手順

1. 一覧化の段階で、資料の留保の語がある文に印を付ける（`certainty_check.py SOURCE NOTE -v` の一覧が使える）。
2. 本文を書くとき、その文の文末は資料の語のまま書く。文を分けるときは、留保の語を、結論を述べる側の文に残す。
3. ざっくり理解に移すときは、です・ますに直すだけで、留保は残す（「〜と考える余地があります」）。
4. `certainty_check.py` を、全文テキストとブロックの両方で走らせる。
5. 「見当たらない」は、資料の文とノートの対応箇所を並べて読む。誤検知（対応づけが別の文に当たった）なら、理由を控える。
6. 論点カード・短答・まとめを書いたら、`derived_check.py` を回す。所見が出た行は、該当箇所の本文の文末（とされる／と考えられている／余地がある）をそのまま行に戻す。字数が足りなければ、ほかの語を削る。留保の語を削って収めない。
7. 除外の一覧（`--certainty-ignore`）は、足した層の候補のうち、読んで別の点を述べた文だと確かめたものに限って使う。使った件数と理由は報告に書く。派生物の検査には除外の仕組みが無いので、行を書き直す。

## 5. 検査

```
python3 scripts/certainty_check.py SOURCE.txt NOTE.txt --out checks/certainty.json -v
python3 scripts/certainty_check.py SOURCE.txt blocks.json --out checks/certainty_layer.json -v
python3 scripts/derived_check.py blocks.json --cards cards.json --tf items.json --index index.json --out checks/derived.json -v
```
見る所：保存率、「弱まった」の一覧、「足した層の候補」、派生物の保存率（該当箇所に留保のある行のうち、留保が保たれた行）と所見。短答の命題の確度は `derived_check.py --tf` が見る（`tf_items.py` の節単位の注意と、作成者が理由を書いて除く `certainty_note` はやめた）。

甘くなりやすい所：除外の一覧は作成者が書ける。点検者は、除いた文と理由（`certainty.json` の `layer_ignored`）を読む。派生物の検査の対応づけは術語の重なりによる近似なので、所見0でも、点検者はカードの「当てはめの要点」と短答の命題を本文と並べて読む。

## 6. 良い例・悪い例

- 資料の文（例）：「もっとも、この規律が類似の場面にも及ぶかは、なお明らかではない。」
- 良い例（本文）：「この規律が類似の場面にも及ぶかは、明らかではない。」
- 良い例（ざっくり理解）：「似た場面にも同じ扱いが及ぶかどうかは、まだはっきりしていません。」
- 悪い例：「この規律は、類似の場面にも及ぶ。」（言い切り）
- 悪い例：「類似の場面には及ばない。」（逆向きの言い切り）
- 悪い例（短答の命題）：「○：この規律は、類似の場面にも及ぶ。」→ 正誤を決められない点を問うている。
