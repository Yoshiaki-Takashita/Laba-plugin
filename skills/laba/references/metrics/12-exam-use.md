# 指標⑫　答案転用性

要件・効果・結論が、答案にそのまま使える形で書かれていること。論述（規範を示して当てはめる）と、短答（正誤を判断する）の両方に使えること。

## 1. 定義と測り方

- 点を付けるのは点検者。機械は、形を補助する。
  - `card_build.py --check-only`：論点カードの5欄（論点／問題の所在／規範／理由／当てはめの要点）と、答案での使い方の2欄（短答で問われる形／論述での書き出し）の形、根拠の節（`section`）があるか。`--note` で、規範・判例の表記が本文と同じかを見る。`--tf` で、カードの短答が短答の表の問と重なっていないか、参照（→短答N）の番号があるかを見る。
  - `derived_check.py`：カードの各欄と短答の命題・根拠を、根拠にした本文の節の最も近い文と照らす。根拠の条文が本文の該当箇所と合うか（本文が「〜は働かない」と書いた条文を根拠に挙げていないか）、本文の留保が落ちていないか。
  - `tf_items.py`：短答式の命題の一覧を、本文から候補として拾い（`candidates`）、仕上げた一覧を検査する（`check`）。
  - `yoken_table.py --check`：本文から、条文つきの規律を「要件／効果」に分けた候補を出し、効果が言い切りでない行、条文番号のない行を出す。
- 換算（点検者の目安）：全ての制度・設例で使え、論点カードと短答の命題が検査を通っている＝10。論点カードはあるが、当てはめの欄が一般論にとどまる＝7。本文に規範はあるが、答案の形になっていない＝5。合格線7。

## 2. 減点された実例の型

| 型 | 例 | 原因 |
|---|---|---|
| 結論が言い切られていない | 設例の結論が「〜と考えられる」で終わる | 資料が結論を示していなかった |
| 要件が番号になっていない | 要件が地の文に溶けていて、数えられない | 資料の文をそのまま使った |
| 規範に根拠がない | 規範の欄に、条文番号も判例もない | 一般論を書いた |
| 当てはめが一般論 | 「事案に応じて判断する」 | 先に見る事実を特定しなかった |
| 書き出しが問題提起で止まる | 「〜が問題となる。」だけ | 規範まで言い切っていない |
| カードが本文と違う | カードの規範と、本文の規範の文言・書誌が違う | 別々に書いた |
| 短答の × が単純な否定 | 本文の文の文末を「ない」にしただけ | 入れ替えの軸を選ばなかった |
| ○× の偏り | ○が8割 | 本文の文をそのまま並べた |
| 議論のある点を言い切る | 資料が「不明確」とする点を、○×の命題にした | 確度を見なかった |
| 本文にない知識を問う | 命題の根拠が、ノートのどこにもない | 知識から作った |
| 根拠の条文がずれる | 正誤は正しいが、根拠の欄に、本文が「働かない」と書いた側の条文を挙げた（結論を導くのは別の条文） | 命題と同じ段落に出てくる条文番号を、役割を確かめずに写した |
| 命題に前提が足りない | 「一方だけが控訴した場合」とだけ書き、第1審の結論（一方認容・他方棄却）が命題に無い | 本文の設例を前提にして、命題だけを抜いた |
| 資料の書き方と衝突する問 | 判決文に照らせば × だが、資料は判例を引いた直後に「…という理由である」と書いている点を問う。資料で学ぶ読者には引っかけになる | 判決文で確かめたことを、そのまま問にした。本文の該当箇所の書き方と照らしていない |
| カードが2か所に分かれる | 規範と書き出しが別の表・別の頁にある | 欄を足すとき、表を足した |
| 埋め草の欄 | 「関連判例」の列が「規範の欄と同じ」「—」で埋まる | 全論点に同じ欄をそろえる条件を、形だけ満たした |
| 読みにくい命題 | 「〜する立場によれば，通説上，〜となる」（前提が二重） | 1文に収めるために語を重ねた |

## 3. 9.5 に届く条件

1. 巻末に論点カードがある（8〜12論点。資料20頁の場合）。基本の5欄が全部埋まり、規範に条文番号か判例の書誌がある。`card_build.py` の所見0。
2. 論点カードに、答案での使い方の2欄がある（全論点にそろえる）。1つの論点は1つの行（1か所）で読める。表を2つに分けない。
   - 短答で問われる形：「○：…」か「×：…（誤りは…）」の1文。短答の表に同じ知識を問う問があれば、文を書かずに「→短答N」と番号で示す。
   - 論述での書き出し：答案の最初の1〜2文。問題の所在を受けて、規範を言い切る。条文番号か判例の立場を含む。
   - 「関連判例」の列は作らない（規範の欄にない判例は、当てはめの要点に書く）。中身のない欄を「—」「同じ」で埋めない。
2-2. カードと短答の全部の行に、根拠にした本文の節（`section`）がある。`derived_check.py` の所見0（根拠の条文が本文の該当箇所と合う、留保が落ちていない）。
3. 巻末に短答式の命題の一覧がある（20〜30問。資料20頁の場合）。各問に、正誤・根拠（条文、判例、節）があり、× には「どこが誤りか」がある。× が30〜60%。同じ節に4問を超えて集中しない。`tf_items.py check` の所見0（誤検知は、1件ずつ読んで理由を控える）。
4. 短答の命題は、ノートの本文にある知識だけを問う。確度に留保のある点は、命題にしないか、留保ごと命題にする。
4-2. 根拠の欄には、その結論を導く条文・判例を書く。本文が「この条文は働かない」「この条文によるのではない」と書いた条文を、根拠として挙げない（挙げるなら「○条は働かない」と書く）。
4-3. 命題は、それだけで正誤が決まるように前提を書く（設例の事実関係、どの審級の話か）。判決文で確かめた点を問うときは、本文の該当箇所の書き方と照らし、資料の記述と衝突する問（資料で学んだ読者が誤答する問）にしない。
5. 本文の要件は、番号つきで数えられる。効果は言い切り。`yoken_table.py --check` の所見を全部読んでいる。
6. 設例があれば、結論が言い切られ、結論一覧表（ケース／問い／結論／決め手）がある。
7. 点検者が、答案に使えるかを見て9.5以上を付けている。

## 4. 手順

1. 本文を書くとき、要件は「第1に」「第2に」または①②で並べ、条文番号を付ける。効果は「〜できる」「〜できない」「効力を生じない」で終える。
2. `yoken_table.py blocks.json --md yoken.md` で候補を出し、論点カードの規範の欄の下書きにする。
3. `cards.json` を書く（`../ronten-card.md`。拡張の欄は同 7）。規範・判例は、本文から写す。
4. `tf_items.py candidates blocks.json --out tf_candidates.json` で候補を出す。候補から、節が偏らないように20〜30問を選び、半分ほどを × にする。× は、入れ替えの軸（できる↔できない、全員↔各自、原則↔例外、主体、時期）を1つだけ入れ替える。2か所を変えない。
5. `tf_items.py check items.json --note blocks.json` で検査し、`tf_items.py block` で巻末の表にする。
5-2. `derived_check.py blocks.json --cards cards.json --tf items.json` を回す。所見が出た行は、行の文・根拠・節を本文に合わせて直す。
6. 論点カードと短答の表は、本文の後、全体のまとめの後に、改頁して置く。

## 5. 検査

```
python3 scripts/card_build.py cards.json --check-only --note blocks.json --tf items.json
python3 scripts/tf_items.py check items.json --note blocks.json --out checks/tf.json
python3 scripts/derived_check.py blocks.json --cards cards.json --tf items.json --out checks/derived.json -v
python3 scripts/yoken_table.py blocks.json --check --out checks/yoken.json --md checks/yoken.md
```
`pipeline.py --cards cards.json --tf items.json` でまとめて回る。見る所：カードの所見と注意（短答の表と近い問）、短答の数・×の割合・節の偏り・根拠、派生物の照合の所見（条文・留保・根拠の節）、要件・効果の所見。

機械の限界：命題の正誤そのものは、機械には分からない。○×と根拠は、条文・判決文で確かめる。カードの短答と短答の表の重なりは術語の重なりで測る近似で、言い方が違えば拾えない（注意に出た組と、出なかった組も、点検者が同じ知識かを読む）。設問として適切か（引っかけになっていないか、事例の形の問いがあるか）は、点検者が読む。

甘くなりやすい所：× の作り方を「本文の語を1か所入れ替える」だけにすると、事例の形の問いが出てこない。設例のある資料では、設例の事実を使った問を数問入れる。

## 6. 良い例・悪い例

- 良い例（論述での書き出し）：「共同被告の一方に対する請求と他方に対する請求とが法律上併存し得ない関係にあるときは、原告は、同時審判の申出をすることができる（41条1項）。本件の両請求がこの関係にあるかを検討する。」
- 悪い例：「本件では、同時審判の申出ができるかが問題となる。」（規範が出ていない）
- 良い例（短答、×）：「× 同時審判の申出は、第一審の口頭弁論の終結の時までにしなければならない。（誤りは時期。控訴審の口頭弁論の終結の時までにすることができる。41条2項）」
- 悪い例（短答、×）：「× 同時審判の申出は、被告もすることができ、第一審の口頭弁論の終結の時までにしなければならない。」（2か所が誤り。どちらを問うているのか分からない）
- 良い例（当てはめの要点）：「両請求が、一方が認められれば他方が認められない関係にあるかを、実体法の要件から確かめる。事実上両立しないだけでは足りない。」
- 悪い例（当てはめの要点）：「事案に即して判断する。」
