# 取締役の対会社責任（会社法423条）の要件と免除・限定

## 1　責任の要件

取締役は、その任務を怠ったときは、株式会社に対し、これによって生じた損害を賠償する責任を負う（会社法423条1項）。要件は、任務を怠ったこと（任務懈怠）、損害、任務懈怠と損害の因果関係、帰責事由である。

## 2　免除と限定

この責任は、総株主の同意がなければ、免除することができない（424条）。総株主の同意があれば、全部を免除できる。

総株主の同意がないときは、取締役が職務を行うにつき善意でかつ重大な過失がないかを問う。悪意又は重大な過失があるときは、一部の免除も責任の限定もできない。

善意でかつ重大な過失がないときは、三つの方法で、賠償の責任を負う額を減らせる（図1）。

- 株主総会の決議によって一部を免除する（425条1項）。免除できるのは、賠償の責任を負う額から最低責任限度額を控除して得た額までで、責任は最低責任限度額まで減る。決議は特別決議である（309条2項8号）。
- 監査役設置会社（取締役が二人以上ある場合に限る）、監査等委員会設置会社又は指名委員会等設置会社は、定款の定めに基づき、取締役会の決議によって一部を免除する（426条1項）。
- 非業務執行取締役等とは、定款の定めに基づき、あらかじめ責任限定契約を結ぶ（427条1項）。責任の限度は、定款で定めた額の範囲内であらかじめ会社が定めた額と最低責任限度額とのいずれか高い額までである。

自己のために会社と直接取引をした取締役の責任は、帰責事由がないことで免れることができず、一部の免除・責任限定契約の規定も適用されない（428条）。
