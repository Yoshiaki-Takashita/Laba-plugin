# 債権者代位訴訟の当事者

債権者が被代位権利の行使に係る訴えを提起すると、四つの関係が生じる（図1）。

債権者は、第三債務者（相手方）に対し、金銭の支払を自己にすることを求めることができる（民法423条の3）。第三債務者は、債務者に対して主張できる抗弁をもって、債権者に対抗できる（423条の4）。

債権者は、訴えを提起したときは、遅滞なく、債務者に対し、訴訟告知をしなければならない（423条の6）。債務者は、被代位権利について、自ら取立てをすることを妨げられない（423条の5）。

債権者が他人（債務者）のために原告となったので、確定判決の効力は、債権者と第三債務者のほか、債務者にも及ぶ（民事訴訟法115条1項2号）。債務者の他の債権者には及ばない。
