# 正しい図での偽陽性の回帰試験（round 5）

`run_tests.py` の advisory の組が使う。どの図も、本文を先に書いてから作った正しい図で、`trace.py --strict` の所見（T06・T07・T01・「なし」）が一つも出ないこと。

| ファイル | 出どころ |
|---|---|
| `p1`〜`p9` | 独立の採点（第4回）で採点者が本文を先に書いて作った図。p2・p3・p4・p5 は、採点で「誤解を招く」とされた書き方を直した版（下） |
| `p5-parties-kyusho`・`p8-swimlane-active` | 採点者が偽陽性として報告した書き方（求償の矢印の語、能動の段の名前）を再現した正しい図 |
| `h1`〜`h5` | 作成側が第5回で新しく書いた本文と図（錯誤の流れ図、債権譲渡の当事者関係図、正当防衛と緊急避難の木、訴えの提起のスイムレーン、取得時効の時間軸）。規則を直した後の確かめに使った。初回は h1（流れ図の出口の言い切り）と h4（スイムレーンで、別の主題の文に前の文の主語を持ち越す）に偽陽性が出て、規則を直した。h2・h3・h5 は初回から所見なし |
| `h6`・`h8` | 規則を直し終えた後に新しく書いた本文と図（留置権と同時履行の抗弁権の比較図、相続の承認と放棄の木）。直さずに初回から所見なし（もう一枚、右向きの流れ図も初回から所見なし。判例の書誌を確かめていないので同梱しない） |

直した書き方（第4回の採点の「誤解を招く書き方」4 件）：
- p5 国家賠償法1条：公務員の箱に「公権力の行使に当たる」「職務を行うについて」「故意又は過失によって」を戻した（採点者が trace の偽陽性を消すために外していた）。線の横の語が長くなる分は、要件を箱の二行目以下に移して解いた。
- p3 共犯と身分：業務上横領の枝の条件を「業務上の占有者でない者が加功」と戻した。
- p2 取締役の責任の免除・限定：「最低責任限度額まで減らせる」を三つの方法に共通の言い方にせず、425 条は最低責任限度額まで、426 条は監査役設置会社等に限ること、427 条は定款で定めた額の範囲内で会社が定めた額と最低責任限度額のいずれか高い額までと、本文と図（と注）に分けて書いた。
- p4 伝聞例外：321 条 1 項 2 号の小枝に前段（供述不能）を入れ、特別の情況が後段（相反供述）だけの要件だと本文に書いた。

条文は e-Gov 法令 API の現行の本文で確かめた（会社法 425〜427 条、刑訴法 321 条、国家賠償法 1 条）。

照合の規則を直したときは、ここに入っていない新しい正しい図（本文を先に書いたもの）でも偽陽性が出ないことを確かめ、その図をここに足す。ここにある図に合わせて規則を足すだけでは、過学習になる。
