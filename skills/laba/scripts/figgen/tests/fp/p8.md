# 賃料債権への物上代位の手続

抵当権者が賃料債権に物上代位するには、払渡しの前に差押えをしなければならない（民法372条・304条1項ただし書）。手続は、抵当権者・執行裁判所・賃借人（第三債務者）・設定者の四者が順に関わる（図1）。

まず、設定者が抵当権を設定し、抵当権設定登記をする。次に、設定者は、建物を賃借人に賃貸する。

抵当権者は、担保権の存在を証する文書を提出して、執行裁判所に賃料債権の差押えを申し立てる（民事執行法193条1項）。執行裁判所は、差押命令を発し、設定者に対し取立てその他の処分を禁止し、賃借人に対し設定者への弁済を禁止する（145条1項）。差押命令は、設定者及び賃借人に送達される（145条3項）。差押えの効力は、差押命令が賃借人に送達された時に生ずる（145条5項）。

賃借人は、設定者に賃料を支払うことができなくなる。抵当権者は、設定者に差押命令が送達された日から1週間を経過したときは、賃料を取り立てることができる（155条1項）。
