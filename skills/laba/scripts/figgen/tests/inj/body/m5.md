# 申請に対する処分と不利益処分（行政手続法）

行政手続法は、処分を、申請に対する処分（第2章）と不利益処分（第3章）に分け、それぞれに違う手続を定める。同じ「処分の基準」「理由の提示」でも、義務の強さが違う所があり、取り違えやすい。図5で、同じ段を左右に見比べる。

基準から見る。申請に対する処分では、行政庁は審査基準を定め、これを公にしておかなければならない（5条1項・3項）。不利益処分では、行政庁は処分基準を定め、これを公にしておくよう努めなければならない（12条1項）。処分基準は努力義務にとどまる。

処理の期間について、申請に対する処分では、行政庁は標準処理期間を定めるよう努め、定めたときは公にしておかなければならない（6条）。

いちばん大きな違いは、意見陳述の手続である。不利益処分をしようとするときは、行政庁は、名あて人となるべき者について、聴聞又は弁明の機会の付与の手続を執らなければならない（13条1項）。申請に対する処分には、意見陳述の手続はない。

理由の提示について、申請に対する処分では、行政庁は、許認可等を拒否する処分をするときに、同時に理由を示さなければならない（8条1項）。不利益処分では、行政庁は、不利益処分をするときに、同時に理由を示さなければならない（14条1項）。

図5　この図で分かること：不利益処分には事前の意見陳述の手続があり、申請に対する処分にはない。処分基準は努力義務にとどまる。
