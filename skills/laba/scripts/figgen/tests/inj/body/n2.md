# 表見代理の三つの類型

代理権のない者がした行為でも、本人が責任を負うことがある。これを表見代理といい、代理権授与の表示（民法109条1項）、権限外の行為（110条）、代理権消滅後（112条1項）の三つの類型がある。効果はどれも同じで、本人が責任を負う。違うのは、本人がしたことと、第三者の要件である。図2で、同じ段を左右に見比べる。

代理権授与の表示では、本人がしたことは、代理権を与えた旨を第三者に表示したことである。代理人がしたことは、表示された代理権の範囲内の行為である。第三者の要件は、代理権がないことを知らず、過失もないことである（109条1項ただし書）。

権限外の行為では、本人は、代理人に何らかの権限を与えていた。代理人がしたことは、与えられた権限の外の行為である。第三者の要件は、代理人に権限があると信ずべき正当な理由があることである。

代理権消滅後では、本人は、かつて代理権を与えていた。代理人がしたことは、消滅した代理権の範囲内の行為である。第三者の要件は、代理権の消滅を知らず、過失もないことである（112条1項）。

表示された代理権の範囲外の行為や、消滅した代理権の範囲外の行為については、第三者に正当な理由があるときに限って、本人が責任を負う（109条2項・112条2項）。

図2　この図で分かること：三つの類型は効果が同じで、本人がしたことと第三者の要件が違う。
