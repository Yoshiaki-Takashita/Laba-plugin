# 訴因変更が許される場合（刑訴法312条）

審理の途中で、起訴状に書かれた訴因と、証拠から見えてきた事実とが食い違うことがある。このとき訴因を変えられるかは、二つの問いで決まる。図5で順に確かめる。

第一の問いは、検察官の請求があるか、である。訴因の追加・撤回・変更は、検察官の請求によって行う（312条1項）。請求がないなら、審理はもとの訴因のまま進む。もっとも、裁判所は、審理の経過に鑑み適当と認めるときは、変更を命ずることができる（312条2項）。

第二の問いは、公訴事実の同一性を害しないか、である。判例は、新旧の訴因で基本的事実関係が同一かを見る。同一性を害するなら、変更は許されない。その事実を審理してもらうには、検察官が別の事件として起訴することになる（補足）。

請求があり、公訴事実の同一性を害しないなら、裁判所は変更を許さなければならない（312条1項）。変更によって被告人の防御に実質的な不利益を生ずるおそれがあるときは、被告人又は弁護人の請求により、公判手続を停止する（312条7項）。

図5　この図で分かること：検察官の請求があり、公訴事実の同一性を害しなければ、裁判所は訴因の変更を許さなければならない。
