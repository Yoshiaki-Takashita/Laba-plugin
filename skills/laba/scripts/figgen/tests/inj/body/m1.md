# 留置権と同時履行の抗弁権

留置権（民法295条）と同時履行の抗弁権（533条）は、どちらも、相手が債務を履行するまで、自分の側の給付を拒める権利である。訴訟で主張すると、どちらも、請求を棄却する判決ではなく、引換給付判決になる（判例）。よく似ているので取り違えやすい。違いは、誰に対して主張できるかと、何を拒めるかにある。図1で、同じ段を左右に見比べる。

留置権は物権である。他人の物の占有者は、その物に関して生じた債権を有するときは、その債権の弁済を受けるまで、その物を留置することができる（295条1項）。物権なので、留置権は、契約の相手方に限らず、第三者にも主張できる。拒めるのは、物の引渡しである。占有が不法行為によって始まった場合には、留置権は成立しない（295条2項）。

同時履行の抗弁権は、双務契約の効力である。双務契約の当事者の一方は、相手方がその債務の履行を提供するまでは、自己の債務の履行を拒むことができる（533条）。契約の効力なので、同時履行の抗弁権は、契約の相手方にしか主張できない。拒めるのは、物の引渡しに限らず、自己の債務の履行である。

どちらも、相手方の債務が弁済期にないときは主張できない（295条1項ただし書・533条ただし書）。

図1　この図で分かること：効果はどちらも引換給付判決だが、留置権は第三者にも主張でき、同時履行の抗弁権は契約の相手方にしか主張できない。
