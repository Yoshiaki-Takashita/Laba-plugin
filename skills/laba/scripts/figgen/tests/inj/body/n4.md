# 差押えと相殺（民法511条）

債権が差し押さえられたとき、第三債務者は、自分が債務者に対して持つ債権で相殺して、差押債権者に対抗できるか。民法511条は、第三債務者がその債権をいつ取得したかで分ける。問いを順にたどれば結論が出るので、図4の木で確かめる。

最初の問いは、第三債務者が債権を取得したのは差押えの前か後か、である。差押えの前に取得した債権なら、相殺を対抗できる（511条1項）。

差押えの後に取得した債権なら、次の問いに進む。その債権は、差押え前の原因に基づいて生じたか。差押え前の原因に基づかないなら、相殺を対抗できない（511条1項）。

差押え前の原因に基づいて生じた債権であれば、最後の問いに進む。その債権は、差押え後に他人の債権を取得したものか。他人の債権を取得したものでなければ、差押えの後に取得した債権であっても、相殺を対抗できる（511条2項本文）。ここが、この条文でいちばん見落としやすい。他人の債権を取得したものであれば、相殺を対抗できない（511条2項ただし書）。

図4　この図で分かること：差押え後に取得した債権でも、差押え前の原因に基づき、他人から取得したものでなければ、相殺を対抗できる。
