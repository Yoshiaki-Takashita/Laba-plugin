# 詐害行為取消権：誰を訴え、判決の効力は誰に及ぶか

債務者が、債権者を害することを知って財産を処分したとき（詐害行為）、債権者は、その行為の取消しを裁判所に請求することができる（民法424条1項）。訴える相手と、判決の効力が及ぶ者とが一致しないところが分かりにくい。図1で確かめる。

訴えの被告になるのは受益者である（424条の7第1項1号）。債務者は被告にならない。債権者は、受益者に対し、取消しと財産の返還を請求する（424条の6第1項）。取り消されるのは、債務者が受益者にした財産の処分（詐害行為）である。

債権者は、訴えを提起したときは、遅滞なく、債務者に対し、訴訟告知をしなければならない（424条の7第2項）。訴訟告知は権利の行使ではなく、手続上の行為である。告知が要るのは、請求を認容する確定判決が、債務者及びその全ての債権者に対しても効力を有するからである（425条）。図1では、当事者のほかに判決の効力が及ぶ者を、灰の破線の枠で囲んだ。枠の中には、債務者と、他の債権者（債務者の全ての債権者）が入る。

財産の処分が取り消されたときは、受益者は、債務者に対し、反対給付の返還を請求することができる（425条の2）。

図1　この図で分かること：被告は受益者だが、判決の効力は債務者と他の債権者にも及ぶ。
