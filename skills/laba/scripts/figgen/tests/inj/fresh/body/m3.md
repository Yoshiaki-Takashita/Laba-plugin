# 不法行為の要件（民法709条）

故意又は過失によって他人の権利又は法律上保護される利益を侵害した者は、これによって生じた損害を賠償する責任を負う（民法709条）。条文は一文だが、損害賠償請求権が発生するには、いくつもの要件がそろわなければならない。図3の木で、効果を支える要件を確かめる。

請求する被害者が主張立証する要件は四つある。第一は、故意又は過失である。第二は、権利又は法律上保護される利益の侵害である。権利と呼べるものに限られず、法律上保護される利益の侵害でもよい。第三は、損害の発生である。第四は、侵害と損害の間の因果関係である。

この四つがそろっても、責任を免れる場合がある。加害者に責任能力がないとき（712条・713条）と、正当防衛・緊急避難に当たるとき（720条）である。これらは、請求される加害者の側が主張立証する。

図3　この図で分かること：損害賠償請求権は、被害者が主張立証する四つの要件がそろって発生し、責任能力がないことなどは加害者の側が主張立証する。
