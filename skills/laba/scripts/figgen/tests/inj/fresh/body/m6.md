# 既判力の範囲：時的・客観的・主観的

確定判決の既判力は、いつの時点の、何についての判断が、誰に及ぶかで範囲が決まる。三つの範囲を混ぜると、後の訴訟で何が言えなくなるのかが分からなくなる。図6で、三つの範囲を同じ段で見比べる。

時的範囲：既判力の基準時は、事実審の口頭弁論終結時である。基準時より前に生じた事由は、後の訴訟で主張できない（遮断される）。基準時の後に生じた事由は主張できる。確定判決についての請求異議の事由が、口頭弁論の終結後に生じたものに限られる（民事執行法35条2項）のは、このためである。

客観的範囲：確定判決は、主文に包含するものに限り、既判力を有する（民事訴訟法114条1項）。主文で判断されるのは訴訟物である。判決の理由中の判断には、既判力は生じない。例外として、相殺のために主張した請求の成立又は不成立の判断は、相殺をもって対抗した額について既判力を有する（114条2項）。

主観的範囲：確定判決は、当事者に対して効力を有する（115条1項1号）。当事者のほか、当事者が他人のために原告又は被告となった場合のその他人、口頭弁論終結後の承継人、請求の目的物を所持する者にも及ぶ（115条1項2号〜4号）。それ以外の第三者には及ばない。

図6　この図で分かること：既判力は、口頭弁論終結時の、主文に包含する判断について、当事者と115条1項各号の者に及ぶ。
