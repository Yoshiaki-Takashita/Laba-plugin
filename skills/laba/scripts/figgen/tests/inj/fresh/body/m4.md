# 正当防衛・過剰防衛・誤想防衛

急迫不正の侵害に対して、自己又は他人の権利を防衛するため、やむを得ずにした行為は、罰しない（刑法36条1項）。これが正当防衛である。正当防衛は違法性を阻却する。過剰防衛と誤想防衛は、どちらも正当防衛の「なりそこない」だが、欠けている要件が違い、扱いも違う。図4で、二つの問いの組合せから四つの場合を見比べる。

一つ目の問いは、急迫不正の侵害が現実にあったか、である。二つ目の問いは、防衛の程度が相当であったか（やむを得ずにした行為か）、である。

急迫不正の侵害が現実にあり、防衛の程度が相当であれば、正当防衛であり、罰しない。

急迫不正の侵害が現実にあったが、防衛の程度を超えたときは、過剰防衛である。過剰防衛は違法性を阻却しない。防衛の程度を超えた行為は、情状により、その刑を減軽し、又は免除することができる（36条2項）。

急迫不正の侵害がないのに、あると誤信して、相当な防衛をしたときは、誤想防衛である。違法性は阻却されないが、通説は故意を阻却する（補足）。過失があれば過失犯が成立しうる。

急迫不正の侵害がないのに、あると誤信して、しかも防衛の程度を超えたときは、誤想過剰防衛である。判例は、36条2項により刑を減軽することができるとする（補足）。

図4　この図で分かること：急迫不正の侵害が現実にあったかと、防衛の程度が相当であったかの組合せで、正当防衛・過剰防衛・誤想防衛・誤想過剰防衛に分かれる。
