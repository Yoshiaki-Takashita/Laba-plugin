# 取締役会・監査役・会計監査人を置く会社の機関

取締役会設置会社は、原則として監査役を置かなければならない（会社法327条2項）。会計監査人を置く会社も、監査役を置かなければならない（327条3項）。誰が誰を選び、誰が何を監査するのかを取り違えやすいので、図3で向きを確かめる。

選ぶ向きから見る。株主総会は、取締役・監査役・会計監査人を選任する（329条1項）。取締役会は、すべての取締役で組織する（362条1項）。取締役会は、代表取締役を選定し、取締役の職務の執行を監督する（362条2項）。

監査の向きは二つある。監査役は、取締役の職務の執行を監査する（381条1項）。会計監査人は、計算書類を監査する（396条1項）。会計監査人の監査の相手は人ではなく、計算書類という書類である。

図3では、監査役の監査の矢印を、取締役会ではなく取締役に向けた。株主総会と取締役会を二重の枠で描いた。この二つは会議体の機関で、合議で決める。計算書類は、右上の角を折った箱で描いた。

図3　この図で分かること：選任は株主総会から出て、監査は監査役から取締役へ、会計監査人から計算書類へ向かう。
