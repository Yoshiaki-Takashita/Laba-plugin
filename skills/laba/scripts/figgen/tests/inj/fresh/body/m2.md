# 株主代表訴訟の手続（提訴請求から訴えの提起まで）

株主は、取締役の責任を追及する訴えを、いきなり自分で起こすことはできない。まず会社に訴えの提起を請求し、会社が動かないときに初めて、会社のために訴えを提起できる。誰が、どの順に、何をするかを図2で追う。

公開会社では、6か月前から引き続き株式を有する株主が、株式会社に対し、書面などで、取締役の責任を追及する訴えの提起を請求する（会社法847条1項）。これを提訴請求という。公開会社でない会社では、保有期間の要件はない（847条2項）。

監査役設置会社では、提訴請求を受けるときは、監査役が会社を代表する（386条2項1号）。会社は、請求の日から60日以内に、訴えを提起するかを決める。

会社が60日以内に訴えを提起しないときは、請求をした株主は、株式会社のために、訴えを提起することができる（847条3項）。この場合に、請求をした株主又は取締役から請求を受けたときは、会社は、訴えを提起しない理由を、遅滞なく通知しなければならない（847条4項）。

株主は、訴えを提起したときは、遅滞なく、会社に対し、訴訟告知をしなければならない（849条4項）。

60日の経過により会社に回復することができない損害が生ずるおそれがある場合には、株主は、直ちに訴えを提起することができる（847条5項）。

図2　この図で分かること：株主は、まず会社に提訴請求をし、会社が60日以内に訴えを提起しないときに、会社のために訴えを提起できる。
