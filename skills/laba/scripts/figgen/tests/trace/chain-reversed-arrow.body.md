# 二重譲渡と対抗関係

売主（もとの所有者）が同じ不動産を二人に売ったとき、二人の譲受人の優劣は、契約の先後ではなく登記の先後で決まる（民法177条）。図3で関係を確かめる。

売主は、まず第一譲受人との間で売買をした（①売買）。第一譲受人は先に契約したが、登記がない。その後、売主は第二譲受人との間でも売買をし、移転登記をした（②売買と移転登記）。第二譲受人は後に契約したが、先に登記を備えた。

この場合、登記を先に備えた方が優先する。第二譲受人は第一譲受人に所有権を対抗できる（177条）。第一譲受人は、登記がないので第二譲受人に所有権を対抗できない。

ただし、第二譲受人が背信的悪意者に当たるときは、第一譲受人は登記がなくても対抗できる（判例）。

図3　この図で分かること：二重譲渡では、先に登記を備えた譲受人が優先する。
