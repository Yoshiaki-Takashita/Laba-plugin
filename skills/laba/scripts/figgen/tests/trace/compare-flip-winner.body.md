# 同時審判の申出と証明責任

二人の被告への請求が両立しないとき、原告がどちらにも負けてしまう危険があるかは、証明責任の置かれ方で分かれる。図1で二つの型を比べる。

無権代理型は、法律上併存しない関係の典型である。原告は、本人には契約の履行を求め、代理人には無権代理人の責任を求める。争点は代理権があったかである。本人との関係では代理権の存在について原告が証明責任を負うが、代理人との関係では代理人が負う（民法117条1項）。したがって、代理権の存否が真偽不明のとき、本人との関係では原告が負けるが、代理人との関係では原告が勝つ。同じ手続で審理されれば、どちらかには勝てる。

もっとも、この型でも、弁論が分離されて代理権の判断が食い違うと、原告は両方に負ける。これを防ぐのが同時審判の申出（民訴41条）で、対象は法律上併存しない型に限られる。

相手方不明型は、事実上併存しない関係である。原告は甲にも乙にも契約の履行を求める。争点は、契約の相手方は甲か乙かである。相手方であることの証明責任は、甲との関係でも乙との関係でも原告が負う。真偽不明のときは、甲との関係でも乙との関係でも原告が負ける。帰結として、同じ手続で審理されても、両方に負けることがある。

図1　この図で分かること：二人の被告への請求が両立しないとき、争点の証明責任が被告ごとに逆向きなら原告はどちらかに勝てるが、どちらも原告にあると両方に負けうる。
