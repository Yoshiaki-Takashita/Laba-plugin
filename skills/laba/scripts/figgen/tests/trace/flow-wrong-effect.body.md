# 共同正犯・教唆犯・幇助犯の区別

犯罪に関わった者が共同正犯・教唆犯・幇助犯のどれに当たるかは、三つの問いを順に当てはめると区別できる。図5にその順を示す。

第一に、重要な役割を果たしたか。共謀に加わり、自分の犯罪として実行に関わった者は、これに当たる。当たるなら共同正犯であり、全員が正犯として処罰される（刑法60条）。共同正犯は、実行行為を分担しなくても、共謀に基づいて他の者が実行すれば成立しうる（共謀共同正犯）。

第二に、当たらないときは、犯意を生じさせたかを問う。犯罪の決意がなかった者をそそのかして実行させた者は教唆犯であり、正犯の刑を科する（61条）。

第三に、これにも当たらないときは、実行を容易にしたかを問う。すでに決意している正犯を手助けした者は幇助犯であり、正犯の刑を減軽する（62条・63条）。

どれにも当たらないなら、共犯は成立しない。なお、教唆犯・幇助犯は、正犯が実行に着手して初めて成立する。

図5　この図で分かること：三つの問いを上から順に当てはめれば区別できる。
