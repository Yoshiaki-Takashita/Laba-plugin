# ライトとル・コルビュジエの図面表現：スタイル設定（横断担当・v0.2・2026-10-23）

基準は `scripts/archstudio/SPEC.md` §2 の線体系（ISO 128 系列・紙の上の mm）。
下の数値は**原図の実測ではなく**、刊行図版の一般的な観察と二次資料の記述から置いた**初期値**。
原図・初版の図版で測るまで確認段階は V1（後述）。図の複製はしない（数値とルールだけを持つ）。

確認段階：V0＝記憶のみ／V1＝二次資料で一般に述べられるが本作業で本文未照合／V2＝信頼できる資料の本文で照合／V3＝原図・初版で実測。

## 1. ライト：Wasmuth Portfolio（1910/1911）
- 書誌（V2）：*Ausgeführte Bauten und Entwürfe von Frank Lloyd Wright*、Ernst Wasmuth（Berlin）。
  2 巻・石版 100 枚。1893〜1909 年の設計の平面と透視図を**線描のみ（in linework only）**で収める。
  刊行年は Wikipedia 本文が 1911、LOC の所蔵記録は図版の日付を 1910 とする（食い違いは未解消）。
  図版のおよそ半分は Marion Mahony Griffin による描き直しと考えられている（Wikipedia、要原典）。
  米国向けの 500 部はタリアセンの火災で焼失。ル・コルビュジエが 1 部を持っていたことも同ページが書く。
  出典：https://en.wikipedia.org/wiki/Wasmuth_Portfolio
- LOC の所蔵記録（V2・本文確認）：例 Plate XV「Perspektive vom Hardy-haus, Racine」https://www.loc.gov/item/94512168/ 、
  Plate XXV「Ward W. Willets grundriss und perspektive villa」https://www.loc.gov/item/94512175/ 、
  「Unity Tempel und Unity-Haus」https://www.loc.gov/item/2001696316/ 。記録は "Drawn by Frank Lloyd Wright, between 1893 and 1909" と書く。
  これらは JSON に画像ファイルが無く（"Unprocessed"）、本作業では画像を開けなかった。
- **実際に観察した図版**（V2・低解像度 993×675 px で目視）：Plate XXXI 前後の Dana–Thomas 邸の平面
  （Wikipedia の図版 https://upload.wikimedia.org/wikipedia/en/0/07/Wasmuth_portfolio_-_Dana-Thomas_House.jpg 、1910 年の刊行物で米国ではパブリックドメイン）。
  - 壁は**黒く塗りつぶす**。外形の輪郭線は塗りと一体で、別の線としては見えない。
  - 塗りの壁の幅は画像上で約 5〜7 px、建具・目地・植栽の線は約 1 px。**太細の比はおよそ 5〜7 倍**（低解像度の目測・V2 の下限）。
  - 1 枚に**主階平面・上階平面・ギャラリー下階平面・配置（Lageplan）**を並べる。上階の下に見える屋根は**灰色の網（スクリーントーン）**で塗る。
  - 庭・花壇・樹木・道路（Strasse）まで平面の中に描く。樹木は輪郭の細い線の集まり。
  - **寸法線・通り芯・家具は無い**。室名はドイツ語の大文字の細い字で、室の中に小さく入る。
  - 図題は紙の上端に 1 行（「Tafel …」）、出版社名は右上。署名の赤い四角はこの図版では確認できない（白黒の複製のため不明）。
- 透視図（樹木の前景・縦長の画面・日本版画の影響）は**本作業では画像を開けておらず V1 のまま**。
  ライトの浮世絵の収集と *The Japanese Print: An Interpretation*（1912）も V1。
### スタイル設定 `flw-wasmuth`
| 項目 | SPEC 既定 | flw-wasmuth | 備考 |
|---|---|---|---|
| 切断面の輪郭 | 0.50〜0.70 実線＋ポシェ | **ポシェ黒塗り・輪郭線は塗りと一体** | 観察 V2 |
| 見えがかり・建具 | 0.25 | 0.13〜0.18（壁の塗りの 1/5〜1/7） | 観察 V2（低解像度） |
| 遠い見えがかり・植栽 | 0.13〜0.18 | 0.10〜0.13 | 植栽を多く描く |
| 太細比 | 2〜3 倍以上 | 塗り：線＝面の対比で代用 | |
| 家具 | 0.13〜0.18 | 省略（既定 OFF） | 観察 V2 |
| 上階の下の屋根 | — | 灰色の網 20〜30% | 観察 V2 |
| 1 枚の構成 | — | 各階平面＋配置を 1 枚に、図題は上端 1 行 | 観察 V2 |

## 2. ル・コルビュジエ：Œuvre complète（1929–1970、全 8 巻）
- 刊行：Girsberger / Artemis（Zürich）。編者 W. Boesiger ほか。V1。典拠：Fondation Le Corbusier。
- 描き方の約束（V1）：
  - 平面は**細い均一な線**が主で、壁を薄い塗りかハッチ。柱は黒い点（ドミノの柱）として必ず描く。
  - **曲線の間仕切り**（自由な平面）と直交の柱の格子の対比を見せる。
  - **アクソメ（上から見下ろす平行投影）**と、**人が歩く順の透視スケッチ（建築的プロムナード）**を並べる。
  - 写真・スケッチ・図面・文章を同じ紙面に組む（版面は著者自身の編集）。
  - スケッチは**太いフェルトペン・鉛筆の速い線**、色鉛筆の色面。
  - **規則線（tracés régulateurs）**：立面に黄金比・直角の対角線を重ね、開口の位置を決めた過程を図で示す（*Vers une architecture*, 1923）。
  - **モデュロール**（V2）：1943 年に腕を上げた人 2.20 m から始め、1946 年に身長を 1.75 m から **1.83 m** に改め、
    腕を上げた高さを **2.26 m** とした。赤の系列はへその高さ（改訂版 **1.13 m**）から、青の系列はその 2 倍（**2.26 m**）から黄金比で分ける
    （https://en.wikipedia.org/wiki/Modulor ）。
    - 赤（113·φⁿ を丸めたもの、cm）：…, **27, 43, 70, 113, 183, 296**, …（43〜296 は OEIS A080104 https://oeis.org/A080104 で照合。
      27 は 113/φ³≈26.7 の計算値で、同じ並びを載せる仏語資料は scribd の文書のみ＝V1）。
    - 青（226·φⁿ、OEIS A080106 https://oeis.org/A080106 ）：…, 13, 20, 33, 53, **86, 140, 226, 366**, 592, …
      同項の注記：『Der Modulor』（1978）p.84 の印刷値は計算値と少し違う（例：印刷 2507 に対し計算 2506）。
    - A080104 の並び：43, 53, 70, 86, 113, 140, 183, 226, 296（赤と青を合わせたもの）。

### スタイル設定 `lc-oeuvre`
| 項目 | SPEC 既定 | lc-oeuvre | 備考 |
|---|---|---|---|
| 切断面の輪郭 | 0.50〜0.70 | 0.35＋薄い塗り（灰 20%） | 太さの段が少ない |
| 見えがかり | 0.25 | 0.18 | |
| 家具・設備 | 0.13〜0.18 | 0.13（**常に描く**・造付家具を重視） | |
| 柱 | — | 黒丸 φ=実寸、通り芯は省略可 | |
| 太細比 | 2〜3 倍以上 | 約 2 倍 | V0 |
| アクソメ | 30/60・45/45 | プラノメトリック 45/45 を既定、屋上庭園を見せる | |
| 規則線 | なし | 立面に 0.13 の一点鎖線で対角線・φ 分割を重ねる層（ON/OFF） | |
| 寸法の系列 | 任意 | モデュロールにスナップ：赤 27・43・70・113・183・296／青 86・140・226・366（cm） | V2（27 のみ計算値） |
| スケッチ層 | — | 線幅 0.7〜1.0、揺らぎ ±0.3mm、色面は不透明度 60% | V0 |

## 3. 比較（空間の型・グリッド・家具）
| | ライト | ル・コルビュジエ |
|---|---|---|
| 空間の型 | 中心の暖炉から十字・風車形に広がる平面、低い軒と水平の連なり（プレイリー）、のちユーソニアンの L 字 | 柱と床版で壁から自由にした箱（ドミノ）、「近代建築の五つの要点」（1926/27）：ピロティ・屋上庭園・自由な平面・横長の窓・自由な立面 |
| グリッド | 正方形・長方形のユニット（ユーソニアンは 2×4 ft 等）、後期は 30/60 度・六角形・円 | 柱の直交格子（スパンは作品ごと）、後期はモデュロール |
| 家具と空間 | 造付と特注家具で室内を「一つの作品」に統一（ロビー邸の椅子・照明） | 「住宅は住むための機械」、家具は収納の造付（カジエ）と規格品（LC シリーズは Perriand・P. Jeanneret と共同 1928） |
| 図の見せ方 | 透視図で土地と一体の像 | アクソメと動線の連続で構成 |
| 自然 | 「有機的建築」・地形と素材 | 太陽・空気・緑（ヴィル・ラディユーズ）、ブリーズ・ソレイユ |
