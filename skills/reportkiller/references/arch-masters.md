# 建築のレポート・ポートフォリオ：ライトとル・コルビュジエの研究の使い方

建築史のレポート・作品分析・設計課題のポートフォリオで、フランク・ロイド・ライト（FLW）とル・コルビュジエ（LC）の設計規則・寸法・こだわりを使うときに読む。引用台帳（`citation-ledger.md`）と図の規則（`figures.md`）の上に重ねる。

## 1. 元にする研究（このスキルの `references/arch-masters-data/`）

| 種類 | 場所 | 中身 |
|---|---|---|
| 統合の規則集（まずここ） | `references/arch-masters-data/rules.json` | 規則 66 件（グリッド・モデュロール・天井高・断面・階段・開口・家具・平面・材料・色）。値・段階・作品 ID・出典・食い違い（両論）つき。`raw_rules` に各研究の生成規則の原文、`works` に作品 ID の索引、`exclude` に除外する作品 |
| 作品の詳細 | `references/arch-masters-data/deep/*.md`（第 2 次。14 本） | 作品ごとの rooms・openings・furniture・materials・details・quirks（こだわり）・sources |
| 概要 | `references/arch-masters-data/{wright,corbusier}-*.md`（第 1 次） | 時期別の概要。`drawing-conventions.md` は両者の図面表現の約束 |
| 全作品目録 | （同梱しない） | 配布版には入れていない（Wikipedia の表の転記で、ファイルの大きさが上限を超え、転載の条件も別になるため）。作品の年・所在・現存は原典で引く |

作品が `deep/` に無いときは、§3 以下の規則だけを使い、数値は自分で原典から取る（§5 の数値はその手がかり）。

## 2. 確認段階の読み替え

研究の段階と、引用台帳の段階は**名前が同じでも意味が違う**。研究の段階は「その研究の担当が何で確かめたか」で、レポートの書き手が読んだかどうかではない。

| 研究の段階 | 研究での意味 | レポートでの扱い |
|---|---|---|
| V3 | 一次資料（HABS の実測図・NRHP/NHL 推薦書・財団 FLC/FLW の記録・本人の文章）で確認 | 研究に書かれた**出典 URL を自分で開いて**同じ値を読めたら台帳 V3。開いていなければ V2 以下 |
| V2 | 信頼できる二次資料（Docomomo・論文・出典つき Wikipedia） | 出典を開いて読めたら、その二次資料について台帳 V3（中身に依拠してよい）。原典（一次）としては V1 扱い：「（〔二次資料〕による）」 |
| V1 | 一般に言われるが未照合 | **事実として書かない**。本文に入れるなら「…と言われることが多い」とし、自分で原典を見つけて読むまで数値を書かない |
| V0 | 不明・記憶のみ | **書かない**。研究の空白として、渡すときの報告に「不明」と書く |

- 研究の文章（md・json）そのものは**資料であって引用文献ではない**。参考文献には研究が示す原典（HABS・推薦書・FLC のページ・論文）を、自分で読んだうえで載せる。研究ファイルを文献として挙げない。
- 段階が「V3/V2」「V2-V3」と幅のあるものは低い方で扱う。
- 研究に「食い違い」「conflict」とある値は、片方だけを書かない。両方の出典を読み、本文で「A は○○、B は△△とする」と並べるか、読めた方だけを書いて台帳に食い違いを残す。

## 3. 規則（全段）

1. **V0・V1 の値を事実として書かない**。寸法・年・色番号・面積は、自分が読んだ原典か、読んだ二次資料の値だけ。研究に値があっても、出典を開けなかったら書かない（台帳に【要入手】）。
2. 寸法は**原典の単位のまま**書き、換算は括弧で添える（ライトは ft-in：7'-3"（2.21 m）。LC は cm・m）。換算した値を原典の値として書かない。
3. 「こだわり」（quirks）は**本人の言葉か記録の出典がある場合だけ**「ライトは〜にこだわった」と書く。研究者の解釈なら「〔著者〕は〜と解釈する」。逸話は出典の種類（本人の自伝・施主の回想・伝記）を明記する。
4. 作品の帰属に注意。例：HABS IL-1097「Ralph S. Baker House」（1913）は William Drummond の作で、ライトの Frank J. Baker 邸（1909）とは別の建物。Unity Chapel（1886）は Silsbee の設計。`rules.json` の `exclude` を見る。
5. 図面・写真は**複製しない**。HABS の図面はパブリックドメインだが、レポートには自分で描いた図式（グリッド・断面の高さ・動線）を載せ、図題に「〔HABS IL-○○○ シート○〕の寸法をもとに筆者作成」と書く。著作権のある図版は見て寸法を読むだけ。
6. 規則は**規則として**書き、作品の数で裏付ける：「ユーソニアンでは天井が 3 段になる（Jacobs I：7'-3"／9'-4"／11'-7"〔HABS〕）」のように、規則→作品→値→出典の順。1 作品の値を両者の一般則にしない。
7. 設計課題のポートフォリオで「ライト風」「モデュロールに基づく」と書くなら、使った規則と値を説明文に明記し、どれが原典どおりでどれが自分の解釈かを分ける（例：「グリッド 2×4 ft はユーソニアンの規則。天井高 2,400 は日本の基準に合わせた変更」）。

## 4. 作品から規則を引く手順

1. 作品名を `rules.json` の `works` で引き、`ref`（例 `wright-usonian#jacobs-1`）を得る。
2. `curated` のうち `works` にその ref を含む規則を集める（ファイル名だけの ref はそのファイルの作品全体に関わる規則）。
3. 作品の詳細は `deep/*.md` の同じ作品の節：部屋（寸法）・開口・家具・納まり・こだわり・出典。
4. 各値の `stage` と出典 URL を台帳の候補に写し、**URL を自分で開いて**値を読み、台帳の V を決める。
5. `conflicts`（規則ごと）と `conflicts_found`（研究ファイル全体）に、その作品・値があれば両論にする。

逆に規則から作品を引くとき（「天井高の階層を示す例」）は、`category`（grid・modulor・ceiling・section・stair・opening・furniture・detail・plan・material・color）で絞り、`use` が `fact`（V2 以上）のものだけを例に使う。

## 5. よく使う数値（研究の段階つき。本文に書く前に原典で確かめる）

- **ライトのグリッド**：プレーリー後期 4'-0"（Robie、V3）／1887〜1900 年は記載なし（対称 3 分割、V3）／ユーソニアン 2×4 ft・4 ft 角・六角形・三角形・放射（V3）／菱形 4 ft・60/120°（Unitarian、V3）／テキスタイル・ブロック 16 in（V3/V2）。
- **ライトの天井**：Jacobs I 7'-3"／9'-4"／11'-7"（V3）。Robie 地上 7'-2"・主階縁 7'-3"・上階 7'-6"（V3）。Charnley 9'-5"→8'-10"→7'-5"（上の階ほど低い、V3）。低い入口 約 1.8 m → 高い主室（V2）。
- **ライトの家具**：背の高い椅子 90／100／140 cm・座 45.7 cm（V3）、机 居間 66.8・食堂 72.4〜76.4 cm（V3）。チェロキー・レッド #9B3426 は **V0**（書かない）。
- **モデュロール**：基準身長 183・へそ 113・挙手 226（初版 175・108・216）。赤列 …43・70・113・183・296・479・775…、青列 …86・140・226・366・592…（cm）。数列の定義は V1、作品での値 226・366・183・592・70・53・43 は V2。113 より上は 1254／1253 のように 1 cm の食い違い（両論。LC の印刷表は未見＝V0）。
- **LC の天井**：既定 226（ベルリンは規制で 250、研究間で 250／260 の食い違い）。ラ・トゥーレット 226→366→732（V3）。サヴォワ 4×4 スパン 4.75 m（V2）、斜路の勾配は **不明**。
- **LC の最小単位**：カバノン 366×366×226、窓 70×70（V2。面積は FLC 15 m² と計算 13.4 m² の食い違い）。僧房 592×183（V2）。

## 6. 渡すときの報告に足すこと

- 使った規則の一覧（rules.json の id か、自分の言葉の規則）と、各値の台帳 ID・V。
- 研究で V0・V1 だったため書かなかった値と、開けなかった出典（【要入手】）。
- 研究間の食い違いをどう扱ったか（両論にした・片方を読めた・書かなかった）。
