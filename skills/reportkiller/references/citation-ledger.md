# 引用台帳（V0〜V3）・検索先・引用の書き方

原則は一つ：**自分で読んでいないものは書かない。読めなかったことは隠さずに報告する。** 2026-10-22 の研究で、AI の素の出力の注は**ほぼすべてが V0（記憶のみ）**で、書籍の頁が無く（Sonnet 0%）、著名な判決に偏り、評釈を引かない。この台帳が最も効いている規則である。

## 1. 確認段階

| 段階 | 意味 | 本文でできること |
|---|---|---|
| **V3** 全文を読んだ | 原文（PDF・HTML・利用者が貼った資料）を自分で読んだ | 「」引用・頁数付きの参照・著者名を出した要約、すべて可 |
| **V2** 書誌ページを見た | 出版社・DOI・J-STAGE・NDL の書誌だけ確かめた | 中身は書かない。頁数を付けない。**大学院生以上：本文にも注にも参考文献にも載せない**（「〔著者〕の論文がある」と存在に触れる注も書かない。読んでいない文献を並べると査読者は「読んでから出し直せ」と書く）。台帳と渡すときの報告に書く。学部生以下は参考文献に載せてよい |
| **V1** 二次資料の要約を読んだ | 講義資料・教科書・百選の解説などで知った | 「（〔二次資料〕の整理による）」を付け、原著者の実名を出さず「…とする見解がある」。参考文献には二次資料のほうを載せる |
| **V0** 記憶のみ | 読んでいない | **書かない。存在しそうでも書かない。台帳からも外す** |

- 読者がその文献の著者本人でありうる場合（指導教員の論文など）は、V3 以外は本文に入れない。
- 頁数を書くのは V3 か、利用者が貼った資料にその頁数があるときだけ。同じ文献の頁数が箇所ごとに食い違っていないかを最後に `scripts/ledger_check.js` で照合する。
- 段ごとの要求（`levels.md`）：高校生＝中心主張は V3 か V1、V1 は 5 割まで／学部生＝V3 1 件以上、V1 は 3 割以下／大学院生＝一次か査読の V3 2 件以上、V1 1 割以下、すべての主張に台帳の ID／専門家＝V1 は 0、根拠の時点と確認日／論文・学会＝中心主張はすべて V3、全行 V2 以上（DOI か書誌ページ）。
- 判例研究の格付け A／B／C（laba-hanrei。`skills/laba/references/hanrei/02-citation-grade.md`）との対応：A（原文を読んだ）＝V3、B（二次資料の要約）＝V1、C（指導教員の論文で未読）＝V2 で本文に入れない。
- **無料で読める一次資料は必ず原典で引く（孫引き禁止。v2.1）**：報告書・審議会資料・附帯決議・指令の条文・判決は、二次資料の紹介で済ませず原典を開く（伏せた比較で、v2 の論文は 2017 年の分科会報告書と参議院の附帯決議を孫引きした）。原典が無料で公開されているのに読まずに V1 で書くことは、読めなかったことにならない。有料で読めないものだけ V1・V2 にとどめる。
- **参考文献の中身（v2.1）**：本文で中身に依拠した文献だけ＝V3 と、V1 の二次資料の側。V2 は載せない（院以上）。道具 `report_check` は参考文献の節に V2 の題があれば `references-v2` を出す。
- **要入手【要入手】（v2.1）**：有料の重要文献（体系書・特集号・調査官解説）で読めなかったものは、使い方の欄に【要入手】を付けて台帳に残し、**書かずに**渡すときの報告に列挙する。論文・学会の段では「要入手の重要文献が残っている」こと自体を報告の冒頭の警告にする（`ledger-toget`）。本文には書かない。

## 2. 台帳の形（1 文献 1 行。渡すときに本文と別に付ける）

```
ID | 完全な書誌 | 確認に使った URL | V0〜V3 | 本文での使い方【中心】【一次】【査読】【二次】【教科書】【要入手】
R01 | 甲野一郎『債権総論』（架空書房、2020）120頁 | https://doi.org/... | V3 | 中心主張【中心】【査読】
R14 | 乙川二郎「〇〇」ジュリスト 0000 号（2024） | https://cir.nii.ac.jp/... | V2 | 書かない。報告に列挙【要入手】
```

使い方の欄の印で、段ごとの要求（中心主張の V3・一次か査読の数）を機械で数える。印が無ければ数えられず「不明」になる。専門家の段は確認日も書く。台帳には**作業の記録**（検索先・検索語・検索月・読めなかった理由・孫引きの有無）も書く。これは本文に書かない（`prose-ja-law.md` 8″）。

## 3. 検索先（動作確認済み。URL は短く。同一サイトは 1 回ずつ）

- 英語論文：OpenAlex `https://api.openalex.org/works?search=〔語〕&per-page=5`（題名・年・DOI・掲載誌）。CrossRef `https://api.crossref.org/works?query.bibliographic=〔語〕&rows=3`（レート制限に当たりやすい。間を置く）。DOI の実在は `https://doi.org/〔DOI〕` を開いて確かめる。Europe PMC の REST（`https://www.ebi.ac.uk/europepmc/webservices/rest/`）は本文の XML が取れる。
- 日本語論文：J-STAGE `https://www.jstage.jst.go.jp/result/global/-char/ja?globalSearchKey=〔語〕`。CiNii Research の OpenSearch `https://cir.nii.ac.jp/opensearch/articles?q=〔語〕`（一覧）。大学のリポジトリ（WEKO の API）。有斐閣の年間総目次 PDF（yuhikaku.co.jp/static_files/hougaku/pdf/〔年〕naiyou.pdf）、有斐閣 Online の連載一覧、書籍ページ（yuhikaku.co.jp/books/detail/〔ISBN〕）。東京大学法科大学院ローレビュー（sllr.j.u-tokyo.ac.jp）。
- 判例：裁判所 `https://www.courts.go.jp/hanrei/search2/index.html?courtCaseType=1&filter[jikenName]=〔事件名〕`（事件名で引く。詳細 `/hanrei/〔id〕/detail2/index.html`、全文 `/assets/hanrei/hanrei-pdf-〔id〕.pdf`）。全文検索 `search1/index.html?query1=〔語〕`。有斐閣 Online の百選ページは事実の概要が無料。
- 法令：e-Gov 法令 API（XML）。
- 使えない（robots・ブロック・確認画面）：CiNii の本文、NDL の API、Semantic Scholar、Google Books API、Google Scholar、SSRN、bepress 系（Cloudflare）、Science・Cell・PNAS の規定ページ。NDL は個別の書誌ページ（ndlsearch.ndl.go.jp/books/R…）なら読める。大学リポジトリ（repo.nii.ac.jp）はリダイレクト先が長すぎて取れないことがある。**記憶だけで URL を組み立てても取得を拒否されるので、検索結果に出た URL をたどる。確認画面を越えるためにブラウザなどを使わない。**
- 全文が読めない有料文献（調査官解説・ジュリスト・判例時報など）は、書誌だけ確認して V2 として扱い、利用者に「貼ってもらえれば V3 にできる」と伝える。重要なものは【要入手】を付けて報告の冒頭に列挙する（本文には書かない）。
- **文献探索の手順（v2.1。論文の段は必須）**：(a) 無料で読める一次資料（法令・判決・報告書・審議会資料・議事録・附帯決議・指令）は原典で引く。孫引きしない。(b) 読んだ主要な文献の注が引く文献を**たどる**（注から注へ 1 段）。見つかった無料の文献（J-STAGE・リポジトリ・紀要・官公庁）は読んで V3 にする（伏せた比較で、v2 の論文は同じ J-STAGE にある重要論文 2 本を落とした）。(c) 有料の重要文献（体系書・特集号・調査官解説）は書かずに【要入手】として報告に列挙する。(d) 検索先・検索語・検索月は台帳に記録し、本文に書かない。

## 4. 引用の書き方

- 「」は原文と一字一句同じときだけ。表記（漢数字・旧字・読点の字形「，」）も原文のまま。省略は「……」、補いは〔筆者注：〕。言い換えに「」を付けない。判決文の記号（Ｈ・Ｊ）をレジュメの記号（A・B）に置き換えて引くなら、冒頭の※注記か凡例で断る。
- 取得ツールは 1 引用 125 字の制限があるので、長い原文は分割して文単位で取り、要約では受け取らない。
- 事実と評価を文で分ける。推論は「〜と読める」「〜とみられる」（学部生）、「〜と思われる」「〜と考えられる」（論文の型）。未確認のマーク（【要確認】等）は最終版に残さない。
- 判例は初出で正式の形（最判平成○年○月○日民集○巻○号○頁。特定頁は〔 〕か読点で連記）、繰り返すなら略称を定義。下級審・未登載は「公刊物未登載」＋事件番号、裁判所 HP で読めるなら「裁判所 HP 参照」。出典の格（「〔講義資料〕による」）を書く。
- 引用形式：法学は法律編集者懇話会『法律文献等の出典の表示方法』（2014 年版）＝雑誌論文「著者「題」誌名 巻 号 頁（年）」、単行本「著者『書名』頁（発行所、年）」、評釈「判批」、前掲「著者・前掲注（n）頁」。東大 LR 第 18 版は開始頁と該当頁の両方。文書の中でそろえる（頁の位置・日付の形・読点）。
- 図・データの出典：「出典：…」「〔著者〕（年）図 3 を基に筆者が加筆」「筆者の集計」。転載に手を入れたら断る。

## 5. 台帳の検査（`scripts/ledger_check.js`）

`node ${CLAUDE_PLUGIN_ROOT}/skills/reportkiller/scripts/ledger_check.js 本文.txt [--ledger 台帳.txt] [--level grad]`：V0 の行、ID の重複、本文で引いたのに台帳に無い ID、台帳にあって本文で一度も使わない行、V3 でない行への「」引用と頁数、同じ ID の頁数の食い違い、V2 以上で URL が空の行、使い方の欄の印の有無、段ごとの文献数・V1 の上限・V3 の下限・一次か査読の数。
