# 教科書型・解説書型の文章（型 `textbook`）：文・段落・見出し・強調・注・図題の規則と数値

「教科書のように」「解説書として」「講義用のテキスト」「入門書の 1 節」を書くときの型。レポート・論文（`prose-ja.md`・`prose-ja-law.md`）と違い、**読者が初めて出会う概念を、順に、戻って確かめられる形で渡す**文章。
根拠：日本語の法学の教科書 5 冊・122 ページの書き起こしの**形の測定**（文・段落・見出し・強調・注・図題の分布）。本文・図の中の語・画像は持っていない。数と規則だけ。**規則に元の文を貼らない。例文は自作**。
印：［測］＝数えた値／［推］＝判断。本ごと・標本の大きさ・限界は GLYPH 側の `TEXT-STRUCTURE-RULES.md`（TS1〜TS22）にある。この文書の（TSn）はその番号。

## 0. いつ使うか・他の型との関係

| 依頼 | 型 |
|---|---|
| レポート・小論文・発表レジュメ（学部生） | `resume`（`prose-ja.md`） |
| 論文・研究報告（大学院生以上） | `paper`（`prose-ja-law.md`） |
| **教科書・入門書・講義テキスト・「教科書のように」・解説の 1 節・紙面（GNOTO の教科書の形）** | **`textbook`（この文書）** |
- 判例研究は laba-hanrei、Word の講義ノートは laba、紙面（.gnoto）に出すときは laba-textbook。内容の規則（引用台帳・V0〜V3・確認していない出典を書かない・作業の告白を書かない・数え上げの族）は **textbook でもそのまま守る**。
- `prose_check.js` の文の長さ・段落・見出しの密度（`headings-dense`）の所見は**論文・レジュメの型の値**なので、教科書型の本文には採らない（採ると 64 字の文を「長い」と直してしまう）。引用・台帳・`work-note`・`banned` の所見は採る。教科書型の形の点検は `scripts/textbook_check.js`。
- 高校生向けの教科書は、文の中央値を 45〜55 字・段落 150 字・太字をやや増やす（［推］。測定は大学の教科書だけ）。

## 1. 数値の一覧（これを外れたら理由を持つ）

| 項目 | 測定（全体。本ごとの範囲） | 規則 |

| 文の長さの分布 | 40 字以下 22%・41〜80 字 47%・81 字以上 31% | 40 字以下を 15〜30%・81 字以上を 25〜35% |

## 2. 節の組み立て（順序の規則）

1. **事例（具体）→ 総説（定義・分類）→ 要件（番号つきの項・目）→ 例外・学説** の順で開く（TS15）。事例は節（項）の**頭に集め**、本文の途中に挟まない。事例の枠 8 件はすべて直前が見出しか別の事例だった。
2. 総説で、定義語を初めて出し（太字）、分類を述べる。**説明してから名前を付ける**：①具体の場面か条件を 1〜2 文 → ②「このような〜を〜と呼ぶ」→ ③名前だけを太字（TS10）。
3. 1 ページ（600〜900 字）に見出しは 1 つ（p50）。節の頭の見出しの直下に項見出しを置いてよい（下がる向き）。
4. 章頭に導入段落（9 行ほど）、節末の要点は教科書に部品が見つからない（［推］。`laba-textbook/references/rules.md` R8）。
5. 本文は、補足を傍注（脚注）に逃がして**論の流れを切らない**。傍注は読み飛ばしても論がつながる内容だけ（`rules.md` R6）。

自作の例（定義の 3 歩）：**「Aが倉庫の鍵を預かったまま転居し、持ち主Bが取り戻せなくなる場合のように、預かった物を返せない状態が続くことがある。このような状態を、債務の滞留と呼ぶ。」**（場面 → 「このような」→ 名前。名前は太字にする）。

## 3. 図と本文の関係

- 図は図題で**自立**させ、本文は図の中身を繰り返さない。本文から図に触れるのは **1 図につき 1 回まで**（TS21。入門書は図を言葉で多く受ける）。
- 図題は「番号＋名詞句」（「図 2.3　発注から入庫までの流れ」型）。**動詞で終えない・文にしない**。出典と改変の断りは図題の括弧に。
- 図の中の語は 4〜8 字。長い語は図題か本文へ（`figures.md` の「ラベルは 1〜4 語」と整合）。教科書の紙面に出すときの図の型・規模・本文との突き合わせは `laba-textbook/references/figure-spec.md`。
- 図で言えることを要点（箇条）にしない。

## 4. 「AI らしさ」の目印（教科書型で効くもの）

論文型の目印（`prose-ja.md` §4）に加えて、教科書型では次を直す候補にする（［推］＝測定の裏付けは「教科書はこうでない」）：

| 目印 | 教科書の実測 | 道具 |
|---|---|---|
| 文が 40〜50 字にそろい、長さが似ている | 変動係数 0.56・中央値 64 | `sent-short`・`sent-uniform` |
| 項見出しが 12 字を超える・動詞や「〜について」で終わる | 項 p50 5・名詞止め 90% | `head-long`・`head-noun` |
| 「ポイント」「まとめ」の枠・箇条の本文 | 本文に箇条なし（要件の番号だけ） | `bullets`（info） |
| 段落の 4 割が「また」「さらに」「そして」で始まる | 24%・逆接が最多 | `para-open` |
| 全文が「である。」で終わる／「です・ます」が混ざる | 「る。」49%・「である。」13% | `ending-mono`・`dearu-heavy` |
| 太字が 1 段落に 3 語以上・文の途中まで太字 | 0〜2 語・9 字以下 | `bold-*` |
| 事例が長く、結論・評価まで書く | 約 120 字・事実だけ | （人が見る） |
| 傍注が 200 字を超える・接続語で始まる | p50 75・7% | （人が見る） |

## 5. 道具

```
node ${CLAUDE_PLUGIN_ROOT}/skills/reportkiller/scripts/textbook_check.js 本文.md          # 形の測定と範囲外の所見（Markdown：# 見出し・**太字**・空行で段落）
node ${CLAUDE_PLUGIN_ROOT}/skills/reportkiller/scripts/textbook_check.js --json 本文.md
```
所見は直す候補（error は出さない）。1 つの印だけで書き直さない。文の正しさ・論理・引用の確認は見ない（`verification.md`・台帳の規則が担う）。

## 6. 限界・不明

- 標本は大学の法学の教科書 5 冊（B4・B5 は本文の標本が小さい）。他分野（理工・語学）の教科書で同じ数値になるかは**不明**。
- 数は形だけ。分かりやすさそのものは、利用者の採点と第三者の査読で確かめる（`laba-textbook` の評価セット）。
- 文の区切りで物理の行（ページの途中で切れた文）を含むため、文・段落の長さは実際よりやや短く出ている。
